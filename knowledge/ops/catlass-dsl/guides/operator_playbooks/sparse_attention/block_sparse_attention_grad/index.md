# Block Sparse Attention Grad (BSAG)

- [Block Sparse Attention Grad (BSAG)](block_sparse_attention_grad.md)：Ascend 950 Arc35 Block Sparse Attention 反向主路径：以 blockSparseMask 为唯一稀疏元数据， 重算被选稀疏块的 score 与概率，五路 MMAD 产出 dQ/dK/dV。dQ 每个 task 原子加到 FP32 workspace；dK/dV 在同一 KV 块内跨 task 在 L0C 累加、换块时一次原子写出。统合 BSND、BNSD、 TND 三种 layout 的 stride 寻址与 TND 累计长度，覆盖 GQA/MQA 的 Q-head 到 KV-head 映射和 共享 dK/dV 所有权。非确定性路径由 host NonZero 预 kernel 生成有效块下标列表、kernel 按 列表取块并把 Q/K/V/dY 做三槽轮转预取；确定性路径用 latin-square 顺序直接读 mask。同一 kernel 的 constexpr 分支覆盖 FP16/BF16 与 1000..1005/1008..1013 两族 tiling key。文末 「扩展层」记录细 token mask 与 head_dim 32/64 两个实现侧变体的出处与边界。
- [Block Sparse Attention Grad Sink](block_sparse_attention_grad_sink.md)：bsag-sink 扩展层：在块稀疏反向之上追加 attention sink 梯度。块稀疏侧沿用 vendor Arc35 语义（blockSparseMask 块参与、NonZero index 或 latin-square 任务生成、TND 累计 seqlen、 dQ 每 task atomic、dK/dV 同 KV 块 L0C 累加）；sink 侧对齐有 sink 的反向算子语义 （flash_attn_grad 的可选 sinks 输入、FlashAttentionScoreGradV3 的 dsinkOut 公式）， dsinks[h] = -sum exp(sinks[h]-LSE)*D 在 post 阶段按 query head 做 FP32 原子归约。 强调 LSE 口径必须与产生 O 的同一次前向一致，并给出全屏蔽行 LSE=+inf 的处理约定。
