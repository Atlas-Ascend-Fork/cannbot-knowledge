# 量化结果差一位时检查除法改乘倒数的舍入变化

## 适用场景

量化输出要求整数精确一致时，不能只用浮点中间值的容差来批准代数改写。`amax / 127` 与 `amax * (1/127)`、`x / scale` 与 `x * inv_scale` 都可能经过不同舍入，使整数舍入落在半整数边界两侧。

## 症状与记录

dav-3510 的量化工程中，曾出现 scale 误差仅约 1 ULP、浮点检查通过，但 INT8 输出有大量差一位。检查定位到 scale 和归一化的除法/倒数乘法路线差异；问题不能由放宽 scale 容差自动消除。

## 定位与处理

1. 固定同一组输入，逐层比较 amax、scale、归一化结果及最终整数值。
2. 分开试验 scale 计算的改写与归一化改写，一次只替换一层。
3. 构造归一化值靠近 `k+0.5` 的正负样本，保留目标舍入模式及饱和边界。
4. 若合同要求匹配参考除法，先恢复同样的算术与转换顺序；若采用近似路线，必须由合同明确允许并独立验收。

## 验证边界

同时报告 scale 的误差和整数 mismatch 数，覆盖全零行、量化极值和尾块；零 scale、NaN/Inf 的处理依接口合同单独确认。不能把一次整数输出通过推广到全部值域。草稿：历史观测尚待当前目标环境复核，未测性能收益。
