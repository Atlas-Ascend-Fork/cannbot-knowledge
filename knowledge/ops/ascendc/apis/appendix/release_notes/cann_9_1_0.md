# C API

CANN 9.1.0继续完善Ascend 950PR/Ascend 950DT（3510架构）C API，新增矢量计算、数据搬运、标量操作、矩阵计算、同步控制、系统变量和缓存控制接口，并修复9.0.0中的函数命名、类型声明和地址自更新签名问题。

涵盖以下类别：新增特性、矢量计算、数据搬运、标量操作、矩阵计算、同步控制、系统变量、缓存控制、Bug修复、增强。
