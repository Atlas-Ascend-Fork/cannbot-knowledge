# 数学函数

SIMT 数学函数的顶层索引，按数据类型组织为 fp8 类型转换、half 类型、bfloat16 类型、float 类型数学库、数据类型转换和整型数学库六个子类。覆盖从低精度（fp8/half/bfloat16）到标准精度（float）以及整型的算术、比较、数学库和精度转换需求，适用于 AICore SIMT 编程模型。
