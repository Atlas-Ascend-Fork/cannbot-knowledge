# 数学函数

- [bfloat16类型](bfloat16_type/index.md)：获取输入数据的绝对值。
- [数据类型转换](data_type_conversion/index.md)：SIMT数据类型转换接口集合，涵盖概述和类型转换函数。
- [float类型数学库函数](float_math_functions/index.md)：获取两个输入数据相除的结果。
- [fp8类型](fp8_type/index.md)：将float2的两个分量按CAST_RINT模式转换为FP8类型（e4m3或e5m2）的8位浮点数，支持饱和与非饱和溢出处理，结果以位级打包存储。
- [half类型](half_type/index.md)：计算输入half2类型数据各分量的绝对值。
- [整型数学库函数](integer_math_functions/index.md)：将输入数据的位序反转，返回反转后的值。
- [数学函数](math_functions.md)：SIMT数学函数索引，包含fp8、half、bfloat16、float、数据类型转换与整型数学函数。
