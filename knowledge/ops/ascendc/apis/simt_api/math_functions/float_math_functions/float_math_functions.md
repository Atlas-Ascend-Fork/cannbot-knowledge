# float类型数学库函数

提供 float 类型的完整数学运算库，涵盖三角函数（sinf、cosf、tanf 及反/双曲变体）、指数对数（expf、logf 及其变体）、开方与幂（sqrtf、powf、cbrtf）、误差函数（erff 系列）、贝塞尔函数（j0f、y0f 等）、浮点操作（fabsf、fmaf、fmodf）和取整判断（floorf、isnan、isinf 等）。函数以 `f` 后缀标识，遵循 C99 数学库语义。
