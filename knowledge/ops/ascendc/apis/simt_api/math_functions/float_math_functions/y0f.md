# 数学函数y0f

功能：获取输入数据x的0阶第二类贝塞尔函数y0的值。

函数原型：float y0f(float x)

参数：x（输入）源操作数。

返回值：输入数据x的0阶第二类贝塞尔函数y0的值。

约束：无。需包含头文件 simt_api/math_functions.h。

支持平台：仅 Ascend 950PR/Ascend 950DT 支持，其他 Atlas 系列产品不支持。
