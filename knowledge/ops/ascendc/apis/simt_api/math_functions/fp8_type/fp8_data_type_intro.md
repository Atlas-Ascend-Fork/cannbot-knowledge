# fp8数据类型简介（FP8类型）

功能：SIMT编程支持3种fp8数据类型，分别是float8_e4m3_t、float8_e5m2_t、hifloat8_t。其数据范围如下。float8_e4m3_t：1：4；float8_e5m2_t：1：5；hifloat8_t：1：由点域编码决定。
