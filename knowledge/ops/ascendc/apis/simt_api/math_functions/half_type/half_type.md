# half类型

half 类型 SIMT 数学函数的总入口，按功能分为算术函数、比较函数、数学库函数和精度转换函数四个子类。同时提供 half2 双分量向量类型的对应算术、比较和数学库函数，用于在 AICore 上实现高效的半精度并行计算。
