# 扩展语法

SIMD 与 SIMT 混合编程模式下的扩展语法索引，包含函数执行空间限定符（如 __aicore__）、内存空间限定符、内置数据类型、内置变量、内置宏和核函数配置六部分。这些扩展语法为 Ascend C 混合编程模型提供编译器级支持，是编写 SIMD/SIMT 混合算子的基础。
