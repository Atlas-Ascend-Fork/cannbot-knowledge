# 矢量数据搬运

- [AscCopyGm2Ub](asc_copy_gm2ub/index.md)：GM到UB数据搬运接口集合，包含不同架构版本。
- [AscCopyGm2UbAlign](asc_copy_gm2ub_align/index.md)：提供数据非对齐搬运功能，将数据从GM搬运到UB，支持8位/16位/32位数据类型，包含不同架构版本实现。
- [AscCopyUb2Gm](asc_copy_ub2gm/index.md)：UB到GM数据搬运接口集合，包含不同架构版本。
- [AscCopyUb2GmAlign](asc_copy_ub2gm_align/index.md)：提供数据非对齐搬运功能，将数据从UB搬运到GM，支持8位/16位/32位数据类型，包含不同架构版本实现。
- [AscCopyUb2l1](asc_copy_ub2l1.md)：将数据从Unified Buffer搬运到L1 Buffer。
- [AscCopyUb2ub](asc_copy_ub2ub.md)：将数据从Unified Buffer搬运到Unified Buffer。
- [AscNdimCopyGm2ub](asc_ndim_copy_gm2ub.md)：多维数据搬运接口，将数据从GM搬运到UB，支持最多5个维度和Padding功能。
- [AscSetCopyPadVal](asc_set_copy_pad_val.md)：配合asc_copy_gm2ub_align或asc_copy_ub2gm_align接口，设置搬运数据块左右两侧需要填补的数据值。
- [AscSetGm2ubLoop1Stride](asc_set_gm2ub_loop1_stride.md)：GM到UB搬运时，设置内层循环中相邻迭代数据块间的间隔。
- [AscSetGm2ubLoop2Stride](asc_set_gm2ub_loop2_stride.md)：GM到UB搬运时，设置外层循环中相邻迭代数据块间的间隔。
- [AscSetGm2ubLoopSize](asc_set_gm2ub_loop_size.md)：GM到UB搬运时，设置数据搬运流程中的循环次数。
- [asc_set_gm2ub_pad（废弃）](asc_set_gm2ub_pad_deprecated.md)：此接口已废弃，源数据从GM非对齐搬运到UB设置填补数据值请使用asc_set_copy_pad_val进行设置。 将数据从Global Memory (GM) 非对齐搬运到 Unified Buffer (UB)时，通过调用该接口设置连续搬运数据块左右两侧需要填补的数据值。
- [AscSetNdimLoopStride](asc_set_ndim_loop_stride.md)：设置asc_ndim_copy_gm2ub接口每个维度内源和目的操作数元素间的间隔，最多5个维度。
- [AscSetNdimPadCount](asc_set_ndim_pad_count.md)：设置asc_ndim_copy_gm2ub接口各个维度左右侧的padding元素个数。
- [AscSetNdimPadValue](asc_set_ndim_pad_value.md)：设置asc_ndim_copy_gm2ub接口Padding的填充固定值。
- [AscSetUb2gmLoop1Stride](asc_set_ub2gm_loop1_stride.md)：UB到GM搬运时，设置内层循环中相邻迭代数据块间的间隔。
- [AscSetUb2gmLoop2Stride](asc_set_ub2gm_loop2_stride.md)：UB到GM搬运时，设置外层循环中相邻迭代数据块间的间隔。
- [AscSetUb2gmLoopSize](asc_set_ub2gm_loop_size.md)：UB到GM搬运时，设置内层循环和外层循环的次数。
- [矢量数据搬运](vector_data_move.md)：矢量数据搬运类接口汇总，提供GM与UB、UB与L1间的连续搬运、高维切分及padding配置能力。
