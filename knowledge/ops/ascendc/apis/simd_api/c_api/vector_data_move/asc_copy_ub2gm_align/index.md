# AscCopyUb2GmAlign

- [AscCopyUb2GmAlign](asc_copy_ub2gm_align.md)：提供数据非对齐搬运功能，将数据从UB搬运到GM，支持8位/16位/32位数据类型，包含不同架构版本实现。
- [AscCopyUb2GmAlign](asc_copy_ub2gm_align_arch_2201.md)：提供数据非对齐搬运功能，将数据从UB搬运到GM，支持8位/16位/32位分块拷贝操作。
- [AscCopyUb2GmAlign](asc_copy_ub2gm_align_arch_3510.md)：提供数据非对齐搬运功能，将数据从UB搬运到GM，支持8位/16位/32位数据类型搬运。
