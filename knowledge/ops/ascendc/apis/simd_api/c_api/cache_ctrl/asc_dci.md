# asc_dci（缓存控制）

数据缓存失效，该指令用于使整个数据缓存无效化，且不会对处于“脏”状态的缓存行执行写回操作。换言之，所有缓存行将被直接标记为无效，其修改过但尚未同步至主存的数据将被丢弃。

约束：在调用asc_dci之前，需调用asc_sync_data_barrier插入DSB_ALL指令，等待所有内存访问指令执行结束。

仅 Ascend 950PR/Ascend 950DT 支持。
