# 基础算术

- [基础算术](arithmetic_compute.md)：寄存器侧基础算术类接口汇总，提供abs、add、sub、mul、div、exp、ln、sqrt、relu等逐元素矢量计算能力。
- [AscAbs](asc_abs.md)：按元素取绝对值，将结果写入目的操作数dst。
- [AscAdd](asc_add.md)：根据mask对源操作数src0、src1按元素求和，将结果写入目的操作数dst。可选保留进位到carry寄存器。
- [AscAddScalar](asc_add_scalar.md)：执行矢量和标量的加法运算，将结果写入目的操作数dst。
- [AscAddc](asc_addc.md)：根据mask对源操作数src0、src1及输入进位carry_src按元素求和，将结果写入dst，同时将进位结果写入carry寄存器。
- [AscDiv](asc_div.md)：根据mask对源操作数src0、src1按元素求商，将结果写入目的操作数dst。
- [AscExp](asc_exp.md)：根据mask对源操作数src按元素求自然指数，将结果写入目的操作数dst。
- [AscLeakyrelu](asc_leakyrelu.md)：按元素执行Leaky ReLU操作，大于0的元素直接写入目的操作数，否则乘以标量value后写入。
- [AscLn](asc_ln.md)：按元素取自然对数，将结果写入目的操作数dst。
- [AscMax](asc_max.md)：根据mask对源操作数src0、src1按元素求最大值，将结果写入目的操作数dst。
- [AscMaxScalar](asc_max_scalar.md)：矢量src的逐个元素与标量value比较取最大值，将结果写入目的操作数dst。
- [AscMin](asc_min.md)：根据mask对源操作数src0、src1按元素求最小值，将结果写入目的操作数dst。
- [AscMinScalar](asc_min_scalar.md)：根据mask将源操作数src按元素与标量value比较取最小值，将结果写入目的操作数dst。
- [AscMul](asc_mul.md)：根据mask对源操作数src0、src1按元素进行乘法运算，将结果写入目的操作数dst。仅在AIV上生效。
- [AscMulScalar](asc_mul_scalar.md)：对源操作数src与标量value按元素做乘法运算，将结果写入目的操作数dst。
- [AscMull](asc_mull.md)：根据mask对源操作数src0、src1按元素相乘，将乘法结果的低位部分写入dst0，高位（溢出）部分写入dst1。
- [AscMuls](asc_muls_deprecated.md)：对源操作数src和标量value进行乘法运算再按ROUND舍入模式转成half类型，根据mask将结果写入目的操作数dst。已废弃。
- [AscNeg](asc_neg.md)：根据mask对源操作数src逐元素取相反数，将结果写入目的操作数dst。
- [AscPrelu](asc_prelu.md)：实现PReLU激活函数，源操作数src0大于0时直接写入dst，否则将src0与src1相乘后写入dst。
- [AscRelu](asc_relu.md)：根据mask对源操作数src按元素进行relu操作，将结果写入目的操作数dst。
- [AscSqrt](asc_sqrt.md)：根据mask对源操作数src按元素求开方，将结果写入目的操作数dst。
- [AscSub](asc_sub.md)：根据mask对源操作数src0、src1按元素求差，将结果写入目的操作数dst。可选保留进位到carry寄存器。
- [AscSubc](asc_subc.md)：根据mask对源操作数src0、src1及输入进位carry_src按元素求差，将结果写入dst，同时将进位结果写入carry寄存器。
