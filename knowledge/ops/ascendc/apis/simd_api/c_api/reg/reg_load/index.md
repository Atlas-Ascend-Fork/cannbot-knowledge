# reg数据搬入

- [AscCopy](asc_copy.md)：完成矢量寄存器之间、掩码寄存器之间以及矢量寄存器到掩码寄存器的数据搬运。
- [AscGather](asc_gather.md)：根据索引位置index将源操作数src按元素收集到目的操作数dst中。
- [AscGatherDatablock](asc_gather_datablock.md)：根据索引将UB中的源操作数按32B的DataBlock收集到目的操作数中。
- [AscLoad](asc_load.md)：从UB非32字节对齐的源地址搬运VL大小的数据到矢量数据寄存器。
- [AscLoadalign](asc_loadalign.md)：从UB中32字节对齐的起始地址搬入数据到矢量数据寄存器或掩码寄存器，支持连续、立即数偏移、地址寄存器偏移和非连续搬入四种模式。
- [AscLoadalignBrcDatablock](asc_loadalign_brc_datablock.md)：从UB对齐搬入一个DataBlock（32B）并广播到VL。
- [AscLoadalignBrcDatablockPostupdate](asc_loadalign_brc_datablock_postupdate.md)：从UB对齐搬入一个DataBlock（32B）并广播到VL，调用后自动更新源地址。
- [AscLoadalignBrcElem](asc_loadalign_brc_elem.md)：从UB对齐搬入一个元素并广播到矢量寄存器的所有元素位置。
- [AscLoadalignBrcElem2datablock](asc_loadalign_brc_elem2datablock.md)：从UB加载多个元素并将每个元素广播到一个DataBlock（32B）中。
- [AscLoadalignBrcElem2datablockPostupdate](asc_loadalign_brc_elem2datablock_postupdate.md)：从UB加载多个元素并将每个元素广播到一个DataBlock（32B）中，调用后自动更新源地址。
- [AscLoadalignBrcElemPostupdate](asc_loadalign_brc_elem_postupdate.md)：从UB对齐搬入一个元素并广播到所有元素位置，调用后自动更新源地址。
- [AscLoadalignDeintlv](asc_loadalign_deintlv.md)：从UB读取连续2×VL长度数据并在Load过程中完成解交织，分别写入两个目的矢量寄存器。
- [AscLoadalignDeintlvPostupdate](asc_loadalign_deintlv_postupdate.md)：从UB读取连续2×VL长度数据并在Load过程中完成解交织，分别写入两个目的矢量寄存器，调用后自动更新源地址。
- [AscLoadalignDownsample](asc_loadalign_downsample.md)：从UB对齐搬入2倍VL数据并实现2倍下采样，每隔一个元素保留。
- [AscLoadalignDownsamplePostupdate](asc_loadalign_downsample_postupdate.md)：从UB对齐搬入2倍VL数据并实现2倍下采样，调用后自动更新源地址。
- [AscLoadalignPostupdate](asc_loadalign_postupdate.md)：从UB对齐地址搬入数据到矢量数据寄存器或掩码寄存器，调用后自动更新源地址，支持立即数偏移和非连续搬入两种模式。
- [AscLoadalignUnpack](asc_loadalign_unpack.md)：从UB对齐搬入VL/2长度数据并unpack到VL长度，中间位置补0。
- [AscLoadalignUnpack4](asc_loadalign_unpack4.md)：从UB对齐搬入VL/4长度u8数据并unpack到VL长度u32类型，中间位置补0。
- [AscLoadalignUnpack4Postupdate](asc_loadalign_unpack4_postupdate.md)：从UB对齐搬入VL/4长度u8数据并unpack到VL长度u32类型，调用后自动更新源地址。
- [AscLoadalignUnpackPostupdate](asc_loadalign_unpack_postupdate.md)：从UB对齐搬入数据并实现解压缩，调用后自动更新源地址。
- [AscLoadalignUpsample](asc_loadalign_upsample.md)：从UB对齐搬入VL/2个数据并实现2倍上采样，每个输入元素重复两次。
- [AscLoadalignUpsamplePostupdate](asc_loadalign_upsample_postupdate.md)：从UB对齐搬入VL/2个数据并实现2倍上采样，调用后自动更新源地址。
- [AscLoadalignV1Deprecated](asc_loadalign_v1_deprecated.md)：已废弃的对齐搬入接口（无偏移入参），支持NORM、BRC、UP2X等多种搬入模式。
- [AscLoadalignV2Deprecated](asc_loadalign_v2_deprecated.md)：已废弃的对齐搬入接口（addr_reg偏移入参），支持NORM、BRC、UP2X等多种搬入模式。
- [AscLoadalignV3Deprecated](asc_loadalign_v3_deprecated.md)：已废弃的对齐搬入接口（int32_t偏移入参），支持NORM、BRC、UP2X等多种搬入模式。
- [AscLoadalignV4Deprecated](asc_loadalign_v4_deprecated.md)：已废弃的对齐搬入接口（int32_t偏移并启用Post Update），支持NORM、BRC、UP2X等多种搬入模式。
- [asc_loadalign (废弃)](asc_loadalign_v5_deprecated.md)：该接口已废弃，请使用asc_loadalign_postupdate实现此功能。 对齐数据搬运接口，从UB连续对齐搬入目的操作数，支持多种搬入模式，接口使用repeat stride模式。
- [asc_loadalign (废弃)](asc_loadalign_v6_deprecated.md)：reg数据搬运接口，适用于从UB搬入MaskReg。
- [AscLoadunalign](asc_loadunalign.md)：从UB非32B对齐的起始地址连续搬入数据到矢量数据寄存器，需用户手动更新源地址。
- [AscLoadunalignPostupdate](asc_loadunalign_postupdate.md)：从UB非32B对齐地址连续搬入数据并自动更新源地址，配合asc_loadunalign_pre使用。
- [AscLoadunalignPre](asc_loadunalign_pre.md)：用于非对齐数据搬入前的初始化，需配合asc_loadunalign或asc_loadunalign_postupdate使用。
- [reg数据搬入](reg_load.md)：寄存器侧数据搬入类接口汇总，提供gather、load、loadalign等从UB到矢量数据寄存器的搬运能力。
