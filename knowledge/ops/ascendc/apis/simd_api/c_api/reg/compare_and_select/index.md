# 比较与选择

- [AscEq](asc_eq.md)：逐元素比较两个源操作数是否相等，比较结果写入目的操作数对应比特位，为真则置1，否则置0。仅在AIV上生效。
- [AscEqScalar](asc_eq_scalar.md)：根据mask将源操作数src中元素逐个与标量value比较是否相等，比较结果写入dst对应比特位，成立为1，不成立为0。
- [AscGe](asc_ge.md)：逐元素比较两个源操作数是否大于等于，比较结果写入目的操作数对应比特位，为真则置1，否则置0。
- [AscGeScalar](asc_ge_scalar.md)：对源操作数执行逐元素比较，若src_i大于等于标量value则目的操作数对应结果位为1，否则为0，每个元素比较结果占一个bit。
- [AscGt](asc_gt.md)：逐元素比较两个源操作数是否大于，比较结果写入目的操作数对应比特位，为真则置1，否则置0。
- [AscGtScalar](asc_gt_scalar.md)：根据mask将源操作数src按元素与标量value比较，若src_i大于value则目的操作数对应结果位为1，否则为0。
- [AscLe](asc_le.md)：逐元素比较两个源操作数是否小于等于，比较结果写入目的操作数对应比特位，为真则置1，否则置0。
- [AscLeScalar](asc_le_scalar.md)：根据mask将源操作数src中元素逐个与标量value比较是否小于等于，比较结果写入dst对应比特位，成立为1，不成立为0。
- [AscLt](asc_lt.md)：逐元素比较两个源操作数是否小于，比较结果写入目的操作数对应比特位，为真则置1，否则置0。
- [AscLtScalar](asc_lt_scalar.md)：根据mask将源操作数src中元素逐个与标量value比较是否小于，比较结果写入dst对应比特位，成立为1，不成立为0。
- [AscNe](asc_ne.md)：逐元素比较两个源操作数是否不相等，比较结果写入目的操作数对应比特位，为真则置1，否则置0。
- [AscNeScalar](asc_ne_scalar.md)：将源操作数src中每个元素逐个与标量value比较是否不相等，若不相等则dst对应比特位为1，否则为0。
- [AscSelect](asc_select.md)：根据mask从源操作数src0、src1中选择元素得到dst，mask比特位为1时选src0对应位置，为0时选src1对应位置。
- [AscSqueeze](asc_squeeze.md)：将src中被mask选择的有效元素依次复制到dst中，有效元素在dst中从低到高连续排列，剩余位置元素置为0。本接口不会将有效数据大小保存至AR寄存器。
- [AscSqueezeV2](asc_squeeze_deprecated.md)：已废弃接口，请使用asc_squeeze_and_storeunalign。将src中被mask选择的有效元素依次复制到dst并连续排列，搭配asc_storeunalign_postupdate可将有效数据大小保存至AR寄存器。
- [AscSqueezeWithStatus](asc_squeeze_with_status_deprecated.md)：已废弃接口，请使用asc_squeeze_and_storeunalign。将src中被mask选择的有效元素依次复制到dst并连续排列，会将有效数据大小保存至AR寄存器供搬出时使用。
- [比较与选择](compare_and_select.md)：寄存器侧比较与选择类接口汇总，提供eq、ge、gt、le、lt、ne等逐元素比较及select、squeeze选择能力。
