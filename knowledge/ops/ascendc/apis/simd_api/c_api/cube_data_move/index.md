# 矩阵数据搬运

- [AscCopyGm2l0a](asc_copy_gm2l0a.md)：将数据从GM搬运到L0A Buffer。
- [AscCopyGm2l0b](asc_copy_gm2l0b.md)：将矩阵数据从GM搬运到L0B Buffer。
- [AscCopyGm2L1](asc_copy_gm2l1/index.md)：GM到L1 Buffer数据搬运接口集合，包含不同架构版本asc_copy_gm2l1_arch_2201和asc_copy_gm2l1_arch_3510。
- [AscCopyGm2l1Align](asc_copy_gm2l1_align.md)：对矩阵数据进行实时padding后从GM搬运到L1 Buffer，需配合asc_set_gm2l1系列接口使用。
- [AscCopyGm2l1Dn2nz](asc_copy_gm2l1_dn2nz.md)：将矩阵数据从GM搬运到L1 Buffer，过程中执行DN到NZ格式转换并在最内层维度补0。
- [AscCopyGm2L1Nd2Nz](asc_copy_gm2l1_nd2nz/index.md)：GM到L1 Buffer带ND2NZ格式转换的数据搬运接口集合，包含不同架构版本。
- [AscCopyL0c2Gm](asc_copy_l0c2gm/index.md)：将矩阵计算结果从L0C Buffer搬运至GM，支持随路量化、ReLU、格式转换等能力，包含不同架构版本实现。
- [AscCopyL0c2L1](asc_copy_l0c2l1/index.md)：将数据从L0C搬运到L1 Buffer的接口，包含不同架构版本的具体实现。
- [AscCopyL0c2ub](asc_copy_l0c2ub.md)：将矩阵计算结果从L0C Buffer搬运到UB，支持随路量化、ReLU、格式转换等多种能力。
- [AscCopyL12Bt](asc_copy_l12bt/index.md)：L1到Bt Buffer数据搬运接口集合，包含不同架构版本。
- [AscCopyL12Fb](asc_copy_l12fb/index.md)：L1到Fb Buffer数据搬运接口集合，包含不同架构版本。
- [AscCopyL12gm](asc_copy_l12gm.md)：将数据从L1 Buffer搬运到GM。
- [AscCopyL12L0a](asc_copy_l12l0a/index.md)：L1到L0A Buffer数据搬运接口集合，包含不同架构版本。
- [AscCopyL12l0aMx](asc_copy_l12l0a_mx.md)：将Mx scale矩阵从L1 Buffer搬运到L0A Buffer。
- [AscCopyL12l0aTrans](asc_copy_l12l0a_trans.md)：将2D格式数据带转置地从L1 Buffer加载到L0A Buffer。
- [AscCopyL12L0b](asc_copy_l12l0b/index.md)：L1到L0B Buffer数据搬运接口集合，包含不同架构版本。
- [AscCopyL12l0bMx](asc_copy_l12l0b_mx.md)：将Mx scale矩阵从L1 Buffer搬运到L0B Buffer。
- [AscCopyL12l0bSparse](asc_copy_l12l0b_sparse.md)：将L1 Buffer中的稠密权重矩阵搬运到L0B Buffer，同时读取索引矩阵用于稠密矩阵稀疏化。
- [AscCopyL12L0bTrans](asc_copy_l12l0b_trans/index.md)：将数据从L1 Buffer搬运到L0B Buffer并支持转置的接口，包含不同架构版本的具体实现。
- [AscCopyL12l0c](asc_copy_l12l0c.md)：将矩阵由L1 Buffer搬运到L0C Buffer中。
- [AscCopyL12ub](asc_copy_l12ub.md)：将数据从L1 Buffer搬运到Unified Buffer中。
- [AscFillL0a](asc_fill_l0a.md)：将标量值赋值给目的操作数，对L0A Buffer进行初始化。
- [AscFillL0b](asc_fill_l0b.md)：将标量值赋值给目的操作数，对L0B Buffer进行初始化。
- [AscFillL1](asc_fill_l1.md)：将标量值赋值给目的操作数，对L1 Buffer进行初始化。
- [AscLoadImageToCbuf](asc_load_image_to_cbuf.md)：将图像数据从Global Memory搬运到L1 Buffer。
- [AscSetGm2l1Loop1Stride](asc_set_gm2l1_loop1_stride.md)：设置GM到L1搬运时内层循环中相邻迭代数据块间的间隔。
- [AscSetGm2l1Loop2Stride](asc_set_gm2l1_loop2_stride.md)：设置GM到L1搬运时外层循环中相邻迭代数据块间的间隔。
- [AscSetGm2l1LoopSize](asc_set_gm2l1_loop_size.md)：设置GM到L1搬运流程中的循环次数。
- [AscSetGm2l1Pad](asc_set_gm2l1_pad.md)：设置GM到L1非对齐搬运时数据块左右两侧需要填补的数据值。
- [AscSetL0c2gmLreluAlpha](asc_set_l0c2gm_lrelu_alpha.md)：设置L0C搬运接口计算过程中使用的Leaky ReLU alpha值。
- [AscSetL0cCopyParams](asc_set_l0c_copy_params.md)：设置L0C搬运随路格式转换（NZ转ND）的相关配置。
- [AscSetL0cCopyPrequant](asc_set_l0c_copy_prequant.md)：设置数据搬运随路量化流程中的标量量化参数。
- [AscSetL13dFmatrix](asc_set_l13d_fmatrix.md)：设置3D搬运接口的Feature map属性描述，用于配置填充数值。
- [AscSetL13dFmatrixB](asc_set_l13d_fmatrix_b.md)：设置3D搬运接口右矩阵的Feature map属性描述，用于配置填充数值。
- [AscSetL13dPadding](asc_set_l13d_padding.md)：设置asc_copy_l12l0a搬运接口的Pad填充数值。
- [AscSetL13dRpt](asc_set_l13d_rpt.md)：设置Load3Dv2接口的repeat参数。
- [AscSetL13dSize](asc_set_l13d_size.md)：设置3D搬运接口在L1 Buffer的边界值。
- [矩阵数据搬运](cube_data_move.md)：矩阵数据搬运接口索引页，涵盖asc_copy_gm2l0a/l0b/l1、asc_copy_l0c2gm及asc_fill_l0a/l0b/l1等。
