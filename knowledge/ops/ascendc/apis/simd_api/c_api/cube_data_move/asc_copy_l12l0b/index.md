# AscCopyL12L0b

- [AscCopyL12L0b](asc_copy_l12l0b.md)：L1到L0B Buffer数据搬运接口集合，包含不同架构版本。
- [asc_copy_l12l0b](asc_copy_l12l0b_arch_2201.md)：用于搬运存放在L1 Buffer里的512B大小的矩阵到L0B Buffer里。包含2D格式搬运、3D格式搬运。
- [asc_copy_l12l0b](asc_copy_l12l0b_arch_3510.md)：用于搬运存放在L1 Buffer里的512B大小的矩阵到L0B Buffer里，包含2D格式搬运、2D格式转置搬运、3D格式搬运。
