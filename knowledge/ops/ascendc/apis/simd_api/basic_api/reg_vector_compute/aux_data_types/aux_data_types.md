# 辅助数据类型

Reg 矢量计算的辅助数据类型集合。PostLiteral 描述后处理字面量；RegLayout 描述寄存器数据排布；MaskMergeMode 控制掩码合并方式；SatMode 控制饱和计算模式；RoundMode 控制舍入模式。这些类型作为 Reg 矢量计算接口的参数，影响计算精度与数据布局行为。
