# 数据填充

Memory 矢量数据填充接口集合。Duplicate 按指定数据重复填充；Brcb 实现广播填充；CreateVecIndex 生成索引向量用于不规则数据搬运；VectorPadding(ISASI) 提供 ISASI 场景下的向量填充能力。用于初始化缓冲区、构造索引或对齐数据等场景。
