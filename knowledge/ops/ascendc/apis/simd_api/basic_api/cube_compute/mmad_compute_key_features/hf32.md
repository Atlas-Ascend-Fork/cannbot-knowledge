# Cube计算(ISASI)HF32

当矩阵 A、B 均为 FP32 时，开启 HF32 开关后 FP32 数据在 Mmad 计算前被舍入为 HF32（half-fp32）格式，使 f322f32 计算性能提升 2 倍，但会带来精度损失。最终结果仍以 FP32 输出。通过 SetHF32Mode 开启，舍入模式通过 SetHF32TransMode 配置（NEAREST_ZERO 或 NEAREST_EVEN）。950 的 HF32 尾数位为 10 位。
