# HF32

HF32（Half Float 32）是一种扩展精度计算模式，将half类型数据在计算时扩展为类float32精度进行矩阵乘加，在保持half数据存储效率的同时提升计算精度。

通过Mmad接口的模板参数配置HF32模式。适用于对精度有较高要求但仍需保持half存储的场景。
