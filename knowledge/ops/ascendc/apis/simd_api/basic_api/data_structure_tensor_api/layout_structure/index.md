# Layout数据结构

- [Coord（基础API）](coord.md)：定义张量逻辑坐标，并配合 Layout 完成多维坐标到线性内存索引的映射。
- [Coshape](coshape.md)：表示Layout陪域区间的标量大小，即逻辑坐标映射到一维索引后所有可能的索引值构成的区间大小。
- [Cosize（基础API）](cosize.md)：需要包含的头文件为：#include "tensor_api/tensor.h"。 Cosize表示Layout陪域（codomain）的跨度大小，即逻辑坐标经Layout映射为一维索引后，所有可能索引值所处区间的长度。Cosize和Coshape在扁平与嵌套Layout场景下等价。
- [基础APIGet](get.md)：需要包含的头文件为：#include "tensor_api/tensor.h"。 Get提供两类能力： 1. 对元组Tuple，按位置索引提取元素或逐层提取嵌套元素； 2. 对Layout，分别从shape和stride中提取对应位置的子tuple，再组合为新的子Layout。

- [GetStride](get_stride.md)：需要包含的头文件为：#include "tensor_api/tensor.h"。 GetStride用于从Layout中提取Stride部分： - 不指定模板参数Is...：返回完整的Stride元组。 - 指定模板参数Is...：从Stride顶层tuple中选择对应索引的元素。指定单个索...
- [Layout](layout.md)：Layout<Shape, Stride>数据结构是描述多维张量内存布局的基础模板类，通过编译时的形状Shape和步长Stride信息，实现逻辑坐标空间到一维内存地址空间的映射。借助模板元编程技术，该类在编译时完成计算和代码生成，从而降低运行时开销。
- [Layout和层次化表述法](layout_hierarchical_representation.md)：Layout通过Shape和Stride表示张量排布格式，层次化表述法支持元组嵌套描述复杂内存排布如分形格式。
- [Layout数据结构](layout_structure.md)：TensorAPI Layout 数据结构集，包含 Layout、Shape、Stride、Coord 及 MakeLayout、GetShape 等相关接口。
- [MakeCoord](make_coord.md)：需要包含的头文件为：#include "tensor_api/tensor.h"。 构造Coord对象，用于定义张量的坐标。
- [MakeFrameLayout](make_frame_layout.md)：需要包含的头文件为：#include "tensor_api/tensor.h"。 MakeFrameLayout用于根据标准分形排布模式构造带类型信息的Layout对象。该接口根据构造参数，结合指定的LayoutPattern（排布模式）和LayoutTrait（布局特征参数）计算Shape...
- [MakeLayout](make_layout.md)：根据Shape和Stride构造Layout对象，描述数据张量在逻辑维度上的形状及各维步长信息。
- [MakePatternLayout](make_pattern_layout.md)：根据Shape、Stride、LayoutPattern和TraitType构造带布局模式信息的Layout对象。
- [MakeShape](make_shape.md)：构造Shape对象，用于描述数据的逻辑形状。支持传入多个维度值，也支持传入嵌套的Shape子结构以构造层次化Shape。
- [MakeStride](make_stride.md)：构造Stride对象，用于描述各维度在内存中的步长。支持传入多个步长值，也支持传入嵌套的Stride子结构以构造层次化Stride。
- [基础APIRank](rank.md)：用于返回Layout的秩。
- [Select（基础API）](select.md)：选择Layout的shape和stride指定维度组成新的layout对象并返回。
- [Shape（基础API）](shape.md)：定义张量各维度的逻辑大小，并与 Stride 组合形成支持层次化表述的 Layout。
- [基础APISize](size.md)：返回 Layout 的有效元素数量，并支持通过模板索引选择要统计的维度。
- [Squeeze](squeeze.md)：删除Layout的Shape中大小为1的指定维度并同步删除Stride中的对应维度，支持Tensor输入。
- [Stride（基础API）](stride.md)：定义张量各维度相邻元素的内存步长，并与 Shape 组合形成 Layout。
