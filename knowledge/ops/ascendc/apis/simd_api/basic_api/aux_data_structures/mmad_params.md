# MmadParams

MmadParams 是 Cube 矩阵乘加指令 `Mmad` 的参数结构体：`m`/`n`/`k` 给出一次矩阵乘的几何尺寸，`unitFlag`/`kDirectionAlign` 控制指令级并行与 K 方向对齐，`cmatrixSource`/`cmatrixInitVal` 决定 C 矩阵初值来源。它同时保留了一批仅用于兼容旧款产品接口的字段。

头文件：`include/basic_api/kernel_struct_mm.h`。结构体声明位于 `:425-474`（固定 commit `016ba4a159eda090c4d60a1cdcd1ccca2a36cb0a`）。

## 结构体定义

```cpp
struct MmadParams {
    __aicore__ MmadParams() {}

    __aicore__ MmadParams(
        const uint16_t mIn, const uint16_t nIn, const uint16_t kIn, const bool isBiasIn, const int32_t fmOffsetIn,
        const bool enSsparseIn, const bool enWinogradAIn, const bool enWinogradBIn)
        : m(mIn),
          n(nIn),
          k(kIn),
          isBias(isBiasIn),
          fmOffset(fmOffsetIn),
          enSsparse(enSsparseIn),
          enWinogradA(enWinogradAIn),
          enWinogradB(enWinogradBIn)
    {}

    __aicore__ MmadParams(
        const uint16_t mIn, const uint16_t nIn, const uint16_t kIn, const uint8_t unitFlagIn,
        const bool cmatrixSourceIn, const bool cmatrixInitValIn)
        : m(mIn), n(nIn), k(kIn), unitFlag(unitFlagIn), cmatrixSource(cmatrixSourceIn), cmatrixInitVal(cmatrixInitValIn)
    {}

    uint16_t m = 0;
    uint16_t n = 0;
    uint16_t k = 0;
    // Indicates whether to accumulate the initial matrix, 0: matrix multiplication, 1: matrix multiplication and
    // addition
    bool isBias = false;
    // Left matrix offset
    int32_t fmOffset = 0;
    // Enable the structured sparse feature, default value is false
    bool enSsparse = false;
    // Indicates whether matrix a is generated by winograd_feature_map_transform, default value is false;
    bool enWinogradA = false;
    // Indicates whether matrix b is generated by winograd_feature_map_transform, default value is false;
    bool enWinogradB = false;
    uint8_t unitFlag = 0;
    // also mean gemvCtrl in 3101 and 5102
    bool kDirectionAlign = false;
    // Indicates the C matrix source, 1: the C matrix is in bias table buffer, 0: the C matrix is in L0C
    bool cmatrixSource = false;
    // Indicates the initial matrix, 1: the number in C matrix is 0, 0：use the real number in C matrix
    bool cmatrixInitVal = true;
#if defined(__NPU_ARCH__) && ((__NPU_ARCH__ == 3510) || (__NPU_ARCH__ == 5102))
    bool disableGemv = false;
#endif
#ifdef CANN_ASC_ENABLE_FIX_SHIFT
    uint8_t fixShiftVal = 0;
#endif
};
```

## 字段说明

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| m | uint16_t | 左矩阵 Height，取值 [0, 4095]，默认 0。 |
| n | uint16_t | 右矩阵 Width，取值 [0, 4095]，默认 0。 |
| k | uint16_t | 左矩阵 Width、右矩阵 Height，取值 [0, 4095]，默认 0。 |
| cmatrixInitVal | bool | 是否把 C 矩阵默认初始化为 0，默认 true；false 时按 `cmatrixSource` 决定初值来源。 |
| cmatrixSource | bool | C 矩阵初值是否取自 BT Buffer（TPosition C2），默认 false；Atlas 训练系列、Atlas 推理系列 AI Core、Kirin X90、Kirin 9030 仅支持 false，A2/A3/200I&500 A2/950 支持 true/false。带 Bias 的接口配置该参数无效。 |
| isBias | bool | 文档标注**已废弃**：新开发不要使用；需要累加初始矩阵时改用带 Bias 的接口，或用 `cmatrixInitVal`/`cmatrixSource` 配置。 |
| disableGemv | bool | `M = 1` 时是否关闭 GEMV 模式；仅在 3510/5102 架构分支下编译进结构体，文档标注仅 Ascend 950 系列支持该参数。 |
| unitFlag | uint8_t | Mmad 与 Fixpipe 细粒度并行：0 不开启，2 开启且复位位保持，3 开启且执行后复位；开启时 Mmad 与 Fixpipe 两侧都必须设为 2 或 3。文档标注仅 950/A2/A3 支持。默认 0。 |
| kDirectionAlign | bool | float 数据类型下 L0A/L0B 矩阵 K 方向对齐方式：false（默认）对齐到 `ceil(K/8)*8`，true 对齐到 `ceil(K/16)*16`；各产品可配置性不同（训练系列/推理系列 AI Core/200I&500 A2/950 仅 false，A2/A3/Kirin X90/Kirin 9030 支持 true/false）。 |
| fmOffset | int32_t | 左矩阵 offset；文档标注为兼容旧款产品接口保留，A2 及之后产品不做处理。 |
| enSsparse | bool | 结构化稀疏开关；文档标注为兼容旧款产品接口保留，A2 及之后产品不做处理。 |
| enWinogradA | bool | 指示矩阵 A 是否由 `winograd_feature_map_transform()` 生成；文档标注为兼容旧款产品接口保留，A2 及之后产品不做处理。 |
| enWinogradB | bool | 指示矩阵 B 是否由 `winograd_weight_transform()` 生成；文档标注同上。 |
| fixShiftVal | uint8_t | 仅在 `CANN_ASC_ENABLE_FIX_SHIFT` 下存在；语义：unknown（文档未说明）。 |

## 约束与注意事项

- 三个几何参数都是 16 位且上界 4095，形状推算时不要按 32 位整型设计。
- `isBias` 已废弃，语义上与 `cmatrixInitVal`/`cmatrixSource` 的初值配置重叠；混用两套配置容易得到非预期累加结果。
- `disableGemv`、`fixShiftVal` 是架构条件字段：结构体布局随 `__NPU_ARCH__` 变化，跨代迁移时不能假设字段恒存在。
- `unitFlag` 必须在 Mmad 与 Fixpipe 两侧一致地设为 2 或 3，单独设置一侧不会开启该特性。
