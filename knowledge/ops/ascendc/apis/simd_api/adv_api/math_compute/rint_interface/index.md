# Rint接口

- [GetRintMaxMinTmpSize](get_rint_max_min_tmp_size.md)：在host侧获取Rint接口预留或申请临时空间的最大和最小值，用于Tiling参数传递
- [GetRintTmpBufferFactorSize](get_rint_tmp_buffer_factor_size.md)：获取Rint接口的maxLiveNodeCount和extraBuf，用于推算算子单次最大计算元素数量
- [Rint](rint.md)：获取与输入数据最接近的整数，等距时取偶数
- [Rint接口](rint_interface.md)：按元素取最接近的整数，同等接近时取偶数，并提供临时空间大小获取接口。
