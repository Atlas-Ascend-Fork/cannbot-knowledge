# 归约操作

- [Mean接口](mean_interface/index.md)：在host侧获取Mean接口计算所需最大和最小临时空间大小，供Tiling参数选择。
- [ReduceAll接口](reduce_all_interface/index.md)：在host侧获取ReduceAll接口计算所需的最大和最小临时空间大小，用于选择合适的空间作为Tiling参数传递到kernel侧。
- [ReduceAny接口](reduce_any_interface/index.md)：在host侧获取ReduceAny接口计算所需的最大和最小临时空间大小，用于选择合适的空间作为Tiling参数传递到kernel侧。
- [ReduceMax接口](reduce_max_interface/index.md)：在host侧获取ReduceMax接口所需的最大和最小临时空间大小，当前最大值等于最小值，供开发者选择Tiling参数。
- [ReduceMean接口](reduce_mean_interface/index.md)：在host侧获取ReduceMean接口所需的最大和最小临时空间大小，当前最大值等于最小值，供开发者选择Tiling参数。
- [ReduceMin接口](reduce_min_interface/index.md)：在host侧获取ReduceMin接口计算所需的最大和最小临时空间大小，用于选择合适的空间作为Tiling参数传递到kernel侧。
- [ReduceProd接口](reduce_prod_interface/index.md)：在host侧获取ReduceProd接口计算所需的最大和最小临时空间大小，用于选择合适的空间作为Tiling参数传递到kernel侧。
- [ReduceSum接口](reduce_sum_interface/index.md)：在host侧获取ReduceSum接口所需的最大和最小临时空间大小，当前最大值等于最小值，供开发者选择Tiling参数。
- [ReduceXorSum接口](reduce_xor_sum_interface/index.md)：在host侧获取ReduceXorSum接口计算所需的最大和最小临时空间大小，用于选择合适的空间作为Tiling参数传递到kernel侧。
- [归约操作](reduction_operations.md)：归约操作接口导航页，涵盖Sum、Mean、ReduceSum、ReduceMax、ReduceMin等沿指定维度的归约计算接口。
- [Sum接口](sum_interface/index.md)：在host侧获取Sum接口所需的最大和最小临时空间大小，当前最大值等于最小值，供开发者选择Tiling参数。
