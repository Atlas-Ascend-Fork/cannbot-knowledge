# C++标准库

Ascend C 提供的 C++ 标准库子集导航，包含算法（algorithms）、数学函数（math_functions）、容器函数（container_functions）、类型特性（type_traits）和通用工具（general_utils）五部分。该子集经过裁剪以适配 AICore 编程环境，可在核函数中使用的标准库功能需标记 aicore。
