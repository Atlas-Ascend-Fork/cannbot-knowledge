# C++标准库

- [算法](algorithms/index.md)：比较相同数据类型的两个数，返回最大值。
- [容器函数](container_functions/index.md)：get的作用是从tuple容器中提取指定位置的元素。
- [通用工具](general_utils/index.md)：index_sequence是Ascend C提供的一个类模板，用于生成一个编译时的整数序列，适用于模板元编程。 make_index_sequence是Ascend C提供的一个模板，通常使用make_index_sequence创建一个index_sequence类型的对象，用于生成一个从0到N-1的整数序列。
- [数学函数](math_functions/index.md)：获取输入数据的绝对值。
- [Utils API类型特性](type_traits/index.md)：在程序编译时，为指定类型添加const限定符，可以用于在编译时进行类型转换。
