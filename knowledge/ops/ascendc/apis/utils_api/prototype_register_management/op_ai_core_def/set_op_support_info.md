# SetOpSupportInfo

## 功能说明
注册算子切分信息函数。当算子的切分信息属于特殊类型，可以在算子实现文件里实现算子切分信息函数并注册，开发者需要自己按照一定的规则填写算子输入、输出的可以被切分的轴信息。
