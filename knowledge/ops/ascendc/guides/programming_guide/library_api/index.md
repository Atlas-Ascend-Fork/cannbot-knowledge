# 类库API

- [advanced api](advanced_api/index.md)：高阶API基于单核对常见算法进行抽象和封装，实现了一些常用的计算算法，旨在提高编程开发效率。高阶API一般通过调用多种基础API实现。高阶API包括数学计算、矩阵计算、激活函数等API。
- [basic api](basic_api/index.md)：连续计算API，支持Tensor前n个数据计算。针对源操作数的连续n个数据进行计算并连续写入目的操作数，解决一维tensor的连续计算问题。
- [编程接口概述（库API）](programming_interface_overview.md)：>本章提供编程API的概述。具体API参考见Ascend C API。
- [Utils API（库API）](utils_api.md)：Ascend C开发提供了丰富的通用工具类，涵盖标准库、平台信息获取、上下文构建、运行时编译及日志输出等功能，支持开发者高效实现算子开发与性能优化。
