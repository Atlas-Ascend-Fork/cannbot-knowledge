# 性能优化策略：逐行归约存树模式 + 定点事件同步（减全排空次数）

> 单一优化点：向量端逐列块做逐行归约（逐行最大值/最大绝对值/求和）且每块后用全排空同步的路径，把「每块一次全排空」改为「每块结果存到片上缓冲不同偏移 + 循环外树形合并 + 块内跨流水依赖用定点事件表达」，把全排空次数从块数次降到零。
>
> **算子/管线无关性：** 适用于任意"分块逐行归约 + 块间同步"的向量核路径（归约结果供后续逐行缩放等使用），不限算子、不限归约算子种类。前提：块内唯一的跨流水依赖是"片外读入→向量计算"，且片上缓冲存得下全部块的归约结果。

---

## 1. 原理

术语（先定义后用）：

- **全排空**：等待所有流水线的所有在飞指令全部完成的重量级同步；排空范围是全部流水线，代价远大于必要同步。
- **定点事件**：只同步指定的两条流水线（如"片外读入流水→向量计算流水"）的轻量级事件同步原语。
- **存树模式**：每个块的归约结果写到片上缓冲的不同偏移（不覆盖前一块），形成一棵"待合并的叶子数组"，最终在循环外一次性树形合并。

基线写法中，每块的整块归约后紧跟全排空——因为归约结果写回片上缓冲是异步的，紧邻的读取指令会读到旧值，只能用全排空兜底。但全排空排空所有流水线，同步范围远超必要。

| 机制 | 利用方式 |
|---|---|
| 归约结果存不同偏移 | 每块结果存到片上缓冲的不同偏移，块间互不覆盖，无需块间即时可见 |
| 树形合并（向量流水内自动同步） | 循环外用普通向量归约指令逐块合并，同一流水线内部自动保序，无需额外同步 |
| 定点事件 | 块内只同步「片外读入 → 向量计算」两条流水线，不等其它流水线 |

定性归因（相对）：标量/同步开销下降——每次全排空有固定开销，块数次排空累计可观；改为定点事件后每次只付两条流水线的同步开销，块数越多省得越多。

### 1.1 精度代价

精度不变：归约数学等价——每块的归约结果相同，树形合并只是改变合并次序（对最大值类归约严格等价；对求和类注意合并次序的浮点舍入差异，需验证）。实测全量用例输出逐位一致。

归约结果写回异步是真实陷阱：存树模式要求每块结果存不同偏移——若偏移重叠（同地址），后块写回覆盖前块结果。验证方法见第 3 节反模式。

## 2. 性能问题模式

低效基线：每块整块归约 + 全排空，块间串行：

```text
# 基线：每块归约后紧跟全排空
for block in range(block_count):
    whole_row_reduce(reduce_store[block * single_area], load_area)   # 整块逐行归约
    drain_all_pipes()                                                 # 全排空（所有流水线）
```

块数多（列宽大、分块细）时累计排空开销可观。

典型症状（剖析工具 / 算子概览）：

- 标量/同步开销占比异常高（全排空开销随块数累计）。
- 每块的归约与排空串行，块间无重叠窗口。

---

## 3. 正确性红线

- **归约结果必须存不同偏移**：每块存到"块号 × 单核行数"的不同偏移，而非同一地址。偏移重叠 → 后块写回覆盖前块 → 归约值偏小 → 输出错（缩放不足，可能饱和）。
- **树形合并在循环外**：循环内只存不并；循环外一次性逐块合并。若在循环内合并（每块都并到同一地址）→ 需要全排空保证前一块已写回 → 退回基线。
- **定点事件替代全排空的前提**：块内唯一的跨流水依赖是「片外读入 → 向量归约」。若还有其它跨流水依赖（如片内写回后再读），只用定点事件不够。
- **反模式（存树 + 循环内合并 + 循环外不排空）**：合并指令读到旧值（写回未完成）→ 归约错 → 精度崩。
- **反模式（插桩掩盖问题）**：逐块插桩会引入排空时序开销 → 精度"恢复"（掩盖了异步写回问题）→ 误判为已修复。定位口诀：不插桩时错、插桩时对 = 同步/覆盖问题，不是计算问题。

---

## 4. 泛化条件

适用（满足任一即可尝试）：

- 向量端逐列块做逐行归约类操作（求最大/求和/最大绝对值等）且每块后全排空的路径。
- 归约结果可分配到片上缓冲不同地址（存树），跨块最终归约可用循环外树形合并完成。

不适用 / 需退回：

- 块内除「片外读入 → 向量归约」外还有其它跨流水依赖（定点事件不够，需全排空）。
- 片上缓冲不足以存「块数 × 行数」个归约结果（存不下树）。
- 求和类归约且合并次序改变导致舍入差异超阈值（需先验证或按块序合并）。

---

## 5. 实施步骤

1. 每块的整块归约结果写到片上缓冲的不同偏移（偏移 = 块号 × 单核行数）。
2. 块内「片外读入 → 向量计算」之间用定点事件（只同步这两条流水线）替代全排空。
3. 循环外树形合并：从第一块起逐块用普通向量归约指令合并到运行值。

```text
# 优化后：存不同偏移 + 块内定点事件 + 循环外树形合并
for block in range(block_count):
    wait_fixed_event(load_to_compute)                                # 定点事件（替代全排空）
    whole_row_reduce(reduce_store[block * single_area], load_area)   # 每块存不同偏移
running = reduce_store[0]
for block in range(1, block_count):                                  # 循环外树形合并
    running = vec_max(running, reduce_store[block * single_area])    # 向量流水内自动同步
```

4. 最终归约结果交给后续逐行缩放等消费方。

关键参数来源：单核行数 = 行分块大小 ÷ 向量核数；块数 = 列宽 ÷ 归约列宽（向上取整，归约列宽是整块归约的列粒度）。

## 7. 验收标准

精度：全量用例输出与基线一致（含多块用例；求和类允许在阈值内的次序性差异）。若输出饱和或缩放异常 → 优先查偏移重叠（归约覆盖）。

性能（方向性判据）：标量/同步开销下降（全排空次数从块数次降到零）；块间不再串行排空。若标量开销未降 → 全排空非该路径瓶颈，重新归因。

回退条件：精度崩且定位为偏移重叠（修偏移算式后仍不稳）；块内存在其它跨流水依赖导致定点事件不足；标量开销未改善（瓶颈在别处）。

## 检索卡（短卡）

动作：将每块后全排空改为归约结果分偏移存树，并在片外读入到向量计算间用定点事件。
适用：逐列块逐行归约后全排空，或归约结果可分配到片上不同地址时可尝试。
限制：各块结果必须写入“块号×单核行数”的不同偏移，禁止地址重叠。
范围：向量端逐列块的逐行最大值、最大绝对值或求和路径。
检索词：逐行归约、存树、全排空、定点事件、片外读入、向量计算。
机会：逐列块归约后均执行全排空，导致块间串行。
