# 性能优化策略：矩阵乘结果随路转换直出（消除中间缓冲与独立转换段）

> 单一优化点：矩阵计算单元的浮点累加结果回写全局内存的流水（结果回写流水）自带类型转换能力——配置转换模式后，让它在写出的同时直接产出目标低精度类型（半精度/bf16），消掉「先写浮点中间缓冲、再由向量核读回 + 独立转换 + 写回」的中转，该路径向量核完全不参与。代价是转换精度边界更窄，必须按安全子集窄化启用。
>
> **算子/管线无关性：** 适用于任意「矩阵计算单元浮点累加结果 → 全局内存输出需转半精度/bf16」的融合 kernel，只要结果回写流水支持随路转换、且输出落在安全子集内。不限于任何具体算子形态。

---

## 1. 原理

术语（先定义后用）：

- **随路转换**：结果回写流水在写出的同时顺带完成类型转换，不新增独立计算段。
- **独立转换路径**：由向量核显式发转换指令的常规路径，舍入有效尾数更宽。
- **结果回写流水**：矩阵计算单元把累加器内容写回全局内存的专用流水，可配置转换模式。
- **中间缓冲（workspace）**：矩阵计算单元与向量核之间经全局内存交接的缓冲，是本策略要消掉的中转。

| 机制 | 利用方式 |
|---|---|
| 回写流水自带转换 | 配置转换模式后直接写出目标 dtype，向量核不参与该路径 |
| 消中转 | 省去浮点中间缓冲的一写一读，以及向量核整段独立转换 |
| 安全子集判定 | 只有无偏置、形状全对齐、输入规整的输出走直出，其余回退独立转换 |

**精度边界（本策略核心知识）**：随路转换的舍入模式有效尾数位数显著低于独立转换路径（量级：约 10bit 对约 23bit）。规整输入两者结果一致；精度敏感输入（大动态范围、相消后小值、极值）随路路径超差。因此不能全量开启，必须窄化到安全子集（第 3、4 节）。

---

## 2. 性能问题模式

低效基线：所有输出（包括无偏置且形状规整的输出）一律经中间缓冲 + 向量核独立转换：

```text
# 基线：所有输出经中间缓冲 + 向量核独立转换
mm_block(..., middle_store)            # 浮点累加结果写全局内存中间缓冲
vec_epilogue(middle_store, out)        # 向量核：读回 + 类型转换 + 写回输出
```

开销源：

- **中间缓冲一写一读**：浮点结果经全局内存往返。
- **向量核一段转换**：读回、转换、写回三步。
- 症状：profiling 中向量核段占比可观、全局内存流量含中间缓冲往返；无偏置规整输出「白白」多付这两项。

---

## 3. 正确性红线

### 3.1 随路转换精度不够（最致命）
随路舍入的有效尾数显著少于独立转换路径（约 10bit 对约 23bit 量级）。**有相消、极值、非规整输入的路径不能走随路直出**，必须回退向量核独立转换。实测决策链是「先全量开 → 精度崩 → 按边界窄化到安全子集」——这条链本身是策略的一部分：不要只抄「开了更快」的结论而不带边界，也不要因为全量开崩了就整体放弃（安全子集内是净收益）。

### 3.2 浮点输出不能配转换
转换模式必须按**目标 dtype** 选：目标半精度 → 配浮点转半精度；目标 bf16 → 配浮点转 bf16；**目标浮点 → 不配转换**。给浮点输出配了转换会把结果错转成半精度（类型错、整体错误）。

### 3.3 写子块的目的步进
结果回写流水写「大矩阵的子块」时，目的地址步进必须传**完整输出列宽**（元素单位），不是分块列宽；传错会写错行（数据错位，且往往不报错）。

### 3.4 对齐条件
直出快速路径要求行、列都按分形边长对齐（无尾块）；有尾块的行需要向量核掩码处理，回退中转路径。

### 3.5 转换模式取值来源
转换模式的取值来自全局模式枚举，不是算子层命名空间下的类型别名——配置时注意取值作用域，用错会编译失败，按编译报错对齐即可。

---

## 4. 泛化条件

安全子集（须**同时**满足才走直出）：

| 条件 | 要求 |
|---|---|
| 无加性偏置 | 回写流水不带加法；有偏置走「bias 进累加器初值」策略（分支二） |
| 形状全对齐 | 行、列都按分形边长对齐，无尾块 |
| 目标 dtype 低精度 | 半精度或 bf16；浮点输出不配转换，仍走中转 |
| 输入规整 | 无相消/极值/大动态范围，或经验证随路误差在阈值内 |

三分支互斥（与「bias 进累加器初值」策略的关系，按输出路径整体决策）：

| 分支 | 条件 | 走法 |
|---|---|---|
| 一 | 无 bias | **本策略**：直出 + 随路转换，向量核不参与 |
| 二 | 有 bias 且偏置 dtype 进初值的组合支持 | 走「bias 进累加器初值」：bias 作累加器初值 + 向量核只做类型转换 |
| 三 | 有 bias 但 dtype 组合不支持 | bias 与类型转换都留在向量核收尾段（基线形态） |

不适用：精度敏感输入（相消/极值）；行列有尾块；输出为浮点；向量核在收尾段还有其它必要后处理（本策略只消「纯转换」的中转）。

---

## 5. 实施步骤

1. 先做安全子集判定：无偏置、行列全对齐、目标低精度、输入规整——四者同时成立才走直出。
2. 加直出路径：结果回写流水配置按目标 dtype 的转换模式，直接写输出地址（子块目的步进 = 完整输出列宽）。
3. 加分支调度：满足安全子集走直出，否则保留原中转路径（原路径代码不删，作回退）。
4. **按决策链验证精度**：先在候选范围内全量开启 → 跑精度 → 对超差的输入类别收窄边界 → 最终只留安全子集在直出路径。
5. 退回路径：把安全子集判定收紧为恒不成立 → 全部回中转 + 向量核独立转换，与基线同构，作为精度对拍基准。

```text
# 分支骨架
if no_bias and rows_aligned and cols_aligned:
    mm_block_direct(..., out, cast_mode=by_target_dtype, col_pitch=full_width)
else:
    mm_block(..., middle_store)          # 浮点写中间缓冲
    vec_epilogue(middle_store, out)      # 向量核读回 + 独立转换 + 写回
```

## 7. 验收标准

精度（方向性判据）：

- 安全子集内误差达标；子集外走回退路径后**全量**达标。
- 特别验证：精度敏感输入（相消/极值）实际走的是回退路径；浮点输出未被配转换（无「类型错」症状）。
- 写出数据无行错位（抽检子块目的步进按完整列宽）。

性能（方向性判据）：

- 安全子集内耗时下降（消一次中间缓冲往返与一段向量核工作），该路径向量核不参与。
- 若直出后耗时未降 → 瓶颈不在中转，重新归因。

回退或缩小边界的条件：精度敏感输入超差（收窄子集或全回退）；发现子集外输入被误调度到直出（补判定条件）；耗时未降（重新归因）。

与其它策略的关系：与「bias 进累加器初始值」互斥（按三分支整体调度）；与切分/加载侧优化（如右矩阵单指令加载）互不冲突，可叠加。

## 检索卡（短卡）

动作：配置结果回写流水的目标dtype转换模式，将累加结果边转换边直接写出，去除中间缓冲和独立转换段。
适用：仅在无偏置、行列全对齐、目标为低精度且输入规整时直出。
限制：行存在尾块时须由向量核掩码处理并回退中转路径。
范围：矩阵计算单元浮点累加结果的全局内存回写路径。
检索词：结果回写流水、随路转换、目标dtype、中间缓冲、向量核独立转换。
机会：无偏置且形状规整的输出仍统一经过中间缓冲和向量核独立转换。
代价：随路舍入有效尾数较少，约10bit，而独立转换路径约23bit。
