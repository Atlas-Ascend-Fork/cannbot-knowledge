# 性能优化策略：预取深度按片上缓存余量动态定尺（加深搬运与计算的重叠窗口）

> 单一优化点：手写矩阵乘类内核中，一个操作数片上常驻、另一操作数沿归约维分槽预取时，把预取队列的深度从固定值改为按「片上缓存总量 − 常驻操作数字节 − 安全余量」除以单槽字节动态上浮（带上限），让全局内存到片上的搬运与片内搬入/计算的重叠窗口加深，抬升核利用率。
>
> **算子/管线无关性：** 适用于任意「常驻操作数 + 流式操作数分槽预取 + 矩阵乘累加」的手写内核，不限操作数角色（左/右皆可）与具体算子。

**术语**：

- **常驻操作数**：整个生命周期留在片上的操作数（通常体积小、被反复消费）。
- **流式操作数（预取操作数）**：沿归约维切成**面板（单槽）**逐段预取上片的操作数；单槽字节 = 一个面板的分块尺寸 × dtype 字节宽。
- **预取深度**：预取队列可容纳的面板槽数；深度决定全局搬运能领先消费端多少级。
- **每核多任务**：一个核被分配多个任务依次执行的调度形态；跨任务的队列槽复用是深度上限的重要来源。

---

## 1. 原理

归约维循环里，流式操作数面板的搬运链是「全局内存到片上 → 片内转置 → 矩阵乘累加」三段流水。队列深度决定全局搬运能领先消费端多少级：

- 队列多级：填满各级槽后，全局搬运才因槽满阻塞；消费端每取走一级，搬运立刻补一级。
- 三段独立流水：只有深度达到一定级数时，下一面板的全局搬运才能与当前面板的片内转置/计算并行。
- 片上缓存余量：常驻操作数字节 + 深度 × 单槽字节 ≤ 缓存总量 − 安全余量；深度可占用的就是缓存空余部分。

深度上浮后，全局搬运由串行（每面板等计算吃完）变为深窗口并行，计算等待搬运的停顿减少，核利用率抬升。

### 1.1 精度不变性

精度不变：计算序列一字未改，仍是逐面板搬入、转置、累加；深度只改搬运调度窗口，不改参与计算的数据与次序。深度不超过上限时，全量用例输出应与优化前逐位一致——这也是验收的硬判据。

---

## 2. 性能问题模式

深度固定为较小值时，归约循环的搬运链重叠窗口很浅——每消费完一个面板，全局搬运才开始搬下一个；若搬运吞吐跟不上消费速度，计算端出现等待，核利用率偏低。

典型症状（剖析工具 / 算子概览）：

- 核利用率明显低于同形状的库实现。
- 全局搬运时长占比高且与计算大致串行（计算后接搬运，无重叠窗口）。
- 相同计算量的乘加指标与参考一致，说明瓶颈在搬运调度而非计算量本身。

---

## 3. 正确性红线

- **深度有精度天花板（最重要约束）**：实测深度超过上限会在「每核多任务」的大规模行数用例触发精度损坏（输出饱和）。根因是手写队列跨任务槽复用的残留依赖。上限取实测安全值（仍大于原始深度，收益已到手）。若改用库实现（调度器管片上流水）则深度可更高。
- **不是深度越大越好**：实测更大深度反而更慢（队列跨任务缺陷放大 + 片上缓存接近满）。
- **安全余量不可省**：常驻操作数 + 队列把片上缓存占满会触发性能悬崖（同内核曾把常驻预算提高使缓存恰满，性能明显退化）。安全余量取实测安全值。
- **反模式（硬编码缓存容量）**：把某芯片的缓存容量写死带去别的芯片 → 溢出或浪费；必须按目标芯片硬件规格取。
- **反模式（深度上浮后只验小规模行数）**：深度超上限的精度损坏只在大规模行数 + 每核多任务出现，小规模单任务全过 → 只验小规模会漏掉损坏。

---

## 4. 泛化条件

适用（满足任一即可尝试）：

- 手写矩阵乘内核：一个操作数片上常驻、另一操作数沿归约维分槽预取、逐面板累加（非库实现；库的调度器已管片上流水，深度不由手写代码控制）。
- 归约维越长、单槽越小，收益越大。

不适用或需退回（负向边界）：

- 库实现的矩阵乘（深度由库定）。
- 片上缓存无余量（常驻操作数已占满）。
- 单槽过大（余量除不尽一个槽，深度上浮不动）。

深度上限必须按目标芯片的片上缓存容量与实测精度边界取，不得硬编码。

---

## 5. 实施步骤

1. 队列模板上界放开（如从较小的固定级数放开到更大的模板上界）。
2. 初始化时删除固定深度的缓冲初始化，改为先算深度、再按深度初始化。
3. 深度算式：可用字节 = 缓存总量 > 安全余量 + 常驻操作数字节 ? 缓存总量 − 安全余量 − 常驻操作数字节 : 0；深度 = 可用字节 ÷ 单槽字节；小于下界取下界，大于上限取上限。
4. 归约循环、入队/出队/释放逻辑一字不改（深度由队列自动生效）。

关键参数来源：缓存总量来自目标芯片硬件规格（不得硬编码）；安全余量来自实测的缓存占满性能悬崖；深度上限来自实测精度边界；单槽字节由分块尺寸与 dtype 派生。

| 安全余量 | 是否有已知的缓存占满性能悬崖？余量值多少？ |

任一项无法回答，不实施。

## 7. 验收标准

精度（方向性判据）：

- 全量用例输出与优化前逐位一致，**必须含大规模行数 + 每核多任务用例**（只验小规模会漏掉深度超限的精度损坏）。
- 若出现输出饱和 → 深度超上限，退回更小值。

性能（方向性判据）：

- 核利用率抬升（搬运与计算出现重叠窗口）。
- 若未抬升 → 单槽过大（余量除不出槽）或常驻操作数占满缓存（无余量），按泛化条件的负向边界退回。

回退条件：大规模行数精度损坏（深度超天花板）；性能未提升（缓存余量不足，深度无法上浮）。

## 检索卡（短卡）

动作：将固定预取深度改为按片上缓存余量定尺，先计算深度，再按所得深度初始化。
适用：手写矩阵乘中，一侧常驻片上，另一侧沿归约维分槽预取并逐面板累加。
限制：深度不得超过精度安全上限，尤其需防止每核多任务的大规模行数用例输出饱和。
范围：归约循环中流式操作数面板的三段搬运链。
检索词：预取队列深度、归约维、全局到片上、片内转置、矩阵乘累加。
机会：固定小深度使搬运重叠窗口浅，搬运跟不上消费时计算端等待。
