# 性能优化策略：无损值序与位置联合编码键

> 单一优化点：在不损失有效值位的条件下，把单调数值键与并列优先位置编码合成整数键，使一次Max同时确定值序与位置。

## 1. 原理

对可表示值域构造严格单调整数编码，再将并列位置编码放入已证明空闲的低位。若整数比较方向为取最大值，而并列要求较小位置优先，低位可以使用逆序位置编码。

设可用键宽为W、位置字段占q位，必须证明值域在高位中的编码无碰撞、低q位确实不携带有效信息，且位置范围可以由q位覆盖。低精度数精确提升到宽浮点后可能产生空闲尾数位，但不能据此对原生宽浮点直接清尾数。

键只用于比较和恢复位置，最终数值从原始值镜像取得。建键、临时缓冲、特殊值规范化及恢复位置都属于全调用成本；单独编码未证明收益时，作为条件性前置而非独立加速结论。

## 2. 性能问题模式

- 每个候选反复执行值比较、最大值更新和并列索引选择。
- 值与位置状态分离，阻碍使用更便宜的整数归约。
- 输入位型有可证明空闲字段，却未转化为联合比较能力。

## 3. 正确性红线

- 逐值域证明单调性和无碰撞，确认硬件整数比较为所需的有符号或无符号序。
- 禁止丢弃有效尾数位以腾出位置字段；位置宽度和编码乘移不得溢出。
- NaN优先级、无穷、正负零等价类先按契约规范化；若要求等值最小位置，不能让零的符号位改变优先级。
- padding和失效键须严格排在有效项之外；无法保留独立编码时加入有效位。
- 键不能代替数值输出；输出应按恢复的位置读取原值位型。

## 4. 泛化条件

适用：值域可无损编码并留足位置字段，位置范围有界，硬件整数比较语义明确。

不适用或需回退：值位与位置位无法同时无损容纳、比较器语义不明、特殊值等价类无法编码，或建键和缓冲成本无法摊销。

## 5. 实施步骤

1. 定义值的全序或等价类、位置优先级及失效状态。
2. 推导位预算和单调映射，对全部边界证明不碰撞。
3. 构造联合键，比较后解码位置并读取原值。
4. 分别验证最小/最大位置、重复值、特殊值、padding及失效键。
5. 按重复比较次数比较建键成本和内层节省，选择有证据的分派边界；无稳定独立收益则仅条件采用。

## 6. LLM 前置问题

- 低位空闲来自精确表示证明，还是未经验证的近似？
- 位置字段和有效标记是否仍有空间？
- 正负零和NaN的规范化是否保持位置契约？
- 建键及附加缓冲的成本由多少次比较摊销？

## 7. 验收标准

正确性：保持原接口、精度阈值和输出布局，覆盖空域、尾部、容量边界、重复值和所有受影响分支。先验证语义与合法访问，再判断收益；不放宽阈值以迁就新路径。

性能：冻结前后源码和二进制，同设备、同输入、同工具链，依照配对测量协议比较设备Task Duration；每个输入域先取均值，再按约定跨域聚合，保留域内回归和剔除补测记录。迁移到新的资源、布局或数值域必须重新验证。

决策：资源、越界、同步或精度检查失败时修复或回退；没有可信收益时保留原路径。组合验证不能推出任何子动作独立有效。

## 8. 与相邻策略的边界

与[stable-narrow-score-wide-key-sort](stable_narrow_score_wide_key_sort.md)的多轮窄分数稳定排序不同，本策略把值与位置无损合入同一比较键，服务于单轮归约内层；不要求排序载荷跨轮稳定传播。

## 检索卡（短卡）

动作：把可无损编码的值序与并列优先位置合为整数键，用一次Max联合确定值和位置。
适用：位预算能无损容纳值序与位置，位置有界且整数比较语义明确。
限制：不得清除有效尾数；规范化特殊值与零；失效键独立，输出按位置读取原值。
范围：值序与位置联合比较、极值候选筛选。
检索词：单调映射、uint32、位预算、Max、Gather、有效位
机会：值比较和索引维护反复占用内层指令。
代价：建键与缓冲可能抵消收益；单独收益未证实时仅条件采用。
