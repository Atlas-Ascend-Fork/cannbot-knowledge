# 性能优化策略：跨步切片的线程独占有界状态与相邻访存

> 单一优化点：把共享状态下串行推进的独立切片，改为一个 SIMT 线程独占一个切片的小规模有界状态；让相邻线程对应相邻内层坐标，以跨切片并行和相邻访存替代切片内协作。
> 数据流范围：跨步轴上的独立切片扫描、有限容量候选维护及有界流式状态更新。已验证硬件范围为 Ascend 950（A5）；其它架构不继承性能结论。

## 1. 原理

对物理连续布局的逻辑视图 [O,D,I]，D 为扫描方向，O×I 个切片相互独立。线程独占切片 (o,i)，依次访问 offset=(o×D+d)×I+i；相邻线程优先分配相邻 i，在同一 d 时读取相邻地址。物理非连续布局应按真实 stride 计算，不能套用该公式。

每个线程维护容量 C 的候选键、配对整数索引及有效计数，流式读入后按接口比较器更新，全部扫描结束后写回自己的输出区。线程可通过 grid-stride 继续认领其它切片，认领新切片时必须重置状态。没有线程间依赖的状态更新不需要共享直方图、跨线程原子或每轮块同步。

机制收益来自跨切片并行及减少共享状态交接，不来自宣称所有局部数组都能驻留寄存器。编译器可能将数组溢出到局部内存；容量、键宽和线程数必须联合受资源报告与实测约束。

## 2. 性能问题模式

- 大量切片互不依赖，却由一个线程组共享状态并按切片逐个处理；其它线程等待状态更新。
- 跨步扫描的单个切片访问分散，相邻线程没有沿内层连续坐标分配，无法利用同轮相邻访问。
- 每个切片只需较小状态，协作、原子与同步成本超过其扫描和更新成本。

状态随 C 增长，插入式维护的比较工作随 D×C 增长。大容量、切片不足或内层连续性差时，线程独占不一定有收益。

## 3. 正确性红线

- 切片与输出必须唯一归属，尾线程保护每次读写；新任务重置有效计数，不能让初始化哨兵冒充真实元素。
- 候选键与索引同步移动，重复值仍代表不同输入位置。若接口要求稳定次序，将原始索引纳入一致比较器；浮点 NaN、无穷与正负零遵守接口语义。
- 整数键必须保持原宽度下的精确顺序，禁止用浮点代理比较宽整数。宽键与索引分开存储，未经证明不得压进不足位宽的复合整数。
- 输入地址乘积、切片总数、扫描位置与输出索引分别校验宽度；不得因线程内状态较小就缩窄全局寻址。
- 若与其它阶段共享缓冲或存在跨线程消费者，必须重新证明可见性和生命周期，不能直接沿用独占路径的免同步结论。

## 4. 泛化条件

适用条件：切片之间无依赖；单切片状态小且容量有界；存在足够多切片；相邻内层坐标可分配给相邻线程；目标编程入口支持所需 SIMT 操作。

不适用或需回退：单个或少量长切片需要切片内并行；容量增长导致比较链或局部内存溢出主导；物理布局破坏相邻访存；输出存在重叠或跨切片依赖。

容量上限、启核数、线程数及路由阈值按目标 dtype、布局与编译资源确定，不复制某个实现的常数。与共享候选槽、向量 lane 更新或有界堆的区别在于状态归属和线程映射；不能仅因已有小容量候选算法就判定此机制已落地。

## 5. 实施步骤

1. 明确切片独立性、真实 stride、比较器与输出所有权，冻结原实现及正确性对照。
2. 为单线程构建有界状态和有效计数；按原精度更新键与整数索引，不先引入窄化或近似计算。
3. 将相邻线程映射到相邻内层坐标；用 grid-stride 覆盖切片集并保护尾部。
4. 联合调整容量、线程数与启核数，检查寄存器、栈、溢出及并发度。保留大状态或切片不足时的既有路径。
5. 对路由两侧分别验证精度并进行同轮配对性能测量，按实际资源与收益确定守卫。

## 6. LLM 前置问题

- 哪个维度被扫描，哪些维度形成独立切片？实际 stride 是否支持相邻线程相邻访存？
- 状态的键、索引及有效标记总字节是多少？编译后是否发生明显溢出？
- 线程独占能否去掉现有共享交接，还是仍存在隐含跨线程依赖？
- 状态增长或切片数下降时使用哪个已验证回退？

## 7. 验收标准与证据边界

检查值与索引对应、合法范围、无重复、输出次序及接口容差；覆盖重复值、极端整数、NaN、无穷、正负零、尾部、空域、容量边界与路由边界。

已归档的同设备、同输入、同编译配置 BAAB 两对测量证明整条线程独占路径改动有效；精度检查全部通过。历史总集合的几何平均加速约 1.48 倍，只说明该次实现及输入集合，不是任意切片或容量的收益承诺。线程映射与状态归属共同变更，未独立消融其贡献。

新工作负载须统计每个输入域的 device Task Duration，先在域内取均值，再按约定聚合；同时观察总耗时与未命中域回归。若局部内存流量、比较链或占用率恶化，应收缩容量守卫或回退。

## 检索卡（短卡）

动作：把独立跨步切片改为每个SIMT线程独占小规模有界状态，相邻线程沿内层连续坐标分配。
适用：切片无依赖且数量充足；状态小而有界；相邻内层坐标可并行访问；A5支持所需SIMT入口。
限制：键与索引配对且保留原精度；尾部不越界；大状态、切片不足或溢出主导时回退。
范围：跨步切片扫描、有限容量候选维护、有界流式状态更新。
检索词：SIMT、线程独占、grid-stride、相邻访存、有界状态、寄存器溢出。
机会：独立切片被共享状态串行推进，线程等待；少量状态更新仍付出原子与同步成本。
代价：容量增加拉长比较链并提高寄存器或局部内存占用，需按dtype和布局限定路由。
