# 性能优化策略：多 Pass 操作数平面驻留复用

> 库内状态：`active`。已在 A5 完成全量精度和稳定配对验证，进入可选择策略库。

> 单一优化点：固定多 Pass 计算反复装载同一组只读操作数平面时，在每个外层块开始一次性装入所需平面并驻留片上，各 Pass 仅按索引只读复用，最后一个消费者结束后统一释放。

## 1. 原理

若 Pass 表中多个阶段重复引用相同输入平面，逐 Pass 分配、装载和释放会重复占用 MTE2。将唯一平面连续排布在 L1，Pass 只选择平面偏移，可把装载次数降到唯一平面数，同时保持每个 Pass 的矩阵乘参数与累加次序不变。

## 2. 性能问题模式

- 多 Pass 的操作数索引表存在重复值。
- MTE2 占比高而矩阵计算利用率低。
- 相同地址在每个 Pass 被重新分配、搬入和释放。
- 唯一平面总量可驻留片上。

## 3. 正确性红线

- 驻留平面必须只读；任何 Pass 写入共享区域都会污染后续消费者。
- 唯一平面的连续布局、分形对齐和偏移必须逐项验证。
- 释放延迟到最后一个异步消费者真正完成，不能只依据主机循环结束。
- 每个 Pass 的 L0 装载、矩阵乘参数、初始化和累加顺序保持不变。
- 驻留总容量按对齐后峰值核算并保留安全余量。

## 4. 泛化条件

适用：固定多 Pass、操作数平面重复引用、MTE2 绑定、唯一平面集合可驻留。

不适用：平面由前序 Pass 原地更新；索引运行时不规则且无法预取；容量不足；重复加载不是关键路径。

## 5. 实施步骤

1. 列出每个 Pass 引用的操作数平面并去重。
2. 为唯一平面设计连续、对齐的片上布局。
3. 外层块开始时一次装载全部唯一平面。
4. Pass 循环按只读偏移选择平面，保留原 L0 与矩阵乘链。
5. 在最后一个消费者完成后统一释放，尾块独立验证。

## 6. LLM 前置问题

1. Pass 索引表中哪些平面重复、各重复多少次？
2. 唯一平面的对齐后总容量与安全余量是多少？
3. 平面是否在所有 Pass 中只读？
4. 最后一个异步消费者的完成边界如何证明？
5. 预计减少的 MTE2 字节和事务是否位于关键路径？

## 7. 验收标准

- 全量精度一次通过，逐 Pass 数值顺序不变。
- 来源验证整体验证加速比 `1.0654x`，目标多 Pass 计算段获得 `1.39x–1.57x` 改善。
- 稳定配对同向，非目标直接路径保持不变。
- 剖析确认实际装载次数收缩到唯一平面数，MTE2 占比下降。

## 检索卡（短卡）

动作：固定多 Pass 计算在每个外层块开始一次性装入去重后的唯一操作数平面并驻留片上，各 Pass 仅按索引只读复用，最后消费者结束后统一释放。
适用：固定多 Pass、操作数平面重复引用、MTE2 绑定、唯一平面集合可驻留。
限制：驻留平面必须只读；连续布局、分形对齐与偏移逐项验证；释放延迟到最后异步消费者真正完成；每 Pass 装载与累加顺序不变；容量留余量。
范围：固定多 Pass 计算的操作数平面装载。
检索词：多 Pass、平面去重、L1 驻留、只读复用、MTE2 占比、统一释放。
机会：Pass 索引表存在重复值，相同地址每 Pass 被重新分配、搬入和释放，MTE2 占比高矩阵计算利用率低。
