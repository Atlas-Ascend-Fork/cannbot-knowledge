# 性能优化策略：GM→L1 面板宽搬运合并（按归约行块整行带宽 Nd2Nz，砍小搬运指令数）

> **来源：A5 自由探索实测（bmm_bf16_bf16_o32，2026-09-11，device 2）**
> direction_key: `mte2::b-panel-wide-nd2nz-kblock-copy::main-loop`
> 证据：<AOA_ROOT>/AOA/AOA_skill/aoa_out/bmm_bf16_bf16_o32/loop_<run-id>/explore/direction_001/evidence_run/final/bench_paired.log
>       （A=冻结 champion 重建 .so（explore/_C_champion.so，含 01/07/08 已采纳策略），B=本方向改造后 .so，2 对平衡交替，22 case，B_over_A_geomean=0.960589）
> 实测：1.0410 x（相对冻结 champion 重建 .so），精度 PASS（22/22，cann-bench MERE/MARE 口径，零修复轮一次通过），改动前 bad_ratio 情况如证据所述（22 case 全 PASS，无精度修复轮）

## 原理

矩阵乘主循环中，非驻留侧操作数面板（如 B 面板 [K, N]）从全局内存经数据搬运流水（MTE2 类）以 Nd→Nz 分形重排放上片上（L1 级）。若基线按「每个分形列带 × 每个归约行块」为粒度发起小搬运——baseN=128、baseK=48 时每个 K-tile 需 8 列带 × 3 行块 = 24 次 16×16 小搬运（fp32 每次 1KB，GM 源每行连续段仅 64B、行距 totalN×4B）——小搬运指令在 MTE2 队列中串行发射，发射开销与碎片化突发密度成为主循环瓶颈，且计算侧指令数（对照侧每 K-tile 仅 1 次大搬运）反差显著。

机制：把搬运粒度从「列带 × 行块」改为「归约行块整行带宽」——每个 16-K 行块发起一次 d 轴横跨全部满列带的宽 Nd2Nz（16 行 × nUsed 列，nUsed=Align16(validN)），MTE2 指令数/K-tile 从 nBands×(kUsed/16) 降至 kUsed/16（实测 24→3，降 8 倍），GM 源每行连续段从 64B 升至 512B，突发密度提升；**GM 总字节数不变**，L0B 布局与矩阵计算单元入参不变，收益纯来自搬运指令合并与突发密度。

配套改动：L1 中该面板槽的布局从「按列带分槽」改为「按归约行块 × 分形紧排」（[kb 行][d1 分形]），内层 L1→L0 装载的源地址与块步进同步改写（源地址按新布局偏移、srcStride 以分形块为单位），装载目标布局与矩阵计算入参保持不变。

## 性能问题模式（哪些 profiling 信号说明该用）

- 某侧操作数 GM→L1 的搬运指令密度远高于对侧（实测：B 侧 24 次/K-tile vs A 侧 1 次/K-tile），且小搬运在搬运流水队列中串行发射。
- 单 K-tile 预算（kernel 时长 ÷ K-tile 数）显著高于单次矩阵乘估算耗时，差额指向搬运发射等待。
- 大 case（K-tile 多、面板宽）在 tiling/双缓冲/预取类策略用尽后仍零改善——既有机制族只改「搬多少、何时搬」，未改「一次搬多大」。
- GM 源每行连续段远小于可用突发宽度（64B vs 512B 量级），行距为大 stride。
- msOpProf PipeUtilization 中该搬运 pipe（aic_mte2 类）占比高、矩阵计算 pipe 占比低（口径注意：计数器为采样，短 kernel 可能取不到，改用理论带宽估算判据）。

## 正确性红线（什么情况下禁止用 / 必须回退）

1. **分形列距重叠红线**：d 轴一次横跨多列带的前提是该 dtype/形态下「块内仅单个 n1 分形块堆叠单槽」时分形紧排无重叠；若搬运形态在多 n1 块堆叠时存在 C0 列距重叠（窄 dtype 历史），禁止合并，保持逐带小搬运。合并前必须以目标 dtype 的分形语义复核。
2. **N 尾带单独处理**：validN 非 16 倍数时，尾带（<16 列）不得并入宽搬运一起算列数——d 轴原生补零到分形列距，须单独一次小搬运，且配合整槽预清零覆盖脏列区。
3. **K 尾 stale 行**：kUsed > kLen 时 [kLen, kUsed) 行是 stale 数据，累加轴脏数据不可容忍——须保留整槽预清零 + 搬运流水排空的旧路径；满块快路径仅在无尾带且无 K 尾时启用。
4. **L1 布局与内层装载源寻址必须同源改写**：只改外层搬运不改内层装载源偏移/步进，矩阵计算单元读到错位归约块，数值崩（这是布局错误，排空重试无效）。
5. **块偏移按块内完整元素数计**（含分形填充），不得按归约步长计。
6. **容量不额外膨胀但须复核**：布局重排后槽总字节不变（nUsed×kUsed 对齐后与原 nBands×kUsed×16 等价），但双缓冲份数叠加时仍按最坏组合重算。

## 泛化条件（dtype / shape / 流水线 / 算子类型）

- 流水线：aic_mte2（搬运发射/带宽瓶颈）；对任意「非驻留操作数面板 GM→L1 分形重排搬运」的矩阵乘内核适用，不限操作数角色。
- shape：面板列数大（列带数多）、归约行长（K-tile 内行块数多）时收益最大；每核单块、K-tile 极少的小 case 中性或小受益。
- dtype：换 dtype 须重查分形对齐下界与 C0 列距重叠条件（红线 1）；宽字节 dtype 的每行连续段增益更大。
- 前提：GM 总字节数不变、矩阵计算入参与 L0 布局不变的纯搬运形态改造——与块大小（tiling 档位）、双缓冲深度、预取深度类策略正交可叠加。
- 与 `02-matmul-block-reuse-min-memory-compute-ratio` 的关系：02 决定块多大，本条决定该块「一次怎么搬」；先按 02 选块，再按本条合并搬运。

## 实施步骤（从证据里的真实 diff 抽象成通用步骤）

1. 量化两侧操作数的搬运指令数/主循环迭代（代码级即可：列带数 × 行块数 vs 1），确认非驻留侧是发射密度热点。
2. 确认目标 dtype 的分形形态满足「单 n1 块堆叠单槽、d 轴紧排无重叠」（查装载语义或以全 1 输入实验判明），不满足则终止。
3. 把外层搬运循环从「列带外层 × 行块内层」重排为「行块外层」：每行块一次宽 Nd2Nz，dValue 横跨全部满列带；N 尾带单独一笔小搬运。
4. 同步改 L1 面板槽布局为 [归约行块][分形] 紧排，推导内层 L1→L0 装载的新源偏移（按块内完整元素数）与新步进（以分形块为单位）。
5. 保留条件化整槽清零路径：仅尾带或 K 尾时预清零 + 排空，满块快路径不清零（避免加倍搬运流量、打断双缓冲重叠）。
6. 全量精度用例（含尾带、非整除 case）一次过门，再走平衡交替配对复测。

## LLM 前置问题（应用前必须自问）

1. 非驻留侧每个主循环迭代的搬运指令数是多少？对侧是多少？比值是否显著（实测 24:1）？
2. 目标 dtype 下 d 轴横跨多列带是否分形紧排无重叠？依据是装载语义文档还是全 1 实验？
3. N 尾带与 K 尾的清零/排空旧路径是否保留并条件化？哪些 case 走旧路径？
4. L1 槽新布局的字节偏移算式是什么？内层装载的源偏移与步进是否同源重写？块偏移是否按含填充的完整元素数计？
5. 现有 tiling 档位下指令数降幅多少（nBands×kUsed/16 → kUsed/16）？收益上界（省下的发射时间 ÷ kernel 时长）是否超过噪声底？
6. 与已叠加的双缓冲/预取策略组合后，槽布局变化是否影响预取重叠窗口？

## 验收标准（编译 / 精度 / 性能判据，含噪声底口径与回退阈值）

- **构建**：编译通过，L1 面板槽字节总量与原布局等价（双缓冲份数计入）。
- **精度**：全量用例（含 N 尾带、K 尾、非整除）与基线一致一次通过；bad_ratio 无新增失败 case（实测 22/22 PASS、零修复轮）。
- **性能**：平衡交替配对（A/B .so 身份写明，A 侧为冻结 champion 重建），geomean 加速 ≥ 噪声底（本例噪声底 0.5%，实测 1.0410 x）；大 case（多 K-tile）改善为主。
- **零劣化判据**：单 case 最大回退 < 3% 声称阈值（实测最大回退 2.2%，case17 B_over_A=1.0225）。
- **归因**：GM 总字节数不变、矩阵计算入参不变，收益归因于搬运指令合并 + 突发密度提升。
- **回退**：分形重叠条件不成立、尾带精度失败或单 case 回退超阈值时，整体回退到逐带小搬运旧路径。

## 检索卡（短卡）

动作：把非驻留操作数面板 GM→L1 搬运粒度从「分形列带×归约行块」小搬运改为每行块整行带宽一次宽 Nd2Nz，L1 槽同步改按行块×分形紧排并同源改写内层装载寻址。
适用：非驻留操作数面板经 Nd2Nz 分形重排上片的矩阵乘内核；面板列带宽、归约行长时收益最大。
限制：分形 C0 列距重叠的 dtype 禁止合并；N 尾带单独小搬运、K 尾保留清零排空旧路径；外层搬运与内层装载源寻址必须同源改写。
范围：矩阵乘主循环非驻留操作数的 GM→L1 分形重排搬运环节。
检索词：Nd2Nz、宽搬运、分形重排、MTE2、列带、归约行块、突发密度、L1 布局、装载源步进。
机会：一侧搬运密度远高于对侧（24:1）串行发射；源每行连续段远小于突发宽度、行距大；搬运策略用尽后大 case 零改善。
