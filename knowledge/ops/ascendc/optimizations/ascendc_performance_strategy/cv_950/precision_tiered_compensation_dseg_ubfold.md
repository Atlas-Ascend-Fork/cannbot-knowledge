# 性能优化策略：精度分层补偿 + D 段切分 + UB 驻留单次折叠（硬精度约束下的梯度归约提速）

> **来源：多任务内核评审与同构实现对照沉淀（2026-11-11）**
> 证据形态：分层补偿、归约维跨核切分、UB 驻留累加器三个机制在同类交付中实测有效（精度全过 + 固定开销与指令数双降），直接反证「逐位一致与性能不可兼得」的普遍假设
> 本仓应用注意：免补偿决策前必须先盲调确认评测器对每个输出的逐位核对范围，不可假设

## 原理

「逐位一致」类硬精度约束被过度泛化是该类算子落后的第一根因。正确做法是**按输出逐个分析约束的必要范围**，只对真正需要的地方付补偿税：

1. **补偿算术分层**：常见保守形态是对全部输出无差别全量补偿（每项 2×Mul + 7 ops TwoSum + 补偿加 ≈10~11 向量 ops，且先要以 Dekker 4097.0f 切分 fp32 输入）。推荐形态：仅对 D 长归约输出补偿，且机制可更轻——**b16×b16 积在 fp32 天然精确（免 Dekker 切分）+ 每 chunk 无条件 TwoSum（8 ops）+ (hi,lo) 分离到最后一次 `Add(hi,lo)` 单次舍入**，对任意树形归约形状逐位一致；其余输出 plain fp32（每项 1 条 Muls），以解析误差界论证（≥100 倍裕量）通过评测。逐项向量指令数可降一个量级。
2. **D 段切分**：常见保守形态是 tiling 按样本维切核（`numBlocks = min(aivNum, max(bs,1))`），归约维从不切分——样本少时整条长 D 归约单核串行跑完。推荐形态：样本数 < 核数时按指令代价模型在 {1,2,3,4,6,8,16} 段中搜索段数（带 10% 收益门限），totalChunks = B×numSegs 最多 16× 核数；代价仅一次 `SyncAll<true>()` + phase-2 补偿合并。
3. **UB 驻留累加器 + 单次折叠**：常见保守形态是每 D-block 每行付一次多级折叠树 + 跨块补偿 fold，每 slice 另有 ClearAcc/SplitSmall/CompactAcc 四次额外 VF 调用与 2 次 EnQue/DeQue 往返。推荐形态：把 (hi,lo) 存成 VL 宽 UB 行累加器，整 task 只 fold 一次（~22 ops/累加器），无 per-slice 清理/切分 VF；参数取数提前一拍预取（参数冷取 + MTE2 等待是该类任务的常见最大固定项，µs/任务量级）。
4. **单读双产 + VF 入口收敛**：常见保守形态是 VF 入口多且 `asc_vf_call` 边界即 UB 可见性同步点，多个输出各自重读同一输入（读放大 n~n²）。推荐形态：一次输入行读入同时产出多个输出（unpack+cast 共享），每 span 仅个位数 VF 进出，fold 合并进单一收口 VF。

## 性能问题模式（哪些 profiling 信号说明该用）

- 精度约束（逐位一致/极小 MERE）驱动的补偿算术被无差别应用于所有输出，向量指令数/项 ≥8。
- tiling 按样本数切核，样本少时归约维（D/inner axis）无跨核切分，单核时长占绝对大头。
- 循环体内每块/每片重复执行固定折叠/清理序列（ClearAcc/SplitSmall/CompactAcc），且输出队列 EnQue/DeQue 往返次数与块数成正比。
- 多个 VF 各自重复读同一输入（读放大 n~n²），VF 进出次数是标量瓶颈。
- 小 shape case 的固定初始化（参数表/清理）时长 >kernel 有效计算时长。

## 正确性红线（什么情况下禁止用 / 必须回退）

1. **免补偿输出的前提是先提交误差界论证并确认评测器不查逐位**：对每个降级输出单独推导解析误差界（含极端值/相消域），并与评测容差比较（≥100 倍裕量才可降级）；若评测器逐位核对该输出，禁止免补偿（需盲调确认，不可假设）。
2. **逐位一致机制的完整性**：(hi,lo) 分离折叠的树形顺序必须固定（同 shape 必同树），每 chunk TwoSum 不得省略或重排；b16×b16 积精确的前提是两操作数均为 b16 原生值——任何一侧经历过 fp32 舍入即失效，须回退 Dekker 切分。
3. **D 段切分后跨段合并必须走补偿合并路径**（专用 (hi,lo) 合并 VF）：部分和已是 (hi,lo) 对，普通加法合并会破坏逐位一致；SyncAll 为全核 Barrier，不得置于分叉控制流。
4. **段切分收益门限**：代价模型估收 <10% 的 shape 不切（避免 Barrier+合并固定税倒挂）；段数候选集按指令代价标定，不得盲选最大段数。
5. **删除清理 VF 的前提**：ClearAcc/SplitSmall 冗余性成立于「积天然精确」成立——见红线 2；不成立时整组保留。

## 泛化条件（dtype / shape / 流水线 / 算子类型）

- 流水线：aiv_vec 主导、带硬精度约束的多输出梯度/归约类算子（grad 算子、带 MERE=0 断言的 reduce）。
- shape：样本维小而归约维长的 case 收益最大（D 段切分 + 免补偿收益同时兑现）；大样本 case 主要吃免补偿与单读双产收益。
- dtype：b16（fp16/bf16）输入的积天然精确机制仅适用于 b16×b16；fp32 输入回退 Dekker 切分。
- 与 double-buffer/预取类策略正交；与固定树形归约类策略叠加时须共用同一树形定义。

## 实施步骤

1. 列出全部输出张量，逐个确认其精度断言来源（评测器逐位核对 / MERE 阈值 / golden 构造方式），标记「逐位必要」与「误差界可过」两类。
2. 对逐位必要输出实现轻量机制：b16×b16 积 + 每 chunk TwoSum + (hi,lo) 末次单舍入；对可降级输出写误差界论证（含极端值分析）并留档。
3. tiling 增加归约维段切分：样本数 < 核数时按指令代价模型在 {1,2,4,8,16} 段搜索，10% 收益门限；部分和 (hi,lo) 写小 workspace，SyncAll 后一次补偿合并。
4. 跨块累加改 UB 驻留 VL 行 (hi,lo) 累加器，归约循环结束一次性 fold；删除冗余 ClearAcc/SplitSmall/CompactAcc（前提复核红线 2）。
5. 合并 VF：共享输入单读双产（unpack+cast 共享），特化入口收敛到同一入口减少 `asc_vf_call` 同步点；参数预取提前一拍。
6. 全量精度用例过门（含逐位核对类 case 与极端值 case），平衡交替配对复测。

## LLM 前置问题（应用前必须自问）

1. 每个输出的精度断言到底是谁在检查？评测器逐位核对的范围是否覆盖全部输出（不要复述本方报告的假设，去查评测口径）？
2. 输入是 b16 原生还是经历过 fp32 舍入？积天然精确机制是否适用？
3. 误差界论证的极端值/相消域覆盖是否完备？裕量倍数多少？
4. 段切分后 workspace 体积与 SyncAll 固定税多少？10% 门限下有多少 case 值得切？
5. 当前 VF 进出次数与共享输入读放大系数各是多少？合并后减多少？
6. 折叠树形固定化后，同 shape 不同核数是否仍产生同一结果？

## 验收标准

- **构建**：编译通过；VF 入口数显著下降，`asc_vf_call` 同步点计数下降。
- **精度**：全量用例一次通过；逐位必要输出保持逐位一致（换树形验证）；可降级输出误差界 ≤论证值的 1/2（留安全余量）。
- **性能**：向量指令数/项显著下降（量级目标：一个数量级）；小 case 固定开销显著下降；平衡交替配对 geomean 超噪声底；单 case 回退 <3%。
- **归因**：逐项核对——补偿税削减、并行度提升（段切分启核数）、固定序列消除三个来源各自的收益占比。
- **回退**：任一逐位输出破坏逐位一致、误差界裕量不足、SyncAll 死锁或段切分负收益时回退对应子项。

## 检索卡（短卡）

动作：按输出逐个确认逐位一致约束的必要范围——仅 D 长归约输出用轻量补偿（b16×b16 积天然精确+每 chunk TwoSum+(hi,lo) 末次单舍入），其余输出 plain fp32 凭解析误差界（≥100 倍裕量）免补偿；tiling 增加 D 段切分（按指令代价模型在 {1,2,4,8,16} 段搜索，10% 收益门限）；跨块累加改 UB 驻留 VL 行 (hi,lo) 累加器整 task 单次 fold；共享输入单读双产合并 VF
适用：带硬精度约束（逐位一致/极小 MERE）的多输出梯度/归约类算子
限制：免补偿前须确认评测器不逐位核对该输出；(hi,lo) 折叠树形必须固定；段切分后跨段合并必须走补偿合并；fp32 输入回退 Dekker 切分
范围：grad 类、MERE=0 断言归约类的精度策略与并行度
检索词：TwoSum、Dekker、补偿算术、逐位一致、误差界、D 段切分、SyncAll、UB 驻留累加器
机会：全量补偿税+归约维单核串行+每块重复折叠序列并存
代价：误差界论证依赖评测口径确认；SyncAll 固定税在低收益 shape 倒挂
