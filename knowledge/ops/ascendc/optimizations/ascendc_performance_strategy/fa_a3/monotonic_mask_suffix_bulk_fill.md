# 性能优化策略：单调屏蔽后缀的批量向量填充

> 单一优化点：将逐段构造并写入单调屏蔽后缀的处理，改为“至多一个首段部分写入 + 一个已对齐连续后缀批量写入”，减少每行的控制流、标记构造和向量指令发射。

## 1. 原理

当每个有效行的被屏蔽位置是一个连续后缀时，后缀只由起点和有效行宽决定，不需要逐小段枚举。若起点落在对齐段中间，只对首个部分段按位选择性写入；之后的全部位置构成连续且对齐的区间，可一次批量填成屏蔽值。

语义伪代码：

```text
对每个有效行：
  求屏蔽后缀起点和有效行宽
  若起点在有效行宽之外：跳过
  若起点不在对齐段边界：
    仅写入该段内从起点到段尾的有效部分
    将批量区间起点推进到下一段边界
  若批量区间非空：
    一次填充从批量区间起点到有效行宽的连续后缀
```

## 2. 性能问题模式

- 热点向量阶段逐行处理单调的右侧屏蔽区间。
- 旧路径按固定小段循环；每段还要构造位标记或执行细粒度分支。
- 宽行、非对齐后缀起点或长后缀会放大循环次数与标量控制开销。
- 行分组大小、任务划分和数据搬运已合理，瓶颈集中在同一行内重复的小段填充。

本策略只减少单行后缀填充的指令与控制开销；不改变行分组或跨行调度，也不读取逐元素字节标记，更不以选择式掩码替换数据通路。

## 3. 正确性红线

- 仅当被屏蔽集合严格等于每行有效范围内的一个右侧连续后缀时适用；存在多个区间、洞或非单调边界时必须回退原路径。
- 起点等于或超过有效行宽时不得写入；起点为零时必须覆盖整个有效行；首段写完即到有效行宽时不得发起空的批量写入。
- 首段部分写入必须精确限定在“起点到该段有效末端”；不得改写起点左侧，也不得覆盖下一行或行尾填充区。
- 构造首段位标记时，禁止执行位移量等于机器字位宽的移位。完整段应直接走批量填充或显式完整标记，部分段的位数必须严格小于机器字位宽。
- 批量区间的起点必须满足目标向量填充原语的地址和元素对齐要求；若无法证明对齐，保留保守路径。
- 批量长度只能覆盖有效行宽以内的剩余后缀。存储步长、实际有效宽度和物理对齐宽度必须分开处理，不能把填充列当作有效列。
- 屏蔽值、源/目标数据类型、向量掩码的位序与每位控制的元素数必须与原语义一致；尤其要验证不同浮点类型和掩码粒度下的解释。
- 处理最后一行、最后一块和非对齐有效宽度时，所有读写均不得越界；尾部填充必须继续保持原有的不可见或屏蔽语义。
- 若后续阶段紧接着消费写入结果，按既有流水依赖插入或保留必要同步；不得因为减少写入调用而删除仍需要的可见性保证。

## 4. 泛化条件

- 行内边界可由单调规则、行位置和有效宽度确定，且每个行后缀共享同一种屏蔽值。
- 目标硬件提供对连续元素的高吞吐填充，以及对一个对齐段内部分元素的安全选择性填充。
- 可以获得每行的真实有效宽度、行步长和起点，且能证明批量区间不跨越逻辑行。
- 适用于后缀足够长或行数足够多、细粒度段循环处于关键路径的情况；短行或边界稀少时先以测量确认收益。

不适用于每行需要读取外部逐元素掩码、屏蔽区间不连续、屏蔽值随列变化，或批量填充无法满足尾部与对齐约束的情况。

## 5. 实施步骤

1. 定义每个有效行的后缀起点、真实有效宽度与物理行步长，并断言它们的关系满足单调后缀语义。
2. 保留原有的无后缀、全后缀和尾块分支，先建立边界测试表。
3. 对非对齐起点，仅生成一个首段的部分写入；该部分写入后将剩余起点推进到下一个对齐段。
4. 对剩余的已对齐连续区间，调用一次批量填充；禁止重新按小段循环。
5. 保持原屏蔽值、行步长、尾部处理及生产者—消费者同步边界不变。
6. 将新旧路径在随机起点、随机有效宽度和所有支持数据类型上逐元素比对，再评估热点向量阶段的性能。

## 6. LLM 前置问题

1. 每行的屏蔽位置能否严格表示为一个从某起点到真实有效宽度的连续后缀？
2. 对齐段的元素数、地址对齐要求、部分写入的位序和位标记宽度分别是什么？
3. 起点为零、起点位于段内、起点恰好对齐、起点在行外、有效宽度非对齐时，各自会走哪条路径？
4. 批量填充是否只覆盖真实有效元素，并与行步长、尾部填充和下游有效长度判定兼容？
5. 是否存在下游立即消费、缓冲复用或跨流水访问，因而需要保留同步？
6. 该热点的主要成本是否真是逐段控制和填充调用，而非行分组、掩码搬运或其他向量计算？

## 7. 验收标准

- 编译通过，且静态检查确认新路径只实现单调后缀填充，没有改变行分组、任务分解或外部掩码数据通路。
- 精度测试覆盖无后缀、全后缀、对齐起点、非对齐起点、刚好跨段、长后缀、非对齐有效宽度、最后行和最后块，以及所有支持数据类型。
- 对每个测试行，屏蔽值恰好出现在原规则定义的后缀，起点左侧和有效范围外均与基线一致。
- 在目标热点场景中，性能测试显示向量阶段的重复小段调用或相关控制开销下降，且端到端结果不回退。

## 检索卡（短卡）

动作：将逐小段写入改为首个部分段选择性写入，再对齐批量填充其余连续后缀。
适用：边界可由单调规则、行位置和有效宽度确定，后缀屏蔽值一致，硬件支持连续及段内选择性填充。
限制：屏蔽集合须严格为有效范围内的单个右侧连续后缀；多区间、洞或非单调边界必须回退。
范围：每个有效行内的右侧连续屏蔽后缀。
检索词：单调屏蔽后缀、部分段、对齐连续区间、选择性写入、批量填充
机会：热点逐行处理右侧后缀，旧路径按固定小段循环并重复位标记或细粒度分支。
