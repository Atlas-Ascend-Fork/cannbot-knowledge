# 性能优化策略：多轴自适应归约改为「读一次 + 片上累加 + 末轴向量段归约」

> 单一优化点：把「逐输出元素的标量归约 + 每窗口跨流水线同步」改为「读一次输入 + 片上累加 + 末轴向量段归约」。

## 1. 原理

当一个逐输出元素的归约实现把整条归约拆成「每个窗口元素一次标量读 + 一次跨流水线同步」时，
计算被强行串行到标量流水线上，且每读取一个窗口元素都要插入一次跨流水线 flag 同步，导致
带宽与算力都被同步开销淹没。把同样的归约改成「向量归约 + 片上累加」即可让一条向量指令
处理成百上千个元素，并把跨流水线同步降到每次输出一次以内。

对于多轴（深度/高度/宽度）自适应窗口归约，进一步把归约分解为：先沿一个轴把整块输入「流式」
累加进一个按输出分组驻留在片上缓存的累加器（每个输入元素只被从全局存储读一次），再在片上
缓存里逐轴累加，最后一轴用向量段归约产出输出。这样把「输出数 × 窗口元素数」次微小全局读取
降到「输入元素数」次连续大块读取，逼近带宽上界。

## 2. 性能问题模式

命中本策略的典型反模式（任一即可）：

- 归约 hot loop 用「按元素标量读片上缓存 + 标量累加」实现，且每个窗口 load 之后都插一次
  「向量流水线 → 标量流水线」的 flag 同步。
- 每个输出元素独立地从全局存储里把它自己的多轴窗口一行一行地用极小块搬运指令读进来，相邻
  输出之间窗口高度重叠却不复用已搬数据。
- 多轴归约时，同一输入行被属于不同输出行的多个输出反复重读。

症状：算子呈「标量流水线 bound」，墙钟远高于「输入读一遍 + 输出写一遍」的带宽下界，且与输出
元素数、窗口元素数强相关。

## 3. 正确性红线

- 低精度输入必须在更高精度（如单精度）累加器里归约，最后再按目标精度回转，避免中间累加
  溢出或精度损失；不得用低精度做二叉树式累加（会饱和截断）。
- 自适应窗口的起止按「向下取整起 / 向上取整止」计算，窗口在非整除时长度可相差 1；分段归约
  必须按每个输出的真实 [start, end) 段求和，不得假设窗口等长。
- 末轴段归约若用「按位掩码」从一个对齐基址选取段，必须保证对齐基址后的读取范围不越过缓冲
  尾部（按需把该行缓冲尾部补到掩码最大跨度），且未被选中的位不影响求和（补零或被掩码排除）。
- 行内补齐到对齐字节数后，补齐尾部不得参与任何会被写回全局存储的输出；输出窗口只落在真实
  数据范围内。
- 片上累加器与各缓冲的总占用不得超过片上缓存容量；当某维度较大时，对该维度的「流式」搬运
  必须分 tile，使单 tile 的「输入块 + 累加器 + 暂存」三者合计在容量内。

## 4. 泛化条件

适用：

- 逐输出元素的多轴（含 ≥2 轴）窗口归约算子（均值/求和类），窗口由「输出索引 × 输入尺寸 /
  输出尺寸」式自适应决定。
- 输入在全局存储里按行优先连续排布，单行（最内轴）连续。

不适用：

- 窗口为单元素（无归约）或算子本身已是纯向量逐元素运算。
- 输入布局使最内轴不连续、且无法通过对齐补齐得到连续行（需先重排，超出本策略）。

## 5. 实施步骤

1. 选定一个「按输出分组」的工作单元（覆盖一组输出的所有窗口所涉及的输入行集合）。
2. 在片上缓存开一个按该分组形状、按对齐字节数补齐内轴的 fp 累加器，初值置零。
3. 沿「最外归约轴」把该轴涉及的每个输入行块用一条连续大块搬运搬进片上，升精度后用一条向量
   加累加进累加器；若该轴维度大，按 tile 循环（每 tile 内：搬一块 → 升精度 → 向量加），
   保持「输入块 + 累加器 + 升精度暂存」总占用在容量内。该步保证每个输入元素只被读一次。
4. 对剩余的中间轴：在片上缓存里，按每个中间输出索引，把其窗口覆盖的若干累加器行用向量加
   累加进一个「行累加器」（纯片上，不再访问全局存储）。
5. 末轴：对该行累加器，按每个最末输出索引的真实 [start, end) 段做向量段归约（等长且布局
   允许时可用「相邻对求和」类指令一次处理多个输出；否则用按位掩码从一个对齐基址选段），
   得到每个输出的归约和。
6. 把归约和除以窗口元素数（窗口等长时用标量乘以倒数，避免标量写回与跨流水线同步；不等长时
   按输出构造倒数向量），升/降精度回目标精度，按输出行写回全局存储。
7. 把工作单元按该分组的总数均匀分布到所有可用向量核。

## 6. LLM 前置问题

- 该算子的归约当前是「标量逐元素 + 每窗口跨流水线同步」还是「向量归约」？
- 输入是否在最内轴连续？多轴归约能否选出「一个输入元素只属于一个输出分组」的分解？
- 末轴窗口是否等长、最内轴长度是否为对齐字节数的整数倍？是否可用「相邻对求和」批量处理？
- 片上累加器 + 输入块 + 暂存的总占用，在最坏形状下是否超出片上缓存？需不需要对大维度分 tile？

## 7. 验收标准

- 构建：算子在目标芯片上可编译构建并注册到已安装算子包。
- 精度：在共享基准用例集的选定性能用例上，与参考实现逐元素比对，全部通过既有精度阈值。
- 性能：选定性能用例的「每用例最小墙钟的算术平均」达到目标线（参考实现平均墙钟的既定比例）；
  且相比「标量逐元素归约」基线有量级级提升。

## 检索卡（短卡）

动作：将逐输出标量归约和逐窗口同步改为输入只读一次、片上累加、末轴向量段归约
适用：输入行优先连续排布；至少两轴的均值/求和窗口按输出索引及输入输出尺寸自适应确定
限制：低精度输入须在更高精度累加器归约，最后回转目标精度
范围：逐输出元素的多轴自适应均值、求和窗口归约
检索词：多轴自适应归约、标量累加、跨流水线 flag、片上累加、向量段归约
机会：每个窗口元素都有一次片上标量读取和一次跨流水线同步
