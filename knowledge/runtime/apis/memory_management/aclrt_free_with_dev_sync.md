# aclrtFreeWithDevSync

## 功能说明

释放 Device 上的内存，内部会执行隐式 Device 同步。

## 函数原型

```c
aclError aclrtFreeWithDevSync(void *devPtr)
```

## 参数说明

| 参数名 | 输入/输出 | 说明 |
| --- | --- | --- |
| devPtr | 输入 | 待释放内存的指针，不能为空指针 |

## 返回值说明

返回 0 表示成功，返回其他值表示失败，参见 aclError。

## 约束说明

- 本接口内部会进行隐式 Device 同步，等待使用该内存的任务完成后才释放
