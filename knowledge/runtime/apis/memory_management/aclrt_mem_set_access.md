# aclrtMemSetAccess

## 功能说明

设置虚拟内存的访问权限。

## 函数原型

```c
aclError aclrtMemSetAccess(void* virPtr, size_t size, aclrtMemAccessDesc* desc, size_t count)
```

## 参数说明

| 参数名 | 输入/输出 | 说明 |
| --- | --- | --- |
| virPtr | 输入 | 虚拟内存起始地址，必须与 [aclrtMapMem](aclrt_map_mem.md) 的 virPtr 地址相同 |
| size | 输入 | 虚拟内存长度 |
| desc | 输入 | 内存访问配置信息数组 |
| count | 输入 | desc 数组长度 |

## 返回值说明

返回 0 表示成功，返回其他值表示失败，参见 aclError。
