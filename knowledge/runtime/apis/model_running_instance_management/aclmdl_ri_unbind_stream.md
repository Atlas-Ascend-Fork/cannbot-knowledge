# aclmdlRIUnbindStream

## 功能说明

解除模型运行实例与 Stream 的绑定。

## 函数原型

```c
aclError aclmdlRIUnbindStream(aclmdlRI modelRI, aclrtStream stream)
```

## 参数说明

| 参数名 | 输入/输出 | 说明 |
| --- | --- | --- |
| modelRI | 输入 | 模型运行实例。 |
| stream | 输入 | 指定 Stream。 |

## 返回值说明

返回 0 表示成功，其他值表示失败，请参见 aclError。

## 约束说明

任务执行完毕后调用。
