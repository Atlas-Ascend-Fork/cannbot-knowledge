# 日志接口

模块日志记录、级别校验及设备 plog 日志回调注册接口。

- [alog_record.md](alog_record.md)：记录模块日志（已废弃）
- [alog_check_debug_level.md](alog_check_debug_level.md)：校验调测日志级别（已废弃）
- [acllog_record.md](acllog_record.md)：记录用户模块日志
- [acllog_va_list.md](acllog_va_list.md)：通过 va_list 记录日志
- [acllog_check_debug_level.md](acllog_check_debug_level.md)：校验用户模块日志级别
- [acllog_register_callback.md](acllog_register_callback.md)：注册设备 plog 回调
- [acllog_unregister_callback.md](acllog_unregister_callback.md)：取消注册设备 plog 回调
- [aclAppLog](acl_app_log.md)：将日志记录到日志文件中，提供 ACL_APP_LOG 宏封装。
