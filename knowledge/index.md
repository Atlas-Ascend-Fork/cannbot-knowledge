# 知识正文

当前 Bundle 包含 Ascend C 算子参考、社区贡献的 Ascend C 优化经验、Triton-Ascend 算子开发知识和模型推理、训练、空间智能、具身智能知识；公共 domain 含平台知识，图和 Runtime domain 目前保留结构入口。Domain 入口保持完整，`ops`、`contrib` 和 `model` 预建注册 route；其他领域由维护者随首张真实知识创建下层路径。只有实际知识卡计入 Query 覆盖。

- [公共知识](common/index.md)：跨领域公共知识入口。
- [社区贡献](contrib/index.md)：社区贡献的工程知识入口。
- [算子知识](ops/index.md)：按 DSL 隔离的算子知识入口。
- [图知识](graph/index.md)：图领域知识入口。
- [模型知识](model/index.md)：模型推理、训练、空间智能和具身智能知识入口。
- [Runtime 知识](runtime/index.md)：CANN Runtime 领域知识入口。
