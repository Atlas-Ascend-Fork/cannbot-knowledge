# 知识正文

当前 Bundle 只保留基础目录骨架，尚未包含知识卡。Domain 入口保持完整，`ops` 和 `model` 预建下一层 route；其他领域由维护者随首张真实知识创建下层路径。结构入口不计入 Query 覆盖。

- [公共知识](common/index.md)：跨领域公共知识入口。
- [算子知识](ops/index.md)：按 DSL 隔离的算子知识入口。
- [图知识](graph/index.md)：图领域知识入口。
- [模型知识](model/index.md)：模型推理、训练和公共知识入口。
- [Runtime 知识](runtime/index.md)：CANN Runtime 领域知识入口。
