# 并行策略

- [CFG Parallel](cfg_parallel.md)：Classifier-Free Guidance (CFG) 在 DiT 每个采样 step 内需要做两次前向：一次条件（cond，带 prompt）、一次无条件（uncond，空 prompt），再按 `noise_pred = noise_pred_uncond + w·(noise_pred_cond - noise_pred_uncond)` 融合。CFG Parallel 把这两个样本分别放到两张卡上同时跑，每卡只做一次模型推理，最后通过 all_gather 互相拿对方的结果，端到端相当于把 DiT 每步耗时减半。HunyuanImage-3.0、Wan2.2-I2V 均采用该并行。
- [Data Parallel](data_parallel.md)：将不同的请求/batch 分配到不同的模型副本上并行推理的策略，用于提升推理吞吐量。在推理场景中通常以 DP 通信域的形式与 TP/EP 配合使用。
- [Embedding Tensor Parallel](embedding_tp.md)：Embedding Tensor Parallel（Embedding TP）是针对**稀疏参数占主导**的推荐/生成式推荐模型的并行策略：把超大规模的 **Embedding Tables 按 vocab 维度切分**到多张 NPU 上，以减少单卡显存负担，支撑超大 Embedding 词表的推理。在 cann-recipes-infer 中首次用于 hstu（Meta 生成式推荐模型）。 与 LLM 的 tensor-parallel 切 Attention Head / FFN 隐藏维度不同：LLM 参数主要集中在 dense Transformer 权重里，输入 token 来自相对固定的文本词表；而**生成式推荐往往把用户、物品、上下文等离散特征统一建模为 token，模型容量绝大部分来自超大规模的稀疏参数（Embedding Tables），词表规模可达千万甚至上亿**。
- [KVP（KV Parallelism）：长序列 Decode 的 KV Cache 序列分片与历史状态](kvp.md)：解释 memory-bound 长序列 Decode 沿 S 维切分 KV Cache、局部 Attention 的 LSE 合并与耦合配置；LongCat A3 历史实现已撤回，所列版本拒绝 kvp_size，不作为当前部署入口。
- [Ring Attention Sequence Parallelism](ring_attention.md)：Ring Attention 是另一种长序列 SP 方案：与 Ulysses 不同，**attention 内部也保持序列切分**，每张卡仅维护自己那 1/SP 的 Q；通过 概念上以 P2P 环形逐跳传 KV，但本仓 module/unified_sp/core.py 实际用一次 all_gather_into_tensor 把其他 rank 的 1/SP KV 一次性收齐，对本地 FA 与远端合并 FA 两路输出做 LSE（Log-Sum-Exp）合并（非逐跳 P2P）。适合 Ulysses 规模受限（`num_heads` 不够切）或与 Ulysses 组成 2D hybrid SP 的场景。 Wan2.2-I2V 在此基础上实现了 ring-attention-overlap：异步 AllGather + 本地 FA 并行，用计算掩盖通信。
- [SP-TP-SP Hybrid Split (Prefill MLA)机制](sp_tp_sp.md)：DeepSeek-R1 Prefill 阶段 MLA 部分针对 DP 切分在短序列混合/请求数少场景下 **计算负载不均 + TTFT 被拉长** 问题提出的混合切分策略：把 batch 与 seq_len 合轴变为 token 数，按卡数 **SP** 切 token 均匀分发；FlashAttention 计算走 **TP** 切 head；FA 结束后 AllToAll 再转回 **SP** 给 o_proj。"SP → TP（FA）→ SP" 三段式得名。
- [Tensor Parallel机制](tensor_parallel.md)：将模型权重沿 Head 或隐藏维度切分到多张卡上并行计算的策略，是 NPU 推理中最基础的并行方式。具体使用模块与阶段由模型实现决定，也可与 DP/EP 配合。
- [Ulysses Sequence Parallelism](ulysses.md)：Ulysses 是面向**长序列多头注意力**的序列并行策略：在 attention 以外的部分沿 S（sequence）维度切分，在 attention 处通过一次 all-to-all 把切分维度从 S 换到 N（num_heads），attention 内部按 head 并行、attention 输出再 all-to-all 换回 S。相比于 Ring Attention 依赖 P2P 循环传 KV，Ulysses 用集合通信 all-to-all 实现，简单高效，是 HunyuanVideo / HunyuanImage-3.0 / Wan2.2-I2V 长序列 DiT 推理的首选序列并行。 cann-recipes-infer 在 `module/unified_sp/` 提供统一 SP 框架，支持 Ulysses / Ring / Hybrid（Ulysses × Ring）三种模式，并通过 **Ulysses Anything Attention (UAA)** 在满足 padding 边界时支持头数不整除并行度的配置。
- [VAE Patch Parallel](vae_patch_parallel.md)：VAE 编解码的空间并行：HunyuanImage-3.0 与 Wan2.2-I2V 使用 H/W 网格及按算子选择的通信；HunyuanVideo 使用沿宽度的 overlap-chunk decode。说明平台实现、切分范围与边界处理。
- [ZigZag Context Parallel (Load-Balanced Causal Attention)机制](zigzag_cp.md)：ZigZag 是 context-parallel 下针对**因果 Attention 负载不均**的切分变体：将输入 Sequence 切成 `2·cp_size` 个 block，每个 CP rank 负责头尾对称的两个 block（如 rank 0 负责 block 0 与 block 2·cp_size-1），从而让所有 rank 的历史 KV 计算量近似相等。通过两次 AllToAll 在"因果序"和"ZigZag 序"之间切换。 定位：ZigZag 是 CP 的**并行切分策略**（不是正交的通用技术），放在 parallelism 目录下；与 Ulysses/Ring Attention SP 并列作为长序列并行的一个方案族。

- [上下文并行（Context Parallel / CP）：长上下文 Prefill 的序列切分](context_parallel.md)：CP 沿 Sequence 维度切分长上下文 Prefill 的计算，降低单 Rank 的激活值压力。区分 Qwen3-Next 的 CP+TP 与其他整域 CP 实现；通信域、KV 汇聚及 PD 分离限制按具体案例核对。
- [MoE 专家并行（Expert Parallel / EP）：Prefill 与 Decode 的专家切分和通信](expert_parallel.md)：EP 将 MoE 专家分布到多个 Rank，通过 dispatch/combine 分发和收回 token；不以 MLA 为前提，Attention 结构及其 TP/DP 是独立维度。说明 Prefill、Decode 的已知部署方案及与 TP 的分工；吞吐和时延仍取决于负载均衡、通信与具体实现，不能仅由启用 EP 推定收益。
