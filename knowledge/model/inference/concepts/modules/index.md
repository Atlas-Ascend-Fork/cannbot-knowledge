# 网络模块

- [Blockwise Sparse Attention (TopK / SVG)机制](blockwise_sparse_attention.md)：Blockwise Sparse Attention 是一种 Attention 组件变体：按 [block_Q, block_K] 粒度估计块的重要程度，只计算 TopK 重要块、跳过其余块，从而把超长序列 DiT 的 Attention 计算量显著降低。与普通 sparse-flash-attention（按 Token TopK 的稀疏）并列，是 Attention 算法族下的"块级稀疏"分支。cann-recipes-infer 在 module/blockwise_sparse/ 下实现 TopK 与 SVG 两种 predictor，底层算子依赖 blitz_sparse_attention（需按参考文档自行编译）。
- [Diffusion Transformer (DiT)机制](dit.md)：DiT（Diffusion Transformer）是目前主流的多模态扩散生成模型主干：把 U-Net 替换为 Transformer，把 latent（图像/视频 VAE 编码后）当作 token 序列，通过多步去噪（sampling steps） 从随机噪声还原语义信号。cann-recipes-infer 中的 HunyuanVideo、HunyuanImage-3.0、Wan2.2-I2V、Sana-Video 均属于此范式：文本 encoder（T5/CLIP/LLM）把 prompt 编码为 condition，DiT 在每一步 time step 内基于 (noisy_latent, t, cond) 预测噪声；CFG 用一组 conditional/unconditional 预测做 guidance，再经 VAE decoder 还原出像素域的图像/视频。
- [DSA（DeepSeek Sparse Attention）架构模式](dsa.md)：DSA（DeepSeek Sparse Attention）是一种注意力架构模式（非单个 kernel、非 MLA 替代品）：MLA 的 Q/K/V LoRA 计算图 + 并行的学习式 indexer overlay，indexer 为每个 query 选 index_topk 个最相关 key、产出 softmax 前的加性 -inf mask，把非 top-k 位置置零；因此 attention_type=dsa 的模型隐式携带完整 MLA 前向图（DSA ⊇ MLA，MLA 是严格子图）。本页讲清 DSA(架构模式) / MLA(子图) / Lightning Indexer(选 token 模块) / Sparse Flash Attention(稀疏注意力 kernel 落地) 四者边界关系。已验证实例：DeepSeek-V3.2-Exp 与 GLM-5（严格 MLA⊕indexer；indexer RoPE 布局 per-model 差异——V3.2-Exp 非交错 npu_rotary_mul / GLM-5 交错 npu_interleave_rope）、DeepSeek-V4（注意力主体改 MQA/Shared-KV，DSA 思想下沉到压缩 Cache 的稀疏选择）。
- [Gated Attention](gated_attention.md)：承担精确长程检索的标准 Softmax Attention 变体（也称混合注意力模型中的 full attention 层），在 Attention 输出后引入一个元素级 Gate（Sigmoid/SiLU 门控）对输出进行调制，再送入残差路径。在 Qwen3-Next 与 Qwen3.5-MoE 中与线性注意力变体 Gated DeltaNet 混合交替堆叠，构成分层异构注意力。Qwen3.5-MoE 的 full attention 由 merged_qkv_proj 同时产出 gate，并对 Q/K 做 QK-RMSNorm、对部分维度应用 partial MRoPE。
- [Gated DeltaNet (GDN)](gated_deltanet.md)：承担线性复杂度上下文聚合的线性注意力模块，基于 Mamba/DeltaNet 风格的递推状态更新加门控机制。在混合注意力模型（Qwen3-Next、Qwen3.5-MoE）中与 Gated Attention / full attention 交替堆叠。相对标准 Attention，GDN 在长序列下显著降低计算与显存复杂度，但引入 Conv1d 和状态递推，不适合沿 Sequence 的并行切分。各模型的 GDN 在结构上一致，但融合算子路径不同：Qwen3-Next Prefill 走 PyPTO ChunkGDN，Qwen3.5-MoE Prefill 走 torch_npu 原生 npu_chunk_gated_delta_rule。
- [Lightning Indexer (LI)机制](lightning_indexer.md)：Lightning Indexer 是 DeepSeek-V3.2-Exp **DSA 架构**的前置稀疏选择模块 —— 对每个 query token，在长达数十万的上下文中**准确地**（非近似）选出 TopK（一般 2048）个相关 KV token 的 index，喂给后续 sparse-flash-attention。相比 MLA 它是一个轻量的类 MQA 结构，新增 `q_b_proj`、`wk_proj`、`weight_proj` 三个 Linear（综合所有层约 **+0.85B** 参数）。 LI 同时保留了一份**独立的 Indexer Key Cache**（与完整 MLA KVCache 并存），Decode 时免去重复计算；Indexer Key Cache 内存约 `batch × kv_length × Indexer_head_dim × bytes × num_layers`（4 batch × 64K × BF16 ≈ **4 GB**/rank）。 算子层实现见 lightning-indexer（AscendC / PyPTO / TileLang 三路）。
- [mHC (Manifold-Constrained Hyper-Connections)](mhc.md)：mHC（Manifold-Constrained Hyper-Connections，arXiv 2512.24880）是 DeepSeek-V4 引入的传统残差连接扩展，与 Attention、MoE 并列为每个 Layer 的三模块之一。核心：把层间 hidden 从单路残差扩展为多路残差（路数 `hc_mult`；Native 参考实现签名默认 4，实际生产取权重 config，仓内无硬编码全局默认），用 Pre / Post / Res(comb) 三类可学习映射在多路↔单路间转换——每个子层（Attention 一次、MoE 一次）经 `HcPre` 把多路融合回一路（RMSNorm + linear(hc_fn) + pre 加权求和）送入子层，子层一路输出经 `HcPost` 用 Post 系数（`2·sigmoid`）扩展回多路并与 Res(comb) 混合后的多路残差加和。Res(comb) 混合矩阵经 **Sinkhorn-Knopp 迭代**（softmax→列归一→`iters-1` 轮行列交替归一）约束逼近双随机矩阵（论文'流形约束'）。本页讲结构语义与计算公式（以 `mhc.py` 代码为准）；`HcPre`/`HcPost` 融合算子的 A3 分离架构 CV 流水/Tiling/性能为独立子主题。
- [MLA (Multi-head Latent Attention)](mla.md)：DeepSeek-V3 系列（DeepSeek-R1、Kimi-K2）使用的低秩压缩注意力机制。通过将 Q 和 KV 分别投影到低维隐空间（`q_lora_rank`、`kv_lora_rank`）再上投到 full rank，实现 KVCache 体积的显著压缩；RoPE 仅作用于一个较小的 `qk_rope_head_dim` 通道，与 NoPE 通道拼接。相较标准 MHA，MLA 在同样上下文长度下 KVCache 占用显著更小，推理时通过融合算子 mla-prolog 将 Q/K/V Linear + LayerNorm + RoPE + KVCache 写入整体合并，进一步降低下发开销。 训练侧（MindSpeed-LLM CustomMLASelfAttention）默认 mla_naive_attention 走完整 q/kv 上投影 + RoPE + FlashAttention、无 decode KV-cache absorption；--enable-mla-absorb 仅稀疏注意力下吸收 W_UK/W_UV 压激活显存；经 features_manager 的 MLAFeature/DSAIndexerFeature/G2Feature 注册，配合 TP/SP/CP 与 mla-zero-memory 等重计算。
- [Sparse Flash Attention (SFA)机制](sparse_flash_attention.md)：Sparse Flash Attention 是 **DeepSeek Sparse Attention (DSA)** 的核心计算模块。在由 lightning-indexer 选出 TopK 个相关 KV token 之后，SFA 仅在这部分稀疏子集上执行注意力计算，将复杂度从 O(N²) 降到 O(N·TopK)，配合 Flash Attention 的块级 online softmax 思想。DeepSeek-V3.2-Exp 将其作为长序列推理的主力注意力算子，并在此基础上设计了 CP 并行、MLA Absorb 模式适配。 SFA 作为架构概念是 DSA 的一部分；具体算子实现（AscendC / PyPTO / TileLang）见 sparse-flash-attention。
- [VAE（多模态生成）](vae.md)：VAE 在生成模型中完成像素与 latent 之间的编解码；图像条件推理也会调用 Encoder。涵盖按模型区分的 VAE 并行、mask 缓存和 offload 调整，并区分 VAE 与去噪网络优化。
