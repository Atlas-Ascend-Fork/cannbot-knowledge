# 950 随机数实现：legacy 列表与一致性优先级

## 固定版本与证据

依据 PyTorch/TorchNPU 固定主线 `ac0e1564ca6ffb00c1f4fb834fc4b41a601862bf` 的环境变量文档，按所列产品和选项限制使用，不推导发布组合具备全部功能。只读来源审阅，未运行上游代码或设备实验。

## 仅限950DT的实现选择

TORCH_NPU_LEGACY_IMPL_LIST 当前支持配置项 randomness，在进程启动前设置，项区分大小写，多个项逗号分隔，不支持的项报错。它优先于 TORCH_NPU_USE_COMPATIBLE_IMPL 与 use_compatible_impl 全局开关；未列入的功能不受它影响。

来源说明950DT的相关随机API 默认采用与社区对齐的实现，randomness 将这些 API 切到与 A2/A3 一致的旧实现；需要支持该切换能力的 CANN，否则保持产品默认。不能把“主线有此变量”当作任意 CANN 均已切换成功。

## 受控 API 集合

随机生成包括 rand、rand_like、randn、randn_like、randint、randint_like、normal；Tensor 原地包括 uniform_、normal_、random_ 的 from/to 及 to 形式；nn.init 包括 uniform_、normal_、trunc_normal_、xavier_uniform_/normal_、kaiming_uniform_/normal_、orthogonal_、sparse_。

这是实现选择名单，不是所有随机操作或图模式 RNG 的支持承诺。切换会改变序列，固定 seed 仍需分别核对产品、算法、调用顺序和图重放行为，不能把 legacy 等同于开启确定性算法。


## 核验

保存解释器、包版本、设备、完整配置及首次生效时机，在新进程中做单项对照。检查数值与实际路径，再分别比较首次启动、稳态时间和资源开销；调试配置关闭后复测。

## 名单不能覆盖接口产品限制

同提交原生nn.init页对trunc_normal_明确标记950DT不支持，sparse_中文仅列A2/A3、英文明确950DT不支持；它们又出现在本卡legacy随机实现选择名单。保留两种材料的范围差异，不把变量中的名字当作已经可用或完成设备验证的证明。完整来源与初始化类型限制见[原生参数初始化](../../../../training/guides/torch_npu_native_initialization_constraints.md)。
