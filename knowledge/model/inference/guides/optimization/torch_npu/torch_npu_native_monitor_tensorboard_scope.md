# 原生Monitor与TensorBoard：事件字段和记录类型边界

## 固定来源与范围

依据TorchNPU主线 `ac0e1564ca6ffb00c1f4fb834fc4b41a601862bf` 的PyTorch2.7.1、2.9至2.14中英文原生支持页，按具体类、方法、参数和产品消费。A2/A3训练系列与950DT不扩到其他型号；未收录表示该清单未纳入，不自动判为不支持，也不把主线回推26.0/PyTorch2.8组合。清单不提供完整社区参数规格、实现或设备验证，本次未执行上游和NPU实验。

## Monitor与模块跟踪

monitor.Aggregation及name、Stat及__init__/add/count/get/name、Event及__init__/data/name/timestamp、data_value_t、EventHandlerHandle、log_event/register_event_handler/unregister_event_handler、TensorboardEventHandler及__init__列三类产品。module_tracker.ModuleTracker也列三类产品，没有完整hook、线程/嵌套模块、聚合周期和事件时钟合同。

不能由Event.timestamp存在推导它与NPU时间线同源或单位相同，也不能把事件注册、ModuleTracker与Profiler模块归因视为相同采集机制。指标来源、时钟和活动范围须分别核对。

## SummaryWriter参数不能共用一个dtype并集

SummaryWriter及所列构造、标量/直方图、图像/视频/音频、文本/图、embedding/PR曲线、自定义标量/mesh/hparams、flush/close均列三类产品；下面保留各参数的局部类型差异。

| 参数位置 | 来源列出的类型 |
| --- | --- |
| add_image/add_images.img_tensor、add_video.vid_tensor、add_audio.snd_tensor、add_embedding.mat、add_pr_curve.labels | FP16/FP32/FP64、UINT8/INT8/INT16/INT32/INT64、BOOL |
| add_graph.input | BF16/FP16/FP32 |
| add_mesh.vertices | BF16/FP16/FP32/FP64、UINT8/INT8/INT16/INT32/INT64、BOOL |

BF16只在图输入和mesh顶点的上述名单中，不据模型BF16训练推定所有可视化字段也支持BF16。labels的通用类型表也不是分类目标含义、范围或阈值契约，未给的位置/shape与语义不自行补齐。

## 记录与性能判断的边界

add_graph支持不证明任意模型可追踪、编译或执行，记录的图也不证明实际NPU Kernel路径；flush/close支持不定义异步写入完成、磁盘可见性和多进程文件竞争协议。固定rank/进程、实际事件字段、输入类型与产物消费者，检查数值和归因，再比较记录打开/关闭时的开销。本次未运行Writer、事件回调或模块跟踪。
