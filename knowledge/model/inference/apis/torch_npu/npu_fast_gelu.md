# npu_fast_gelu：A2/A3 近似激活与输入范围

## 版本与范围

本文依据 `ascend_26_0_pt28` 发布来源组合中 OpPlugin 的固定提交；仅描述下列平台及参数路径。来源配套与实际部署验证分别核对。

## 接口与语义

以下是固定来源的接口声明：

```text
torch_npu.npu_fast_gelu(input) -> Tensor
```

A2/A3 路径按 x/(1+exp(-1.702*x)) 计算 FastGELU，返回 Tensor。该近似形式不能直接作为精确 GELU 的数值等价替代。

## 参数与组合限制

input 为 ND Tensor，最大 8 维，A2/A3 支持 FP16/BF16/FP32、非连续和空 Tensor，但 input 不能为 None。固定来源明确支持训练、推理及图模式；其他产品的公式与类型表需要单独核对。

## 验证与模型关联

对比同一近似公式和模型原激活，记录误差阈值及模型精度；分别验证极值、非连续、空输入与图模式。 本次为文档与静态调用核对，未运行算子或测量性能。

## 950与旧产品公式的边界

完整主线中英文新增950PR及950DT，与A2/A3共同给x/(1+exp(-1.702*x))；入口参数名由发布input改写为self，底层声明两版均为self。主线明确单算子与TorchAir，最大8维、非连续和空输入说明保持，不扩为精确GELU。

旧Atlas训练/推理页另给带绝对值的公式，其指数写0.851*x*(x-|x|)，不与现代公式等价；这里不将这条可疑公式变成所有产品的参考实现。两版ACL只下发FastGelu/FastGeluGrad，OpAPI按SoC分支和符号兼容性选择ACLNN或ACL，不能据此静态修复底层数值公式。fast_gelu别名的公开限制另按旧页消费。
