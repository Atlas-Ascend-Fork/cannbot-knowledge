## 调用与单位

`torch_npu.npu.Event().recorded_time()`返回设备上记录的uint64时间戳，单位**微秒**；Python页的int/torch.uint64表述不表示返回一个Tensor。必须以enable_timing=True创建Event并先record，否则文档列InternalError。发布A2/A3训练，主线新增950DT。

Python streams.py只转发基类；不把函数返回或record调用完成当作全部设备计算完成。Event.elapsed_time(end_event)是两个记录间的毫秒间隔，与recorded_time的微秒时间戳不同，也不能直接和Host时钟相减解释延迟。

TaskQueue清空及等待的副作用另见[定位指南](../../guides/optimization/torch_npu/torch_npu_taskqueue_error_and_flush.md)。计时必须限定设备、事件记录流和完成条件，未运行设备计时试验。
