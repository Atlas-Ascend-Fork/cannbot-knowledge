- [CP chunked-prefill 空 KV 分片返回 None 破 LSE 合并——须返零输出 + -inf LSE 占位（在线-softmax 中性元）](cp_prefill_empty_kv_shard_none_lse_merge.md)：昇腾 context parallel（CP）chunked-prefill 注意力中，当某分片对某 chunk 无 KV cache（total_toks == 0）时，计算 prefill-context 的函数（vllm-ascend attention_cp.py 的 _compute_prefill_context）原返回 (None, None)，被下游跨分片/跨 chunk 的在线-softmax LSE 合并逻辑当张量使用而抛 TypeError。根因是在线-softmax 合并要求每分片提供同形状/同 dtype 的 (output, lse) 两路输入、靠 lse 表达权重，而 None 破坏了「每分片都在场」的合并契约。修法：空分片提前返回与非空 FIA 路径同形状/同 dtype 的占位张量——output 全 0（形状 (T, num_heads, head_size)、query.dtype）、lse 全 -torch.inf（形状 (T, num_heads, 1)、固定 float32）。-inf 的 LSE 是 log-sum-exp 在线-softmax 合并的中性元（exp(-inf)=0、权重 0），等价于该空分片不参与合并，下游无需为空分片写特判分支。非空路径走 npu_fused_infer_attention_score（FIA，TND 布局，softmax_lse_flag=True，actual_seq_lengths_kv/actual_seq_lengths）。触发用例：tensor_parallel_size=2、prefill_context_parallel_size=2、W8A8、cp_kv_cache_interleave_size=128，混合长度 prompt + chunk_size=50 构造空分片边界，回归用例 test_models_chunked_prefill_with_empty_kvcache。抓手系于 CP 分片 + NPU FIA chunked-prefill 的 LSE 合并契约，可迁移到任何昇腾上 CP/ring-attention 式跨分片 chunked-prefill + LSE 合并实现；与 decode 侧「只 mask lse 不 mask out」陷阱互补。
