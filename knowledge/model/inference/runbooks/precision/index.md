- [CP/DCP 在线-softmax 跨卡合并只 mask lse 不 mask out 污染归并——本卡对某序列无 KV 时须对 attn_out 施同一 batch_seq_mask 置 0](cp_dcp_online_softmax_merge_mask_out_not_only_lse.md)：昇腾 CP/DCP 解码 + P/D 分离下,KV 按 context-parallel 维切分后存在"本 CP rank 对某 batch 序列持有 0 份 KV token"的空位置(由 batch_seq_mask = num_computed_tokens_of_pcp_dcp[:,pcp_rank,dcp_rank]==0 标记)。每卡先用 FIA(npu_fused_infer_attention_score)算本地 attn_out 与 attn_lse,cat([out,lse])后跨卡 all_to_all/all_gather,再用在线-softmax 跨卡合并算子 npu_attention_update(lse_list, out_list, update_type)归并。failure_signature:对这些空位置只把 attn_lse 置 -inf、不屏蔽同位置 attn_out,会导致 attention 静默精度回退(accuracy issue),无报错、shape 正确。根因:合并算子以 out 与 lse 为两路独立输入,屏蔽 lse 不等于屏蔽 out,空 rank 的无意义 attn_out 污染归并。修法:在 lse 掩码前对称地对 attn_out 施加同一 batch_seq_mask、置 0(out_mask = batch_seq_mask[:,None,None].expand_as(attn_out); attn_out = torch.where(out_mask,0,attn_out))。可迁移边界:任何在昇腾上实现 CP/DCP 在线-softmax attention 跨卡归并(out+lse 两路合并)的实现都须对本卡无有效 KV 的位置同时屏蔽 out 与 lse;系于昇腾特有抓手(FIA 输出契约、npu_attention_update、PCP/DCP HCCL 归约),与具体模型无关。参考实现 vllm-ascend attention_cp.py::_forward_decode_pcp_dcp,复现于 Qwen P/D 分离。
