# 融合 Kernel

- [CalcRender —— 3DGS Alpha-blending 渲染融合算子（前向/反向）](calc_render.md)：CalcRender 是 3DGS 光栅化的核心渲染算子，把空间中已排序的 3D 高斯球颜色 alpha-blending 到各像素上，构成对应视角的渲染图。host 定义为 CalcRenderFwdDoubleClipGsids（前向）与 CalcRenderBwdVarClipGsids（反向），由 rasterizer.py 中 calc_render(...) 调用。被 3d-gaussian-splatting 串联在渲染流程末端。
- [GaussianFilter —— 3DGS 视锥剔除融合算子（前向/反向 Scatter）](gaussian_filter.md)：Culling（剔除）是渲染前的关键优化步骤：提前过滤对当前帧渲染无贡献的高斯球，减少后续投影/排序/Alpha-blending 计算量。GaussianFilter 把视锥剔除融合为单算子，host 定义见 gaussian_filter.cpp，在 projection_three_dims_gaussian_fused(...) 内与投影一同调用。被 3d-gaussian-splatting 串联。
- [GaussianSort —— 3DGS tile 内高斯球深度排序算子](gaussian_sort.md)：Alpha-blending 渲染依赖累乘，必须保证高斯球在每个 tile 内按深度排序后依次渲染。GaussianSort 负责把每个 tile 命中的高斯球按深度排序，输出排序后的高斯球 ID。host 定义见 gaussian_sort.cpp，被 3d-gaussian-splatting 串联在精确相交映射之后、渲染之前。
- [Precise Intersection（FlashGaussianBuildMask）—— 3DGS 高斯球-像素块精确相交算子](precise_intersection.md)：Precise Intersection 算子用于计算高斯球-像素块（tile）映射关系，基于 FlashGS 算法实现；算法归属依据昇腾适配文档，证据范围限于该适配实现。host 定义为 FlashGaussianBuildMask，Python 侧为 flash_gaussian_build_mask(...)。被 3d-gaussian-splatting 串联在投影之后、排序之前，输出供 gaussian-sort 排序、calc-render 渲染。
- [Projection-3DGS —— 3D→2D 高斯球投影融合算子（前向/反向）](projection_3dgs.md)：投影预处理把 3D 高斯球的均值与协方差由 3D 球面投影到 2D 平面，得到光栅化所需的 2D 均值 means2d、协方差/锥参 conics/covars2d、深度 depths、半径 radius 等属性。前向 host 定义为 ProjectionThreeDimsGaussianForward，反向为 FullyFusedProjectionBwd；Python 侧 projection_three_dims_gaussian_fused(...) 在融合投影的同时执行视锥剔除（见 gaussian-filter）。被 3d-gaussian-splatting 串联在球谐着色之后、排序之前。
- [SphericalHarmonics —— 3DGS 球谐系数→颜色 算子（前向/反向）](spherical_harmonics.md)：球谐（Spherical Harmonics, SH）着色是 3DGS 渲染流程的第一步：由相机到高斯球的视线方向 dirs 与每个高斯球的球谐系数 coeffs 计算出视角相关颜色，再送入投影与渲染。前向 host 定义为 SphericalHarmonicsForward，反向为 SphericalHarmonicsBwd。被 3d-gaussian-splatting 串联在投影之前。
