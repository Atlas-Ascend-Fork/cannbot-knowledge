- [torch.compile 图追踪下符号尺寸校验用 aten::_assert_scalar 替代 Python if 分支（修复 GuardOnDataDependentSymNode）](aten_assert_scalar_guard_data_dependent_symnode.md)：torchtitan-npu DeepSeek V4 compressor 的 if length % ratio: Python 分支在 make_fx 符号化追踪下需对无来源 SymInt（u0）求值 Ne(Mod(u0,4),0)，Dynamo 建不出 guard 抛 GuardOnDataDependentSymNode。修复：length 为 torch.SymInt 时改发 torch.ops.aten._assert_scalar.default 断言（避免Python分支求值的源码方案；尚未核对目标编译产物中的运行时行为），eager 路径保留 raise ValueError。
