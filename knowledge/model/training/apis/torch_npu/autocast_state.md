# NPU Autocast状态API：可选dtype、当前dtype与使能状态

## 固定版本与证据范围

文档固定为OpPlugin发布dedc316708372c9a8bfde4527abd2a94b74840f5及主线d84e9b1d6a558e5f27973cd4329f62968e46fdda，区分发布中文与主线中英文。发布配对TorchNPU为f3ecfe4a7ef7395754da7ca2e35661a7132b519b；补充的独立主线ac0e1564ca6ffb00c1f4fb834fc4b41a601862bf不视为与OpPlugin main已配套。

产品逐接口、参数和版本消费；主线新增950DT不回推发布、不扩到950PR。旧Atlas产品保留来源身份，不由其名字推定其他型号。以下为静态审阅，没有导入上游、加载库、操作设备、采集或性能测试，知识卡stable不代表运行verified。


## 五个入口

| 入口 | 合同 |
| --- | --- |
| get_amp_supported_dtype() | 返回dtype列表；两固定实现按is_bf16_supported返回[FP16,BF16,FP32]或[FP16,FP32] |
| get_autocast_dtype() | 查询当前配置的scalar dtype，文档默认torch.float16 |
| set_autocast_dtype(dtype) | 设置AMP的dtype，不会扩展硬件或算子的能力 |
| is_autocast_enabled() | 查询当前使能布尔状态，不是设备是否具备AMP能力的完整探测 |
| set_autocast_enabled(enable) | 设置bool状态，无返回数据对象 |

发布页列A2/A3训练和旧Atlas，主线各页新增950DT。autocast_utils.py转发_C的查询/设置；列表中存在FP32或BF16不证明所有算子、输入组合、自定义Kernel和梯度都能按该dtype执行。get_autocast_dtype返回一个当前值，不能按文档笼统“支持类型”措辞当成能力列表。

这些底层状态接口不能代替[autocast上下文及自定义前反向](../../guides/torch_npu_autocast_and_custom_autograd.md)的生命周期；退出、异常恢复、GradScaler和优化器存储各有独立合同。本卡未修改AMP状态或运行数值试验。
