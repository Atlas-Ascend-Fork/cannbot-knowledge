# 网络模块

- [DeepSeek-V3.2 / V4 MTP 训练（串联预测与损失）](deepseek_v32_mtp_train.md)：当前独立 mtp_layers、num_mtp_layers 构造参数、packed sequence 位移、全局 token 损失归一化；区分 V3.2 logits 与 V4 mHC/chunk loss、CP 及可选梯度隔离。
- [Gated DeltaNet 训练（Chunk 并行 / Flash 递归 / GDN 上下文并行）](gated_deltanet_train.md)：MindSpeed-LLM 训练侧 Gated DeltaNet（GDN）线性注意力模块，覆盖 Qwen3-Next 与稠密/混合 GatedDeltaNet 预训练。当前 mcore 与 FSDP2 实现的 chunk 反向、三套后端和 GDN 上下文并行边界；旧启动样例已移除。
- [Mamba2 SSM 训练（Mamba Mixer / 状态空间对偶 SSD / SSM 上下文并行）](mamba_ssm_train.md)：MindSpeed-LLM 把 Mamba2 选择性状态空间模型搬到昇腾训练侧，以 monkey-patch 覆盖 Megatron-Core 的 MambaMixer/MambaStack 并强制 use_mem_eff_path=False。mamba_mixer_forward 前向链：A=-exp(A_log) → in_proj 切 z0/x0/z/xBC/dt（d_mlp 门控 MLP 旁路）→ 深度因果 conv1d+SiLU → 选择性 SSM 扫描 → Mamba2RMSNorm 门控（norm_before_gate，FP32）→ out_proj。状态空间对偶 SSD（StateSpaceProcessor.process）把 SSM 递推沿 chunk 切块：softplus+clamp 时间步、x·dt/A·dt 离散化、块内 Y_diag=bmm((C·Bᵀ)∘L,x)、块间 einsum 状态递推 Y_off、segmented_sum 数值稳定分段和。SSM 上下文并行（mamba_cp_algo）解决状态时间依赖：SequenceParallelConvFunction 跨 rank AllGather 卷积尾巴、SSDAllgatherOverlapFn AllGather local_decay/local_hidden_state 让状态传递并发（前向 AllGather/反向 ReduceScatter+计算掩盖），顺序切序列（非 2cp 对称），与 TP/SP 正交。对照 GDN（同为线性序列模型，CP 切 head 而 Mamba 切序列）；mambav2-rmsnormgated 是推理算子级，本页训练模块级。混合 Mamba-Attention 由 hybrid-attention/mlp-ratio 控制，2.7B/8B/hybrid 三脚本。
- [多模态生成训练（MindSpeed-MM 扩散 DiT + VAE）](multimodal_dit_vae_train.md)：MindSpeed-MM 的视频/图像生成训练由 SoRAModel 串联冻结的文本编码器与 VAE、噪声调度器和可训练 DiT：VAE 将输入编码到隐空间，调度器按 DDPM/IDDPM 或 flow-matching 规则加噪，DiT 预测噪声、原图或 velocity 并计算损失。长视频 VAE 通过时间因果卷积与帧维上下文并行保留跨 rank 左边界；DiT 长序列采用 Ulysses 或 Ring Attention。只有 predictor 参与反向，VAE 与文本编码器保持冻结。
- [VLM 多模态训练（TorchTitan Qwen3.5 与 MindSpeed-MM）](vlm_multimodal_training.md)：当前 TorchTitan Qwen3.5 上游复用、视觉 mask 上限、视频 MRoPE 和 VL CP 拒绝条件；保留 MindSpeed-MM 的模型注册、数据接入、loss 归一与微调契约。

- [Engram 训练：Host 记忆表、稀疏更新与联合分片](engram_host_table.md)：说明 950 Engram 训练的按行访问、CPU SparseAdam、EP×EFSDP 分片及 MXFP8 查表副本，区分稀疏计算和完整优化器状态内存。
