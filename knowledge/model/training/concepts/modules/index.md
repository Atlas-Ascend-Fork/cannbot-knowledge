# 网络模块

- [DeepSeek-V3.2 MTP 训练（torchtitan-npu 可配置长度多 Token 预测）](deepseek_v32_mtp_train.md)：DeepSeek-V3.2 MTP 训练（torchtitan-npu 可配置长度多 Token 预测，兼容 FSDP2/EP/TP）：MTPModule 继承 TransformerBlockV32，按 DeepSeek-V3 技术报告(arxiv2412.19437)加 MTP 结构。关键设计：标准 Transformer 层与 MTP 层统一进顶层 model.layers，现有 FSDP2/EP/TP 并行逻辑零额外适配即作用于 MTP。loss：每 MTPModule 独立 CE，total_loss=main_loss+mtp_loss_weight·mtp_loss（patches/torchtitan/loss.py）。配置 TrainingConfig.num_mtp_modules(0=关,=预测 token 数)/mtp_loss_weight(0.3)。区别 cann-infer MTP 投机解码（推理侧）。V4 续训用 num_mtp_modules=1。
- [Gated DeltaNet 训练（Chunk 并行 / Flash 递归 / GDN 上下文并行）](gated_deltanet_train.md)：MindSpeed-LLM 训练侧 Gated DeltaNet（GDN）线性注意力模块，覆盖 Qwen3-Next 与稠密/混合 GatedDeltaNet 预训练。两条入口：mcore spec CustomQwen3NextGatedDeltaNetAttention（DP-only，TP/CP>1 断言报错，340M/1.3B examples/mcore/gated_deltanet 脚本承载）与 FSDP2 Qwen3NextGatedDeltaNet（支持 Flash 后端与 CP）。训练侧三项新增：带完整反向的 chunk gated delta rule（块内 WY/UT 矩阵并行 + solve_tril 下三角求逆、块间状态递推，前向六段算子链 + 反向 dq/dk/dv/db/dg/dh0），三套互斥后端（torch 参考 / --use-triton-gdn Triton / --use-flash-gdn 的 fla_npu AscendC，bf16-only）；decode-cache 的逐步递归形式 torch_recurrent/fused_recurrent；GDN 上下文并行 gdn_forward_with_cp——因递推有序列依赖，用 cp2hp/hp2cp 全互换把序列分片换成 head 分片，含负载均衡重排与参数按 head 切片。门控 g=-exp(A_log)·softplus(a+dt_bias)、beta=sigmoid(b)，输出 RMSNormGated。前反向与 GPU FLAME 逐张量对齐、下游精度差<1%。chunk 算子细节链 gdn-chunk-kernels。
- [Mamba2 SSM 训练（Mamba Mixer / 状态空间对偶 SSD / SSM 上下文并行）](mamba_ssm_train.md)：MindSpeed-LLM 把 Mamba2 选择性状态空间模型搬到昇腾训练侧，以 monkey-patch 覆盖 Megatron-Core 的 MambaMixer/MambaStack 并强制 use_mem_eff_path=False。mamba_mixer_forward 前向链：A=-exp(A_log) → in_proj 切 z0/x0/z/xBC/dt（d_mlp 门控 MLP 旁路）→ 深度因果 conv1d+SiLU → 选择性 SSM 扫描 → Mamba2RMSNorm 门控（norm_before_gate，FP32）→ out_proj。状态空间对偶 SSD（StateSpaceProcessor.process）把 SSM 递推沿 chunk 切块：softplus+clamp 时间步、x·dt/A·dt 离散化、块内 Y_diag=bmm((C·Bᵀ)∘L,x)、块间 einsum 状态递推 Y_off、segmented_sum 数值稳定分段和。SSM 上下文并行（mamba_cp_algo）解决状态时间依赖：SequenceParallelConvFunction 跨 rank AllGather 卷积尾巴、SSDAllgatherOverlapFn AllGather local_decay/local_hidden_state 让状态传递并发（前向 AllGather/反向 ReduceScatter+计算掩盖），顺序切序列（非 2cp 对称），与 TP/SP 正交。对照 GDN（同为线性序列模型，CP 切 head 而 Mamba 切序列）；mambav2-rmsnormgated 是推理算子级，本页训练模块级。混合 Mamba-Attention 由 hybrid-attention/mlp-ratio 控制，2.7B/8B/hybrid 三脚本。
- [多模态生成训练（MindSpeed-MM 扩散 DiT + VAE）](multimodal_dit_vae_train.md)：MindSpeed-MM 的视频/图像生成训练由 SoRAModel 串联冻结的文本编码器与 VAE、噪声调度器和可训练 DiT：VAE 将输入编码到隐空间，调度器按 DDPM/IDDPM 或 flow-matching 规则加噪，DiT 预测噪声、原图或 velocity 并计算损失。长视频 VAE 通过时间因果卷积与帧维上下文并行保留跨 rank 左边界；DiT 长序列采用 Ulysses 或 Ring Attention。只有 predictor 参与反向，VAE 与文本编码器保持冻结。
- [VLM 多模态训练适配（DenseMaskSDPA）](vlm_multimodal_training.md)：torchtitan-npu VLM/多模态训练适配（debug 模型 vlm_debugmodel_npu，无真权重/fake_backend）：适配上游 Llama3Siglip2Transformer，仅 FSDP/HSDP 数据并行（无 TP/CP/PP/EP）。npu_vlm converter 核心：用 DenseMaskSDPA（torchtitan_npu.models.multimodal）替换上游 FlexAttention，在 LLM inner_attention 与 SigLIP2 视觉编码器 Attention 两处生效。multimodal helper：build_text_document_causal_mask/build_encoder_causal_mask/build_valid_patch_mask/scatter_visual_embeddings（按 img_id 位置并入视觉嵌入）。VisionTransformerNpu 子类化 siglip2（零填充双线性位置编码 resize）。新多模态模型应复用 multimodal helper。 MindSpeed-MM 侧补 VLM 训练：Qwen3-VL-30B-A3B MoE 经插件式 FSDP2 后端迁移（HF 接入 + forward 内 CP 切分聚合/MoE aux loss + fsdp_plan.apply_modules 分片 + freeze visual + meta init/hf_to_dcp DCP + npu_patch 融合算子）、VLM loss 三口径（default/per_sample_loss/per_token_loss，对应 fixed_cross_entropy 的 alpha 与 reduction，修 micro_bs×grad_acc 的 global-batch 一致性）、多模态数据接入（ShareGPT messages/images + Qwen3VLPlugin 产 pixel_values/image_grid_thw）。
