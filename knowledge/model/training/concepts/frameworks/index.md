# 框架

- [MindSpeed-Bridge（运行时注册与 HF/Megatron 权重映射）](megatron_bridge.md)：当前 pip/.pth 运行时插件注册、委托训练入口、参数映射验证，以及离线 checkpoint 灵活 PP/VPP layout 的互斥限制。
- [MindSpeed（昇腾大模型训练加速框架 + 低精度训练）](mindspeed.md)：MindSpeed（MindSpeed Core）是面向华为昇腾设备的大模型加速库，提供训练/推理迁移与昇腾专有优化能力。DeepSeek-V3 HiF8 / MXFP8 低精度预训练使用 MindSpeed + MindSpeed-LLM + Megatron-LM(core_v0.12.1)，配置为裁剪版 DeepSeek-v3、8 卡 Atlas 950 950DT、8K 序列。与采用 PyTorch 原生 DTensor 的 torchtitan 不同，MindSpeed 使用 Megatron 风格训练栈，内置 Transformer Engine（TE）兼容模块承载 Fprop/Dgrad/Wgrad MatMul 量化，支持 Delayed/Tensorwise/Blockwise/MX 四类 scaling 与 HiF8/MXFP8；swap-optimizer 源于其自适应 Swap 特性。features_manager 通过 MindSpeedFeature 自描述特性、MindSpeedPatchesManager 两阶段 monkey-patch、optimization_level 0/1/2 分级及 ms-core⇄ms-llm 两层补丁框架接入优化。
- [MindSpeed-MM（昇腾 NPU 多模态大模型训练套件）](mindspeed_mm.md)：MindSpeed-MM 面向 VLM、DiT 图像/视频生成和 Omni 训练，提供 Megatron-mcore 与插件式 FSDP2 两条后端， 由 NON_MEGATRON 分流。FSDP2 通过 model/data 注册表和顶层 YAML 接入新模型，使用逐参数 DTensor sharding、逐模块 fully_shard 和 reshard_after_forward 切换 ZeRO-2/3；其约束包括禁用分布式优化器与 Megatron 完全重计算、插件式 TP=1、仅 DCP 检查点。Bridge 层按架构解析模型，通过通配参数映射 双向拆分、合并和重排权重；Canonical Model 保留 HF 计算布局，使 LoRA 可跨 HF/Megatron 复用。 套件通过 verl_plugin 接入 GRPO；DanceGRPO 和 Sora-DPO 由不依赖 verl 的原生训练入口承载。
- [MindSpeed-RL](mindspeed_rl.md)：MindSpeed-RL 是昇腾 RL 后训练框架，包含原生 mindspeed_rl 和向依赖包文件应用持久补丁的 verl_npu。 原生路径用 Ray 编排 Megatron 训练态与 vLLM 推理态；IntegratedWorker 让 actor、reference 和 reward 分时复用同批 NPU，LoRA share_backbone 时 reference 通过关闭 adapter 得到基座输出，共卡模式不支持 独立 reward 资源。Actor 在 generate、infer-logprob 和 train 之间用显式状态机切换，由 sharding manager 重切分训练与推理所需的不同 TP/PP/EP 布局，空闲模块可卸载到 Host。各 Ray worker 通过 TransferDock 与 ZMQ 交换数据，框架支持 GRPO、DAPO、PPO 和 DPO。
- [torchtitan-npu 配置转换与显式 Override](model_custom_converter.md)：说明 TrainerConfigConverter 的配置转换、override.imports 的精确工厂选择与构建时序、冲突检查及组件语义边界。
- [torchtitan-npu 融合算子与组件替换入口](npu_fused_op_converters.md)：以当前 override 与 ops 机制说明 RMSNorm、RoPE、MoE dispatch/SwiGLU、DSA/SMLA 和 mHC 的启用入口及配置、布局和反向边界。
- [ScaleBox（可扩展分布式代码执行沙盒 + veRL 融合部署）](scalebox.md)：ScaleBox（icip-cas/ScaleBox）是一个开源的可扩展分布式代码执行沙盒，在 cann-recipes-train 中作为昇腾平台上 Code RL（代码强化学习）的代码执行环境。Code RL 的奖励信号来自「让模型生成代码 → 在沙盒里真跑测试用例 → 用通过率打分」，因此一个能扛住 RL rollout 海量并发请求、又能跨机扩展的安全执行沙盒，是 Code RL / Agent RL 训练链路里和训练框架同等重要的一环。ScaleBox 的核心特性可概括为三点：可扩展的分布式代码沙盒体系（多机分布式部署 + 请求负载均衡、单元测试并行 + 实例级并行）、面向 Code RL 的统一训练接口和评估套件（批量评估接口 common_evaluate_batch、内置 LiveCodeBench/HumanEval/MBPP 一键评估）、灵活的 Special Judge 判题机制（自定义判题逻辑，适配多正确答案的复杂编程题）。
- [TorchTitan / torchtitan-npu 训练框架](torchtitan.md)：基于当前插件结构说明 DTensor 并行、配置转换与显式 override、torchtitan_npu.train 入口和单机/多机 launcher 边界。
- [Triton-on-Ascend（昇腾 Triton 算子后端）](triton_on_ascend.md)：Triton-on-Ascend 让用 Triton DSL(@triton.jit + tl.load/store + tl.dot)写的融合算子经 triton_npu 后端落到昇腾 NPU(需 CANN>8.3),是与手写 AscendC、Tile 级 TileLang 并列的第三条算子通道,优势是复用并按 NPU 调度适配开源 Triton 算子(GDN chunk 核移植自 flash-linear-attention)。MindSpeed 内两套 ops/triton:核心 mindspeed/ops/triton 承载 GDN/DeltaNet delta-rule chunk 内核族(solve_tril 求(I+A)^-1、chunk_delta_h 隐状态门控扫描、chunk_o、chunk_scaled_dot_kkt、wy_fast、cumsum、l2norm、sort_chunks),lite/ops/triton 承载 MHC 超连接(MHCPreOnlyTriton/MHCPostTriton + sinkhorn pre/post + pre/post_bmm)与 Sinkhorn 路由;另有实验态 Triton FlashAttention BNSD 与 bf16 indexer。NPU 映射要点:get_available_device 返回 'npu'、get_multiprocessor_count 取 num_vectorcore;chunk_fwd_o 固定 24 核 program 手动均分 chunk(持久化内核风格而非一 tile 一 program);get_autotune_config 暴露昇腾专属旋钮 multibuffer/enable_hivm_auto_cv_balance/tile_mix_vector_loop/tile_mix_cube_loop/no-l0c;make_block_ptr→UB DMA、tl.dot→Cube(fp32 累加)、TMA 关闭;triton.language.extra.cann.extension(tle.extract_slice)补昇腾原语;sinkhorn 反向两阶段确定性归约避 atomic。
- [veRL（火山引擎开源 LLM RL 后训练框架 + 昇腾适配）](verl.md)：veRL（volcengine/verl）是开源 LLM 强化学习后训练框架，结合单控制器（控制流）与多控制器（计算流）优势，简化 PPO / GRPO 等 RL 算法的实现。一次 RL 迭代包含 actor（被训练模型）/ rollout（推理生成）/ reference（参考模型）/ reward（奖励）等 worker 角色，由 Ray 单控制器调度并传递数据。训练后端支持 FSDP / FSDP2 / Megatron-LM，推理后端支持 vLLM / SGLang / HFTransformers。昇腾适配采用 MindSpeed 使能 Megatron-LM 训练后端，以 vLLM-Ascend 承载图模式与大 EP rollout 推理；DeepSeek-R1 RL 使用 Atlas A3 SuperPoD 128 卡集群。verl_npu 适配层在 import 时触发 apply_npu_plugin，经 patch_summary.yaml commit 校验后逐个执行 patch -p1，衔接 MindSpeed 训练后端。
- [vLLM-Ascend（veRL RL 的 rollout 推理后端）](vllm_ascend.md)：vLLM-Ascend 是开源高吞吐推理引擎 vLLM 的昇腾 NPU 适配插件，通过硬件插件化机制解耦框架与硬件依赖，无需修改核心代码即可部署模型。它支持 vLLM V1 模式及 DeepSeek-R1 TorchAir 图模式优化。在 DeepSeek-R1 671B RL 训练中，它承载 veRL 的 rollout（on-policy 采样生成），后续由 reference 计算参考概率分布，再由 actor 计算 loss 并反向更新；与 MindSpeed / Megatron-LM 训练引擎配合，在 Atlas A3 SuperPoD 128 卡上达到真实权重系统吞吐 123.16 TPS/卡。MindSpeed-RL 的 rollout vllm_adapter 负责 megatron_weight_loaders 在线加载权重、QKV/MoE reshape，以及 acl graph、prefix cache、chunked prefill 的接入。

- [GraphTrainer：联合训练图中的通信与计算调度](graphtrainer.md)：区分联合 FX 图、SimpleFSDP、Profile-aware EP 调度和图级 CV 并行，并说明 ChunkLoss 梯度归约合并的适用路径。
