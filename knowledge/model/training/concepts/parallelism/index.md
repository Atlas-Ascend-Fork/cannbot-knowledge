# 并行策略

- [MindSpeed 上下文并行家族（Ulysses / Ring / Hybrid / Unaligned CP）](context_parallel_train.md)：MindSpeed 训练侧上下文并行（Context Parallel/长序列并行）家族，沿 Sequence 维切分把 Attention 的 O(S²) 激活压到单卡，由 --context-parallel-algo 在 CPDotProductAttentionImpl 内分派。Ulysses CP（ulysses_cp_algo）用 single_all_to_all 在 head 维做 All2All 把序列切分换成头切分，约束 num_heads%(cp·tp)==0，GQA 头不足时 repeat_interleave KV。Ring CP（megatron_cp_algo）KV 沿序列维 P2P 环形逐跳传递、分块 Softmax forward_update 累积，不约束头数、序列可无限扩，--cp-window-size>1 启用 Double Ring（LoongTrain 内外双层环）。Hybrid CP（hybrid_cp_algo，USP）拼成 Ulysses×Ring 二维 mesh，cp=ulysses_degree×ring_degree，Ulysses 子组取连续 rank（同节点高带宽）、Ring 子组取跨步 rank。非对齐变体：GatherSizeCalculator/DynamicGatherSizeCalculator 支持变长 Ulysses，get_unaligned_cp_shapes 支持变长 Ring。KV-AllGather CP（kvallgather_cp_algo）AllGather 全量 KV、本地 Q 算注意力，GQA/MQA 友好、TE all_gather 路径。CP-KV-cache（--context-parallel-kv-cache-policy full/half、--context-parallel-cache-interval、--use-ulysses-allgather-kv）前向缓存 KV 带到反向省通信/内存。get_batch_on_this_cp_rank 用 2·cp 对称切分做因果负载均衡，全程依赖 npu_fusion_attention。
- [自定义 CP for DSA（DeepSeek-V3.2 长序列上下文并行）](custom_cp_dsa.md)：torchtitan-npu 自定义 Context Parallel：CP 策略注册表(distributed/context_parallel/registry.py，apply_cp_to_attention_module 按 attention 模块自动选 CP 策略，无手动开关)。两类自定义 CP：(1)SDPA Ulysses CP(ulysses_cp.py，All-to-All 把序列并行分布换成 head 维分布使每节点拿全上下文，context_parallel_degree>1 自动注册)；(2)DSA CP(sparse_attention_cp.py，AllGatherKV 风格，对 KV 前向 AllGather 反向 ReduceScatter)。配置 ParallelismConfig.context_parallel_degree，约束 seq_len%（TP·2·CP）==0，缺 npu_dsa 抛 'No custom CP strategy found'。自动选择：V3 dense→Ulysses，V3.2+npu_dsa→DSA CP。深入含 dsa_forward_with_cp/AllGather KV+因果切片/SLIG/SFAG。
- [DualPipeV（V 形双向流水 + Zero-Bubble dw 分离）](dualpipev.md)：DualPipeV 是 MindSpeed 面向 MoE 大模型训练的流水并行（PP）调度，脱胎自 DeepSeek DualPipe：从 PP 维只截取 DualPipe 一半，再把每个 PP rank 的层二次切分成 chunk0/chunk1、前向沿 rank 下行、回程上行，呈 V 字排布，由此把 DualPipe 的参数翻倍与启动规模翻倍各砍一半。配合 --moe-fb-overlap（MoE 跨 microbatch 前反向通信掩盖）在 overlap 稳定阶段全掩盖专家 All2All/P2P；warmup 尽量多 P2P 掩盖；warmup/cooldown 引入 Zero-Bubble 的 dw（权重梯度）分离压气泡，经 WeightGradStore（start_decouple/flush_chunk_grad/pop_single）实现。MindSpeed 默认取消 cooldown 阶段 dw 分离以降重计算场景内存峰值，--dualpipev-dw-detach 可重开。V 字使首尾 stage 同卡（PP rank0，chunk0 含 embedding、chunk1 含 output head），免 embedding 梯度 AllReduce、天然亲和 MTP、便于 PP 负载均衡。开关 --schedules-method dualpipev；约束层数 ≥2·PP、microbatch ≥2·PP−1、需 untie_embeddings_and_output_weights、与 VPP/CP/异步DDP/swap-attention/tp_2d/custom-fsdp 互斥。气泡 (PP−1)·(F&B+B−W)−F 优于 1F1B/VPP。profiling 场景 DeepSeek-V3 671B PP8 TP2 EP32。
- [FSDP2（Fully Sharded Data Parallel 2）](fsdp.md)：FSDP2 是 PyTorch 分布式训练的核心数据并行演进方案（ZeRO-3 同源思想）：在每个前向/反向计算步骤中按需全量收集（AllGather）被切分到各设备的参数，计算完成后立即重新切分（reshard）释放非本设备参数，从而压低参数 / 梯度 / 优化器状态的驻留显存。FSDP2 基于 DTensor 构建，比 FSDP1 提供更细粒度的通信控制，统一分片管理参数、梯度与优化器状态，并原生适配混合精度与 torchtitan 的自动化切分配置。相较 FSDP1，FSDP2 在分片粒度、通信重叠与内存复用上深度优化：采用逐层（layer-wise）收集与释放机制，让每层的 AllGather 通信与上一层计算相互掩盖，形成高效流水。 图：FSDP2 按需 AllGather / 计算后立即 reshard 的逐层流程（DeepSeek-V3.2 预训练优化文档·内存优化 / FSDP2 流程与特点） 在 DeepSeek-V3.2 的 64 卡 Atlas A3 极致显存部署里，FSDP2 是关键支撑：TorchTitan 当前以 FP32 存权重，671B 模型权重+梯度即占 5368GB，超过 32 卡 A3 的总内存 4096GB，故 64 卡是部署的最小规模——FSDP2 把 Attention/共享专家这类卡间冗余权重以 DP 域为单位二次分片，是把单卡显存压进 A3 容量的核心手段。MindSpeed 侧另有三条 FSDP 落地路径——custom-fsdp 自研分桶 ZeRO-3（per-parameter sharding + DTensor）、torch-FSDP2 适配、ND 并行引擎，与 torchtitan FSDP2 同属 ZeRO-3 思想、实现不同。
- [异构并行（MindSpeed-MM 多模态分组并行 + 动态 DP-CP）](hetero_parallel.md)：MindSpeed-MM 多模态异构并行：把 VLM/Omni 拆成 image_encoder/audio_encoder/text_decoder 三类子模块，各自独立设 tp/pp/cp/mbs 以消化模型异构(encoder/LLM bound 空泡)与数据异构(变长 token 负载不均)。机制为逐子模块用 initialize_model_parallel 建并行组并快照进 _ParallelStatesDict，运行时 change_parallel_state 把快照写回 mpu 全局零通信切换，配合 image_encoder forward pre/post hook 的 all_gather_dp_group/split_tensor_dp_group 做 encoder→LLM 数据分发；异构 PP 经 get_forward_backward_func_wrapper/hetero_pipeline 把编码器段(forward_only、大 mbs)与解码器段(DecoderRerunDataIterator 按 hetero_encoder_mbs_scale 重切)串行调度，patch forward_backward_pipelining_without_interleaving。使能 --hetero-parallel/--hetero-encoder-mbs-scale，shell TP/PP/CP=1、并行度写 model.json，优先级 model.json>shell>megatron 默认；推荐异构 DP/TP/CP(Qwen2.5-Omni 7B ViT/Audio DP8+LLM TP4DP2)与异构 PP。动态 DP-CP(use_dynamic_dpcp/max_cp_size/max_seq_size)按每轮序列长度 DP 优先在 {dp4cp1,dp2cp2,dp1cp4} 切组并广播缓存数据(OpenSoraPlan1.3)；非对齐 Ulysses CP 用 All2All 非均匀切分(--context-parallel-algo ulysses_cp_algo, qwen2vl/2.5vl)。仅 Megatron pretrain_vlm，FSDP2 不支持。
- [MindSpeed 高级流水并行（VPP / Ripipe / 多参数 / Unaligned PP / 变长序列 / PP Layout）](pipeline_parallel_advanced.md)：MindSpeed 在 Megatron 1F1B 流水并行之上提供三类增强：VPP、Ripipe、自动流水搜索和 P2P 通信重叠用于压缩气泡；Noop 空层、Unaligned PP/VPP 与自定义 PP Layout 用于平衡各 stage；多参数流水和变长序列流水扩展跨 stage 传递语义。各能力通过 MindSpeedFeature monkey-patch 接入 Megatron，并存在明确互斥关系；选型需同时核对气泡、激活峰值、通信重叠和布局约束。
- [高维张量并行 TP-2D（MindSpeed 2D Tensor Parallel）](tensor_parallel_2d.md)：MindSpeed 高维张量并行 TP-2D 把一维 TP 单通信域分解为正交子域 tp = tp_x × tp_y，激活值与权重同时在 first-dim（序列/输出维）与 last-dim（隐藏/收缩维）切分。TPXCollectiveComm(nd1_dim1，连续 tp_x rank) 负责序列维 AllGather/ReduceScatter，TPYCollectiveComm(nd1_dim2，跨步 tp_y rank) 负责隐藏维归约。ParallelLinear2D/Linear2DSplitAlongFirstDim 的前向为 AllGather(tp_x)→本地 matmul→ReduceScatter(tp_y) 三段小域通信，MLP fc1/fc2 把 AG/RS 子域对调使二维切分层间翻转。分布式 normalization（LayerNorm2D 九步 e_x/var_x 两次 AllReduce、RMSNorm2D pow_mean 一次 AllReduce）只在 tp_y 子域归约，避免对 input 沿隐藏维 AllGather。RotaryEmbedding 按 tp_y×cp 切位置编码，经 TensorParallelYUnionCP 与 context-parallel 共存。支持 enable-overlap-ag-with-matmul / overlap-matmul-with-rs / coc-fused-kernel 通算掩盖。--tp-2d --tp-x --tp-y 启用，须 tp=tp_x*tp_y；与 sequence-parallel、use-fused-rmsnorm、MoE 互斥。llama3-405B tp=16(tp_x=8,tp_y=2) 较 1D-TP 提升 5%+，叠加融合再 5%+。
- [TorchTitan 5D 并行与 DTensor Sharding 优化（DeepSeek-V3.2）](torchtitan_5d_parallel.md)：DeepSeek-V3.2 TorchTitan 预训练以 DTensor 组织 5D 并行，组合 FSDP2、TP、PP、EP 与自定义 CP；通过调整 MoE 的 TP 通信顺序及 DTensor 算子 sharding 策略，减少不必要的通信与张量重排。
