# 融合 Kernel

- [GDN Chunk 算子（solve_tril / chunk_delta_h / chunk_o / wy_fast Triton 核）](gdn_chunk_kernels.md)：门控 DeltaNet（GDN）线性注意力 prefill/训练侧的 chunk-parallel Triton 算子族（MindSpeed core mindspeed/ops/triton，经 triton-on-ascend 后端落昇腾），由 MindSpeed-LLM 的 ChunkGatedDeltaRuleFunction 串成正反向。算子链：chunk_local_cumsum（log 门控 g 前缀和）→ chunk_scaled_dot_kkt（β·tril(KKᵀ)·门控衰减）→ solve_tril（严格下三角求 (I+A)⁻¹，前代求逆 + 16×16→32×32 Schur 补块合并，WY/UT 变换核心）→ recompute_w_u_fwd（WY 表示 u=A@βv、w=A@β·e^g·k）→ chunk_gated_delta_rule_fwd_h（隐状态 h∈R^{K×V} 的 chunk 间门控扫描：v_res=u−w@h、g/gk 门控、h+=k@v_res、K 沿 64 拆块、h0/ht、cu_seqlens 变长）→ chunk_fwd_o（O=scale·exp(g_i)·(Q@h)+scale·tril(QKᵀ⊙门控)@v_new，grid=24 少核持久化）。反向 dv_local/dhu/dqkwg/wy_repr_bwd 与正向对偶。仅 bf16、fp32 累加；与推理 decode 侧 recurrent_gated_delta_rule 同属一条 delta-rule 的两种时间分解。
- [MHC 训练（融合 Pre/Post 与 Triton Head）](mhc_train.md)：当前 MindSpeed-LLM MHC 的分阶段后端、融合算子布局、四路与迭代数约束、细粒度重计算及流水线边界。
- [SASG（SparseAttnSharedkvGrad，DeepSeek-V4 SAS 训练反向算子）](sasg.md)：DeepSeek-V4 SAS 训练反向的五阶段流水与当前 TND SMLAG 绑定，区分四路主梯度、teacher carrier 和独立 Indexer 梯度。
- [SFAG（SparseFlashAttentionGrad，DSA 稀疏注意力反向算子）](sfag.md)：DSA 主注意力反向的数学与离散访存优化，以及当前 DeepSeek-V3.2 TND AscendC backend、softmax 统计量、CP metadata 和显式 override 接入契约。
- [SLIG（SparseLightningIndexerGradKLLoss，DSA 训练反向算子）](slig.md)：当前 DeepSeek-V3.2 AscendC backend 的 SLIG：forward 零占位，backward 计算 Indexer 梯度和 KL，AuxLoss 按全局有效 token 归一化；保留来源的数学、Tiling 与离散访存优化。
- [SMLA（Sparse Flash MLA，DeepSeek-V4 稀疏 MLA 融合算子）](smla.md)：当前 DeepSeek-V4 TND SMLA/SMLAG 与独立 LI/SLIKG override：backend-owned metadata、teacher 梯度载体、CP 归一及 A3 key-frame 适配。
- [TileLang MoE Token Permute 算子族（permute / unpermute fwd+bwd）](tilelang_moe_token_permute.md)：TileLang-Ascend MoE Token 路由算子族（DeepSeek-V3.2 训练，permute/unpermute 前向+反向 4 算子）：permute（Histogram→全局 Prefix-Sum→流水 Scatter，double-buffer MTE2/MTE3，丢弃 offset≥num_out_tokens）；permute_grad（Gather-Reduce=top-K 专家梯度求和，CAST_LOW2HIGH FP32 累加，Cast/NoCast 双核）；unpermute（加权 Gather+Scale+Accumulate，has_probs，AXPY，Cast-Up FP32）；unpermute_grad（双梯度 perm_grad=grad×prob + probs_grad=点乘 ReduceSum，Dual-Vector-Unit vid[2,…] 各算 HALF_H 再合并）。关键参数 topK/num_experts/num_out_tokens/has_probs/sorted_indices(sio)。是 npu_permute converter 绑定 npu_moe_token_permute/unpermute 的 TileLang 实现。
- [TileLang RMSNorm / SwiGLU / SwiGLU-Grad（DeepSeek-V3.2 训练算子）](tilelang_rmsnorm_swiglu.md)：TileLang-Ascend rms_norm/swiglu/swiglu_grad 训练算子（DeepSeek-V3.2）：rms_norm 平方累加→行 ReduceSum→除以N→+eps→rsqrt→归一化写回；swiglu Swish(x1)=x1·σ(x1)、y=Swish(x1)·x2，5 步 in-UB Swish 链（sub/exp/add/reciprocal/mul，无额外访存）；swiglu_grad Swish'(x1)=σ+x1·σ·(1-σ)、dx2=dy·Swish(x1)、dx1=dy·x2·Swish'(x1)。共享调度：(block_M,block_N) tiling、block_id=cid+i·NUM_CORES、VEC_NUM=2 dual-Vector-Unit 行切分、bf16/fp16→fp32 UB 计算→CAST_RINT 回写。是另一条 TileLang 实现；仅单位权重且 eps 等条件一致时与有权重 converter 等价。
- [TileLang RoPE（旋转位置编码，TileLang-Ascend 训练算子）](tilelang_rope.md)：TileLang RoPE 的双旋转、Partial RoPE 和训练反向数学；当前 TorchTitan AscendC override 的位置表与尾部旋转边界。
