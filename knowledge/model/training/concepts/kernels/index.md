# 融合 Kernel

- [GDN Chunk 算子（solve_tril / chunk_delta_h / chunk_o / wy_fast Triton 核）](gdn_chunk_kernels.md)：门控 DeltaNet（GDN）线性注意力 prefill/训练侧的 chunk-parallel Triton 算子族（MindSpeed core mindspeed/ops/triton，经 triton-on-ascend 后端落昇腾），由 MindSpeed-LLM 的 ChunkGatedDeltaRuleFunction 串成正反向。算子链：chunk_local_cumsum（log 门控 g 前缀和）→ chunk_scaled_dot_kkt（β·tril(KKᵀ)·门控衰减）→ solve_tril（严格下三角求 (I+A)⁻¹，前代求逆 + 16×16→32×32 Schur 补块合并，WY/UT 变换核心）→ recompute_w_u_fwd（WY 表示 u=A@βv、w=A@β·e^g·k）→ chunk_gated_delta_rule_fwd_h（隐状态 h∈R^{K×V} 的 chunk 间门控扫描：v_res=u−w@h、g/gk 门控、h+=k@v_res、K 沿 64 拆块、h0/ht、cu_seqlens 变长）→ chunk_fwd_o（O=scale·Q@h+scale·tril(QKᵀ⊙门控)@v_new，grid=24 少核持久化）。反向 dv_local/dhu/dqkwg/wy_repr_bwd 与正向对偶。仅 bf16、fp32 累加；与推理 decode 侧 recurrent_gated_delta_rule 同属一条 delta-rule 的两种时间分解。
- [MHC 训练算子（DeepSeek-V4 Manifold-Constrained Hyper-Connections：Triton BMM + Sinkhorn）](mhc_train.md)：MindSpeed-LLM deepseek4 把 DeepSeek-V4 的 MHC（Manifold-Constrained Hyper-Connections / 流形约束超连接 / 超连接）残差结构落到一组 Triton-on-Ascend 算子，补齐推理侧只有正向的 HcPre/HcPost 所缺的训练正反向。三条链：预连接 BMM（MhcPreBmm，4 路按 pre 权重融合为一路）；全量 Sinkhorn 切分（从 hc_fn 投影的 mixes 一次产 pre=σ+eps / post=2σ / comb，4×4 comb 经 Sinkhorn-Knopp 迭代逼近双随机，反向重放迭代逆传）；后连接 BMM（post_bmm1 Post 扩展 + post_bmm2 用 tle.extract_slice 做 comb 混合 + add → MHCPostTriton）。另有 pre_only 出口收敛（反向确定性归约避 atomic，配 MHCPreOnlyTriton：rms_norm+matmul+Triton 混编）与 mhc_recompute 省激活。全程 fp32、hc_mult=4 固定。与推理侧 mhc / mhc-hcpre-hcpost、torchtitan-npu npu_mhc_pre 对照。
- [SASG（SparseAttnSharedkvGrad，DeepSeek-V4 SAS 训练反向算子）](sasg.md)：SparseAttnSharedkvGrad（SASG）是 sparse-attn-sharedkv（SAS，DeepSeek-V4 统一 Attention 融合算子）的训练反向融合算子。它在 cann-recipes-train 的 DeepSeek-V4-Flash TorchTitan-NPU 续训练实践中，与 slig（Lightning Indexer 反向 + KL Loss）一道补齐 V4 稀疏注意力的反向链路——推理侧 cann-recipes-infer 只有 SAS / lightning-indexer 正向算子，SASG 是训练侧新增件。
- [SFAG（SparseFlashAttentionGrad，DSA 稀疏注意力反向算子）](sfag.md)：SparseFlashAttentionGrad（SFAG）是 DeepSeek-V3.2 训练独有的 sparse-flash-attention 反向融合算子，整体沿用 FlashAttentionGrad（FAG）计算流程，针对 DSA 稀疏 Top-k 选择带来的离散访存做指令缩减与搬运聚合。与推理侧不同：推理只有 LI/SFA 正向算子，SFAG 是训练侧新增件，与 slig（Indexer 反向 + KL Loss）一道构成 DSA 训练反向算子组，是「业界率先攻克 DSA 反向」的关键之一。 在 TorchTitan-npu 中，SFAG 并非独立的 autograd.Function，而是 torch_npu.npu_sparse_flash_attention 正向算子在 PyTorch autograd 引擎下注册的反向实现——正向于 dsa_forward 落子，反向由 autograd 自动触发，因此正向调用必须 return_softmax_lse=True 以向反向透传 softmax_max/softmax_sum（见 ［op 绑定］(#op-绑定torch_npunpu_sparse_flash_attention)）。
- [SLIG（SparseLightningIndexerGradKLLoss，DSA 训练反向算子）](slig.md)：SparseLightningIndexerGradKLLoss（SLIG）是 DeepSeek-V3.2 训练独有的 DSA 反向融合算子：在 Sparse Training Stage 计算每个 token Top-k 位置的 lightning-indexer 反向梯度，并融合 KL Loss 的计算。反向梯度依赖 sparse-flash-attention 正向 softmax 的聚合归一化结果（softmax_max / softmax_sum）与 Lightning Indexer 自身的输出分布。推理侧只有 LI/SFA 正向算子，SLIG 是训练侧新增件，也是「业界率先攻克 DSA 反向」的核心。device 侧 kernel 对应 torch_npu.npu_sparse_lightning_indexer_grad_kl_loss，在 torchtitan 里通过 npu_dsa converter 注入。
- [SMLA（Sparse Flash MLA，DeepSeek-V4 稀疏 MLA 融合算子）](smla.md)：npu_smla converter（torchtitan-npu）：DeepSeek-V4 Sparse Flash MLA 融合算子。950/Ascend-950 走 torch_npu SMLA 融合路径 + attention mask 接入 post_dataloading_process；非 950 保持兼容 V4 稀疏注意力/LI/LI-loss。关键：LI-loss 计算+反向梯度融进 npu_sparse_lightning_indexer_klloss_grad，默认不显式算/打印 LI-loss、跳过 save_loss_to_tracker（区别 V3.2 DSA 显式 LI-loss），避免额外重计算；调试设 logger npu_smla=DEBUG 强制写 tracker。与 slig/sfag/sasg 同属 V4 稀疏注意力训练融合算子。
- [TileLang MoE Token Permute 算子族（permute / unpermute fwd+bwd）](tilelang_moe_token_permute.md)：TileLang-Ascend MoE Token 路由算子族（DeepSeek-V3.2 训练，permute/unpermute 前向+反向 4 算子）：permute（Histogram→全局 Prefix-Sum→流水 Scatter，double-buffer MTE2/MTE3，丢弃 offset≥num_out_tokens）；permute_grad（Gather-Reduce=top-K 专家梯度求和，CAST_LOW2HIGH FP32 累加，Cast/NoCast 双核）；unpermute（加权 Gather+Scale+Accumulate，has_probs，AXPY，Cast-Up FP32）；unpermute_grad（双梯度 perm_grad=grad×prob + probs_grad=点乘 ReduceSum，Dual-Vector-Unit vid[2,…] 各算 HALF_H 再合并）。关键参数 topK/num_experts/num_out_tokens/has_probs/sorted_indices(sio)。是 npu_permute converter 绑定 npu_moe_token_permute/unpermute 的 TileLang 实现。
- [TileLang RMSNorm / SwiGLU / SwiGLU-Grad（DeepSeek-V3.2 训练算子）](tilelang_rmsnorm_swiglu.md)：TileLang-Ascend rms_norm/swiglu/swiglu_grad 训练算子（DeepSeek-V3.2）：rms_norm 平方累加→行 ReduceSum→+eps→rsqrt→归一化写回；swiglu Swish(x1)=x1·σ(x1)、y=Swish(x1)·x2，5 步 in-UB Swish 链（sub/exp/add/reciprocal/mul，无额外访存）；swiglu_grad Swish'(x1)=σ+x1·σ·(1-σ)、dx2=dy·Swish(x1)、dx1=dy·x2·Swish'(x1)。共享调度：(block_M,block_N) tiling、block_id=cid+i·NUM_CORES、VEC_NUM=2 dual-Vector-Unit 行切分、bf16/fp16→fp32 UB 计算→CAST_RINT 回写。是 npu_rms_norm converter 绑定算子的 TileLang 实现。
- [TileLang RoPE（旋转位置编码，TileLang-Ascend 训练算子）](tilelang_rope.md)：TileLang-Ascend RoPE 训练融合算子（DeepSeek-V3.2，前向+反向，训推通用）：interleave/half 两种旋转模式（interleave rotate([x0,x1,x2,x3])=[-x1,x0,-x3,x2]；half=[-x2,-x3,x0,x1]），前向 out=x*cos+rotate(x)*sin、反向 dx=cos*dy+swap(sin_masked*dy)；Partial RoPE 仅末 rope_dim 维；纯 Vector 算子（按操作类型推断）+ fp32 计算（前向为逐元素 FMA，非归约累加）；block_M 默认 64(fp16/bf16)/32(fp32)；6 步 TileLang 流程（block load→cast fp32→sin/cos load→gather+mask 元素重排→RoPE 计算→writeback）。是 npu_rope converter 绑定算子的 TileLang 实现。
