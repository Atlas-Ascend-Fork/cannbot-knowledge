# 导航

- [Alpamayo-R1（智驾 VLA 推理 · 昇腾 A2）](alpamayo_r1.md)：Alpamayo-R1（下文 AR-1）是 NVIDIA 提出的面向 L4/L5 级智能驾驶的视觉-语言-动作（VLA）大模型，cann-recipes-embodied-ai 在昇腾 Atlas A2 上完成其推理迁移与计算逻辑优化。AR-1 融合视觉感知与自然语言指令构建结构化场景理解，并引入显式的因果思维链（Chain-of-Causal-Thinking, CoC）机制，模拟人类驾驶员「观察—分析因果—预判后果—决策」的认知流程，生成稳健可验证的轨迹规划，同时输出自然语言决策解释。
