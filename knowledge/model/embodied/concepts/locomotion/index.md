# 运动控制

- [LQC（Learning-based Quadruped Controller · 昇腾 A2 训推）](lqc.md)：LQC（Learning-based Quadruped Robot Controller）是适用于足式 / 人形机器人的强化学习运动控制算法，支持宇树 G1、GO2 等多款本体的模型导入、一键式训练与推理验证。cann-recipes-embodied-ai 在昇腾 Atlas A2 服务器上完成优化与迁移，推动昇腾在足式机器人领域的场景化落地。
- [NMR（Neural Motion Retargeting · SMPL-X→G1 · 昇腾 A3 训推）](nmr.md)：NMR（Neural Motion Retargeting）是将人类 SMPL-X 动作重定向到宇树 G1 人形机器人的神经网络方法，面向昇腾引擎（Atlas A3 系列）训练与部署。cann-recipes-embodied-ai 完成其在昇腾上的训练与推理迁移。
