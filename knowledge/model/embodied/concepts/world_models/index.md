# 世界模型

- [AgiBot Arm World Model（机械臂世界模型，昇腾 A2 训练+推理）](agibot_arm_world_model.md)：AgiBot Arm World Model 是本仓打包的一个机械臂世界模型工作流样例，基于 Wan2.1-Fun-V1.1-1.3B-Control 视频扩散模型，在 AgiBotWorld 风格数据上做轨迹条件（trajectory-conditioned）的视频世界生成。提供多卡训练样例 + 基于 PyTorch 的单卡推理样例，面向昇腾 NPU（README 标注 Device: Ascend910，对应 Atlas A2 级硬件）。训练默认 8 NPU，推理默认单卡。模型本体复用上游 modelscope/DiffSynth-Studio 中的 Wan 系列实现，本仓自带训练/推理脚本、数据加载、轨迹/动作工具与 lvdm/ 第三方模块。
- [Cosmos-Predict2.5-2B 视频生成世界基础模型（昇腾 A3）](cosmos_predict2_5.md)：Cosmos-Predict2.5-2B 是 NVIDIA 推出的世界基础模型（World Foundation Model），面向物理 AI（Physical AI）场景的世界模拟，cann-recipes-embodied-ai 提供昇腾 Atlas A3 上的 NPU 适配优化与多卡并行实现。模型基于流匹配（Flow Matching）架构，结合 Cosmos-Reason1 物理 AI 视觉语言模型作为文本编码器，生成高质量、物理一致的视频世界，用于机器人操作、自动驾驶等动态场景的模拟与预测。支持文本 / 图像 / 视频三种条件输入模式（Text2World / Image2World / Video2World）；单段生成视频长约 5.8 秒，逐段生成拼接可实现 30-120 秒长时序一致视频。整体评分据适配 README 与参数量大 7 倍的 Wan2.2-27B-A14B 相当（PAI-Bench 外部基准，无独立复测结果）。昇腾优化重点是多卡并行推理 + NPU 融合算子适配。
- [Cosmos-Transfer2.5-2B 视频风格转换世界模型（昇腾 A3）](cosmos_transfer2_5.md)：Cosmos-Transfer2.5-2B 是 NVIDIA Cosmos 平台的世界基础模型之一，是面向物理 AI 的多控制网络（multi-controlnet）视频风格转换模型：基于深度图、语义分割、边缘检测等多种控制信号，对输入视频做 video-to-video 的风格迁移与内容转换，输入可同时接收 RGB / depth / segmentation / edge 等多模态结构化信号，用于自动驾驶场景模拟、机器人视觉仿真、视频内容创作。cann-recipes-embodied-ai 提供昇腾 Atlas A3 上的 NPU 适配优化，重点是 CFG 并行 + 上下文并行 + NPU 融合算子适配。
