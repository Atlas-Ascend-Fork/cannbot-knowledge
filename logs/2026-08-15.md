# 2026-08-15

## [17:30] bootstrap | 初始化知识库

### Summary

初始化面向 CANNBot 的平台中立工程知识库，建立空 OKF Bundle 骨架、统一治理契约、三类基础 Skill、项目安装入口和质量回归。

### Details

- 以 `knowledge/` 作为唯一 OKF v0.2 Bundle root，只保留五个 domain 根、`ops` 的五个注册 route 和 `model` 的三个注册 route；初始知识卡、Profile 目录、检索 posting 和图谱关系均为空，其他路径随真实知识创建。
- 建立 Frontmatter Schema、Profile、Registry 和统一 Contract，约束字段、路径、受控值、生命周期、固定来源、逐层索引、链接和发布镜像关系。
- 提供平台中立的 `knowledge-ingest`、`knowledge-query` 和 `knowledge-lint`：Ingest 统一路由新来源、增量、版本升级和候选建卡，并以不可覆盖 receipt 绑定 inventory、ledger、固定源文件与真实候选卡；Query 使用平台受限的持久索引，以及逐层校验 request/receipt 文件哈希的 state/ready/outcome 审计链；Lint 执行只读治理检查并整理可复现 Issue 材料。
- 提供 consumer/contributor 安装模式和多客户端适配，统一安装 `.agents/skills` 规范入口、项目知识根、持久化 profile、空库可用索引和可卸载托管上下文；路径冲突和 marker 异常在写入前失败，reinstall 保留原 profile，不修改用户全局配置。
- 建立 README、贡献指南、Agent 工作约定、检索与治理单元测试及统一质量门禁；正式 Bundle 保持无测试知识，临时多卡语料实际校验 Recall/MRR、排序和 platform/DSL/status/shared 隔离，索引失效和审计链同样使用临时数据验证。
- 图谱和 SQLite 索引均由规范源本地重建并保持为 ignored 产物；Skill 只包含通用 `SKILL.md`、references、scripts 和测试，不保存单一 Agent 厂商元数据。
