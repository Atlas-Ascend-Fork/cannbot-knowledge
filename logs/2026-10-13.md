## [09:05] 公共组件 | 新增 mcp-server：知识库检索契约的 MCP 适配层

### Summary

按 `docs/mcp_server_spec.md` 实施规格新增 `mcp-server/` 公共组件：三个只读 MCP 工具（discover/search/read_card）、stdio 与 Streamable HTTP 双传输（多令牌认证 + 限流 + IP 冷却）、仓外 JSONL 调用日志与离线分析命令；`install.sh` 新增可选 `--with-mcp`。默认路径零变化：根 `requirements.txt` 逐字节不变，不带新 flag 的安装器行为不变，不使用 MCP 服务器的用户无感知。

### Details

- `mcp-server/server.py`：官方 `mcp` SDK（`mcp>=2,<3`，2.x 中 FastMCP 更名为 MCPServer）实现。search 的 14 个参数与 CLI 一一映射（零改写、零默认值注入），payload 原样透传；platform 保持可选 + 缺失报错指导补参（fail-closed），schema 不设 required。read_card 分页默认 200 行/上限 500、`next_offset` 游标、frontmatter 解析为顶层对象、sources/source_headers 提升、三种正文链接形态解析为 `resolved_path`（#锚点无 resolved_path、仓外链接不收录、index.md 保留）、images url+alt 透传、stdio 模式附加 `local_only`；path canonicalize 强制落在 `knowledge/` 根内（拒绝 `../` 穿越、绝对路径、符号链接逃逸），卡片须存在于索引。错误映射：CLI 退出码 2 → tool error 带 stderr 摘要与重建索引修复指引，绝不静默重建。
- HTTP 传输：stateless Streamable HTTP（`POST /mcp`），`CANNBOT_MCP_TOKENS` 多令牌清单（token:label，裸令牌=匿名，清单空拒绝启动），逐把 compare_digest 比对，命中 label 写入日志 principal；每令牌滑动窗口限流默认 60 次/分钟（429 + Retry-After）；认证失败按直连 IP 冷却（1 分钟 10 次 401 → 封 5 分钟，不信任 X-Forwarded-For）；限流器为可替换接口（in-memory 实现）。stdio 模式不受认证与限流影响。
- 子进程防线：信号量限制并发（默认 CPU 核数，`CANNBOT_MCP_MAX_SUBPROCS`）+ 硬超时（默认 30s，`CANNBOT_MCP_SUBPROC_TIMEOUT`），挂死 CLI 被杀并返回结构化 tool error。
- 调用日志：每次 tools/call 一行仓外 JSONL（ts/transport/principal/tool/args/ok/count/latency_ms/request_sha256/index/hits），HTTP 默认开、stdio 默认关（`CANNBOT_MCP_LOG`/`CANNBOT_MCP_LOG_DIR`），失败调用同样记录；auth_failed/rate_limited 独立事件行；日志目录配置在仓内时拒绝启用。
- `mcp-server/analyze_logs.py`：维护者离线命令（仅标准库），三维度报告（零命中聚合含 knowledge_request Issue"已尝试的检索"可粘贴文本、查询词热度、卡片阅读热度），`--log-dir` 多目录合并按幂等键去重、`--days` 时间窗、报告写仓外 reports/，principal 全 null 时标注匿名模式。
- `install.sh --with-mcp`：向目标项目写 `.mcp.json`（uv --directory 启动 stdio 本地模式，env 含 CANNBOT_KNOWLEDGE_ROOT；已有文件合并保留其他 server 条目）并打印 Cursor / Claude Desktop / HTTP 远程配置片段；与 `--prompt-action` 互斥；默认不带 flag 时安装器行为与产物逐字节不变（evals/test_installer.py 回归覆盖）。
