# 技术问答

术语、单一语义或单 API 事实通常走轻量查询；问题同时涉及契约、故障、实现或性能时切换到对应模式。

## 查询路线

1. 先把问题改写成一个可判定 decision，并确认 platform；纯术语也传目标 platform，Glossary 会按平台中立处理。
2. 用 domain、technology、Profile 和任务标签收窄，读取少量最高相关候选正文。
3. 定义和规范回到正文或固定 source；摘要、图谱关系和 trust tier 只用于选证据。
4. 回答中区分明确规范、特定实现候选、经验性结论和当前知识缺口。

## 补搜与使用

零命中不证明能力不存在。只有问题新增了错误信号、平台版本或实现边界时补搜；需要正式交接或存在来源冲突时升级审计路径。
