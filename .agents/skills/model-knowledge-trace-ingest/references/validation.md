# 公开离线验证

仓库提交检查使用根目录 check.sh。Skill 的本地解析、批处理、证据和审查绑定可独立验证：

```bash
python3 -m unittest discover -s .agents/skills/model-knowledge-trace-ingest/scripts -p 'test_*.py'
```

合成测试覆盖 Codex、Claude Code、OpenCode 和通用消息导出中的等价任务、调用与返回；另一种结构通过字段映射接入。还检查混合来源批次、未知块、不完整记录、长文本、脱敏、原文不执行、来源变化与审查内容变化。格式覆盖仅代表已测结构，不承诺兼容所有客户端版本。

策展回归覆盖完整 claim/性能字段保留、显式删减与标题/正文同步、原机制单元不可被子串替换、合并后来源重排与独立比较、多候选错误汇总、真实审查覆盖、语义 minor 阻断及实际入库清单。归一化回归区分继承快照前缀与真实重复回合；有界证据回归核对 Unicode/控制字符、空结果、调用配对、跨页逐字还原、来源变化及输出路径边界。

公开 A/B 现场生成合成来源，不依赖私有数据、网络、模型客户端或密钥：

```bash
python3 .agents/skills/model-knowledge-trace-ingest/scripts/synthetic_ab.py --output .build/model-trace-synthetic-ab
```

A 为单来源精确分页，B 为批级连续阅读视图，C 为引用目录加有界证据页。三组使用同一规范化事件与相同开发事件集合，分别检查短、长正文的完整性、选择字符数、响应页数和实际序列化字节；C 另核对逐页字节上限和准备阶段存储字节。系统上下文在三组均单列。B 适合能直接供给正文的小批，C 控制工具分页上限；页数不能跨不同供给方式直接解读成速度。

report.json 记录实际结果。页数不代表模型请求数或 token 消耗；离线实验不执行语义挖掘，不证明候选质量、真实性能或费用收益。语义验收需另行提供可评审样本、来源边界与实际审查记录。
