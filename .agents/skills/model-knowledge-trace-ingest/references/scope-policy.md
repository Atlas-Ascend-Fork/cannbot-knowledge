# 模型与框架知识范围

轨迹来源不限 Agent 类型，知识提取限定于以下实际任务：

- 模型推理或训练的性能、显存、精度、量化、并行、通信、图执行及测量优化，包含相关失败尝试与诊断。
- 推理/训练框架的开发、迁移适配、调试、验证和优化，例如 vLLM、SGLang、Torchtitan 及同类框架；示例不构成封闭白名单。
- 服务于上述任务的运行环境、依赖、后端、容器、通信和部署配置调试调优；框架底座自身的加载、构建和兼容性问题也在范围内。

依据实际用户目标、操作对象和开发证据判定，不以客户端名称、日志文件名、框架关键词或最终是否成功作为标准。框架适配不要求已经跑通模型；模型/框架调用链中的算子集成问题可以纳入，但孤立算子实现或微基准不能直接外推为模型知识。

无关的普通应用、系统管理、网站、文案及 Agent 编排仅记录 out_of_scope，不提取其知识。混合会话只采纳范围内的证据；缺上下文导致无法判定时记 deferred 并保留缺口。不要因系统提示词提到框架名称就把会话纳入，也不要因包含构建、测试或环境步骤而排除真实框架任务。

远端全量初筛由调用方完成。本地批次仍逐来源记录实际去向，保持原始来源和候选对应关系，不对每条轨迹额外派发筛选 Agent。

策展必须同时记录任务锚点和至少一处客观的模型调用、框架实现/集成或相关环境证据。算子路径含模型名称、赛题背景写 LLM、单算子输入 shape 接近模型或宣称可用于训练，都不足以证明关系。仅验证独立 kernel、DSL 微基准、算子用例或其 CI 的材料从本 Model 批次排除；不自动转写到其他领域。
